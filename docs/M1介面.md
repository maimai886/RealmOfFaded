# M1 介面

M1：登入、選角、進萌芽草原、點地走路會繞牆，兩個客戶端互相看得到對方走。
舊行為和數字在 `M1舊行為.md`，寫法照 `程式規範.md`，行數預算 6,000。

## 1. 製作人定的

- 新角色和找不到位置的角色都放萌芽草原 `meadow` 的 [4, −39]，M1 沒有城鎮
- 超大數字照舊在解析前掃，掃到算 `bad_json` 踢線；`1e400` 的測試期望改成踢線
- 保留名字的清單放資料檔，`sproutia` 換成 `rof`、`realmoffaded`
- `move.dir` 不做，做搖桿時再做，那兩條防加速測試跟著延後
- 走動的實體是一個點，半徑 0，和舊的擋路結果一樣
- 伺服器設定放 `rust/crates/server/config/`，在 `rust/` 底下不會被匯出進客戶端
- `docs/伺服器架構.md` 的校正門檻照程式改成 0.12

## 3. 各模組對外長什麼樣

名字和參數照這裡寫，要改先講。座標一律公尺，地面是 xz 平面，y 朝上。

**rof-core，Marcus**：伺服器和客戶端預測共用
- `MapCollision::new(&MapData)`、`is_walkable(x, z) -> bool`、`move_point(from, to) -> [f32; 2]`、`push_out(p) -> [f32; 2]`
- `PathFinder::new(&MapCollision)`、`find_path(from, to, budget) -> Vec<[f32; 2]>`
- 規則照 `M1舊行為.md` 第 3、4 節，兩邊算出一模一樣的路

**client.rs，Marcus**：`RofClient`，繼承 Node，autoload 名字 `Rof`
- `connect_server(host: String, port: i64)`
- `request(t: String, d: Dictionary) -> i64` 回請求編號
- 訊號 `connected()`、`disconnected(reason: String)`、`replied(id: i64, ok: bool, reason: String, data: Dictionary)`
- 收到 `world.enter` 由它換到世界場景，介面不用管

**world.rs，Marcus**：`RofWorld`，繼承 Node3D，把下面四個接起來，預測和內插用 `rof-netcore`

**map.rs，Rowan**：`pub fn build(map_id: &str) -> Gd<Node3D>`
- 讀 `data/maps/<map_id>.json` 和 `data/props.json`，蓋地面、小路、擺設、光和環境，長相照舊專案的萌芽草原
- 碰撞不歸這裡，這裡只管看得到的東西

**actors.rs，Leo**：`Actor`，繼承 Node3D
- `setup(gender: String, appearance: Dictionary)` 載初心者底板圖集
- `set_motion(velocity: Vector2, camera_yaw: f32)`：選八方向、idle 或 walk、播放倍率，數字照 `M1舊行為.md` 第 7 節
- 位置由呼叫的人設，這裡不移動自己

**camera.rs，Chloe**：`RofCamera`，繼承 Node3D，裡面放 Camera3D
- `follow(target: Vector3)`、`yaw() -> f32`；縮放和右鍵轉向自己處理，數字照第 7 節

**input.rs，Chloe**：`GroundPicker`，繼承 Node3D
- 滑鼠射線打地面、吸 0.6 公尺格子，畫游標那一格
- 訊號 `hovered(x: f32, z: f32)`、`clicked(x: f32, z: f32)`；`set_walkable(walkable: bool)` 由世界告訴它游標那格能不能走

**介面，Chloe**：`scenes/login.tscn` 當主場景，登入、伺服器列表、選角、建角四頁，只透過 `Rof` 講話

## 4. 驗收

- 伺服器：Rust 整合測試開真的伺服器，兩個機器人登入、建角、進地圖，一個點牆後面的點，繞過去停在同一格，另一個收到它的 spawn 和移動
- 防作弊：`M1舊行為.md` 第 9 節的協定、連線、帳號、密碼、視野、移動，`move.dir` 那兩條除外
- 畫面：每個模組用自己的預覽場景加 `ShotTaker` 節點截圖，`--shot=路徑`；最後兩個客戶端互相看得到對方的截圖
- 行數：每個崗位回報自己寫了幾行，空行和註解不算
