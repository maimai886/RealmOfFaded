# M1 介面

M1：登入、選角、進萌芽草原、點地走路會繞牆，兩個客戶端互相看得到對方走。舊行為和數字在 `M1舊行為.md`，寫法照 `程式規範.md`，行數預算 6,000。

## 1. 製作人定的

- 新角色和找不到位置的角色都放萌芽草原 `meadow` 的 [4, −39]，M1 沒有城鎮
- 超大數字在解析前掃，掃到算 `bad_json` 踢線
- 保留名字放 `data/reserved_names.json`
- `move.dir` 不做，做搖桿時再做，那兩條防加速測試跟著延後
- 走動的實體是一個點，半徑 0
- 伺服器設定放 `rust/crates/server/config/`，在 `rust/` 底下不會被匯出進客戶端

## 3. 各模組對外長什麼樣

名字和參數照這裡寫，要改先講。座標一律公尺，地面是 xz 平面，y 朝上。

- **rof-core**：`MapCollision::new(&MapData)`、`is_walkable(x, z)`、`move_point(from, to)`、`push_out(p)`；`PathFinder::new(&MapCollision)`、`find_path(from, to, budget)`。伺服器和客戶端預測共用，兩邊算出一模一樣的路
- **client.rs**：`RofClient` 繼承 Node，autoload 名字 `Rof`。`connect_server(host, port)`、`disconnect_server()`、`request(t, d)` 回請求編號，`auth.login` 的 `client_version` 由它補；8 秒沒回發 `replied(id, false, "timeout", {})`。訊號 `connected()`、`disconnected(reason)`、`replied(id, ok, reason, data)`，連不上時 reason 是 `connect_failed`。收到 `world.enter` 由它換到世界場景
- **world.rs**：`RofWorld` 繼承 Node3D，把下面四個接起來，預測和內插用 `rof-netcore`
- **map.rs**：`build(map_id) -> Gd<Node3D>`，讀地圖檔和 `data/props.json` 蓋看得到的東西，碰撞不歸這裡；光、環境、材質放 `scenes/maps/<map_id>.tscn`，太陽是裡面的 `Sun` 節點
- **actors/**：`Actor` 繼承 Node3D。`setup(gender, appearance)` 載底板圖集；`set_motion(velocity, camera_yaw)` 選方向、idle 或 walk、播放倍率；`light_from(map)` 蓋好地圖後呼叫一次角色才受光。位置由呼叫的人設；自己傳預測的意圖速度，別人傳內插區段的速度
- **camera.rs**：`RofCamera` 繼承 Node3D，裡面放 Camera3D。`follow(target)`、`yaw()`；縮放和右鍵轉向自己處理，數字在 `data/camera.json`
- **input.rs**：`GroundPicker` 繼承 Node3D，滑鼠射線打地面、吸 0.6 公尺格子、畫游標那一格。訊號 `hovered(x, z)`、`clicked(x, z)`；`set_walkable(walkable)` 由世界告訴它游標那格能不能走；游標圖由介面的 `game_cursor.gd` 掛上
- **介面**：`scenes/login.tscn` 是主場景，登入、伺服器列表、選角、建角四頁，只透過 `Rof` 講話

## 4. 驗收

- 伺服器：整合測試開真的伺服器，兩個機器人登入、建角、進地圖，一個點牆後面的點繞過去停在同一格，另一個收到它的 spawn 和移動
- 防作弊：`M1舊行為.md` 第 9 節，`move.dir` 那兩條除外
- 畫面：每個模組用自己的預覽場景截圖，最後兩個客戶端互相看得到對方
- 行數：每個崗位回報自己寫了幾行，空行和註解不算
