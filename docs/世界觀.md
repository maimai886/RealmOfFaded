# 世界觀

2026-09-17 第一版。

寫這份的規矩，先講清楚：

- **能借就不發明。**底層全部取自真實神話與真實制度，每一條在第 8 節標出處
- **留矛盾。**不同地方講的版本互相衝突而且都沒有錯，真實神話就是這樣
- **不寫死數字。**永遠不說「兩個傳統」「三位神」，只說「已知的」
- 我們自己加的部分在第 8 節單獨標出來，之後誰接手都分得清哪些有依據

## 1. 一句話

**土地是一具屍體，而它還沒死透。**

## 2. 大家都同意的部分

### 土地是身體

山是骨、河是血、土是肉。這不是比喻，是這個世界每一個地方都這樣講的事實，只是各地講的是**誰的**身體不一樣。

挖得越深，離那具身體的核心越近。所以地城不是遺跡，是解剖。

### 它被殺了，被切開，被埋在各處

一個很久以前的存在被殺害、肢解，碎塊分散埋進土裡。從那些埋藏點長出了穀物、樹、獸，以及**人**。

被埋的那些碎塊沒有完全死去。靠得太近的地方，土會失去顏色，聲音會變鈍，東西會忘記自己原本的形狀。這個現象叫**灰蝕**。

**「灰蝕」是那個現象的名字，不是那個存在的名字。**

### 沒有人直呼它的名字

各地都有稱呼，但各地的稱呼都是繞過去的說法：晨曦諸邦的教會說「那位安睡的」，霧嶺的人說「山裡的那個」。問他們真名是什麼，得到的答案是「說出來會被聽見」。

這不是設定上的神秘感，是**真實民俗常見的命名禁忌**。斯拉夫語系至今用「吃蜜的」稱呼熊，因為熊的本名被避諱到失傳。

### 每年有一段時間，世界要下去一趟

一年之中有幾個月，生長會停止。各地的解釋不同，但都同意**有東西每年得下去一趟，然後回來**。

### 有一年它可能不回來

那一天叫**枯季**。

枯季不是預言，是**日期**。它由星象定出來，曆法上標得清清楚楚，和播種收割的日子印在同一張表上。教會說那一天會來，學者說那只是曆法外插的產物，兩邊吵了幾百年。

**遊戲的名字要講的就是這件事。**

## 3. 已知的說法之一：晨曦諸邦

埋藏點在地底深處，離地表遠，所以灰蝕滲出來得慢。

這裡的做法是**壓住、記錄、傳下去**。有教會、有騎士團、有學院，靠制度把東西按在原地。他們認為碎塊接觸得越少越好，最好一輩子都不要下去。

他們的版本：那是一位被自己的兄弟殺害並肢解的神，妻子一塊一塊把他找回來，但找不齊。缺的那幾塊還在土裡。

制度的樣子取自真實的東西：

- **入會分階**，低階不知道高階知道的事 —— 厄琉息斯秘儀的做法
- **騎士團**有誓約、會規、分團據點
- **學院**分三階學位
- **行會**分學徒、職人、師傅，升師傅要交一件作品

轉職在這裡不是變強，是**取得資格**。

## 4. 已知的說法之一：霧嶺

埋藏點在山裡而且淺。壓不住，那口氣一直往外滲。

所以這裡改成**共處**：進山去，把那口氣引進自己身體裡練。用符、用呼吸、用身法去馴它。晨曦諸邦看這叫送死，霧嶺看晨曦諸邦叫掩耳盜鈴。

他們的版本不是一位神被殺，是**一位神被斬之後，五穀和蠶從祂的身體各部位長出來**，所以吃飯本身就是在吃祂。他們沒有「找回碎塊」的概念，因為碎塊早就在每個人肚子裡了。

制度的樣子一樣取自真實的東西：

- **山岳修行**：進山把山的力量納進身體，修驗道山伏的做法
- **官署**：陰陽師不是法師是公務員，有品級有值班表
- **方士**：煉丹、望氣、符籙

轉職在這裡不是取得資格，是**撐過去了**。

## 5. 玩家

**萌芽者。**

這個詞不是頭銜也不是稱號，是分類：從那具身體長出來的東西都叫萌芽者，路邊的草是，你打的史萊姆是，你也是。

所以這個世界**沒有救世主**。你不是被選中的，你只是又一株長出來的東西。NPC 對你沒有特別的期待，任務是工作不是天命。

## 6. 名字要有層次

**每個地方至少有兩個名字**：官方的和當地人講的。這兩個名字差在哪，就是那個地方的歷史。

現在地圖上的名字是官方名：晨曦鎮、萌芽草原、低語森林、碎石谷、灰蝕地窟。**當地的老名字還沒定**，定的時候規矩是：老名字要講地形或講誰先來的，不要講意境。

怪物的名字也一樣。現在的名字安全但空洞，講不出任何東西。之後補的時候照民俗走，不要照外型走。

## 7. 哪些寫死，哪些留白

### 寫死，不要改

- 土地是身體
- 有東西被殺、被肢解、被埋在各處，而且沒死透
- 灰蝕是現象的名字，不是那個存在的名字
- 沒有人直呼它的名字
- 每年有一段時間要下去一趟
- 枯季是由星象定出來的日期，不是預言
- 玩家是萌芽者，沒有救世主

### 留白，永遠不要封死

- **碎塊有幾塊。**永遠不說數字，只說「很多」
- **有幾個地方、幾種傳統。**永遠寫「已知的說法之一」，不要寫「兩個傳統」
- **它是不是真的會醒。**兩邊的說法都不能被證實
- **NPC 講的版本可以互相矛盾**，而且不要有任何一個 NPC 知道全貌

### 怎麼擴充

**一塊埋藏點 = 一個地方 = 一座地城 = 一套傳統 = 一條職業分支。**

| 要加什麼 | 怎麼加 |
|---|---|
| 新職業分支 | 挖出新的埋藏點，那裡長出新傳統 |
| 新大陸 | 同上，坐船或傳送過去 |
| 現有一轉多一條二轉 | 那個學派分裂了 |
| 新的怪物生態 | 那一塊滲出來的方式不同 |
| 三轉以後 | 越深入越接近沒被拆開的部分 |
