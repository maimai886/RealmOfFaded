# 交接指南

> 2026-09-27 起這份寫的是舊專案 `../Sproutia` 的程式。新專案照 `Rust重構規劃.md` 重寫，寫到哪一塊就把那一段改成新的。

## 1. 起手式

1. 讀 `CLAUDE.md`、`docs/遊戲總規格.md`、這份、`docs/進度.md`、`docs/未來方向.md`
2. 跑測試確認基準：`/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script res://tests/run_tests.gd`，現在是 1299 個，只有 `test_full_flow_over_websocket` 在本機 ping 延遲偏高時會紅
3. 美術管線測試：`/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python-exit-code 1 -P art_pipeline/tests/run.py`，61 個全過；系統的 python3 沒有 numpy 跑不動
4. 看畫面用 `--offline` 加 `--dev-shot`，指令在 `docs/開發指令.md`；不要自己開遊戲給自己玩
5. 看 `docs/決策紀錄.md`，不要推翻已定案的事，除非使用者要求

## 2. 使用者的期待

- 繁體中文溝通，講重點，先講結果和證據，不要長篇解釋
- 討厭半成品、假資料、籠統的功能；要求「線上遊戲基本水準」
- 美術標竿是仙境傳說和救世者之樹，覺得差太多會直接罵；美術做出第一張就要先給他看
- 打擊感很在意，之後要做 PVP
- 介面要安靜、透一點、不要像作業系統；2026-09-18 定案的樣子寫在 `src/ui/ui_theme.gd` 開頭
- 要求連續開發不停，告一段落講一聲就接著做
- 只有真的需要決定、要下載、付費、對外發布時才問

## 2.1 絕對不要做的事

- **不要用一般方式啟動遊戲，也不要砍掉或重開任何正在跑的遊戲或 7777 埠的伺服器。**
  使用者就在那裡玩。自己要驗證就用 `--offline` 加截圖，或連開發用的 7778 埠：`-- --server=ws://127.0.0.1:7778`
- **後台管理器是使用者自己的啟動器，不要替他按。**雙擊 `manager.bat` 或 `manager.command` 開，說明在 `docs/開發指令.md`。
  面板上的「同步到穩定版」更不要跑，只有使用者說要更新才同步
- **不要救回使用者刪掉的檔案**，不確定是誰刪的先問
- 提交和推送由 AI 自己做，規則在 `CLAUDE.md` 的協作與交付：一個提交一件事、訊息寫清楚、不准 force 推送

## 5. 做功能的標準流程

1. 先查成熟遊戲怎麼做，把來源和參數寫進文件
2. 資料先設計，放 `data/`，伺服器驗證用同一份資料；職業清單、上限、門檻一律讀資料不寫死
3. 邏輯放 `src/core/`，寫測試，含惡意輸入
4. 伺服器指令與事件加進 `docs/伺服器架構.md` 的契約，動到協定就升 `Protocol.CLIENT_VERSION`
5. 客戶端表現層訂閱事件
6. 介面照 `ui_theme.gd` 規則做，玩家看得到的字走文字表，用 `--dev-shot` 截圖自己檢查
7. 更新 `docs/進度.md`，給 commit 訊息

## 6. 常見坑

- 介面文字貼邊、描邊造成重影、字級混用：全部照 `ui_theme.gd`；HUD 壓在世界上的字用 `HUD_TEXT` 那組帶影子，視窗裡的字用 `INK` 那組不描邊
- 假資料：伺服器列表、人數、狀態都要真實
- 打擊感調整不要憑感覺，先用 `--dev-timing` 量時間軸；操作手感用 `--dev-feel` 逐幀量
- 參考作品的差距分析在 `docs/調查/操作手感參考.md`，裡面有還沒決定的事，別自己決定
- 換地圖每張圖是獨立 BattleWorld，增益要跨圖帶著走
- 鏡頭俯角和距離是整套美術的基準，改了要重算 `docs/美術技術框架.md` 的表，不要順手調
- 精靈圖格式改動要先改 `docs/精靈圖規格.md`，產圖端與 Godot 端一起改；像素圖的 `meta.json` 要寫 `filter`，匯入器和著色器讀同一個欄位
- 3D 場景牆不要高過 3.5 公尺，會擋住鏡頭。這條是 38 度俯角時訂的，
  2026-09-22 俯角改成 45 度之後牆擋到的範圍變小，要放寬得先實拍量過
- 職業改名要顯示名稱和代號一起換，舊代號進 `LEGACY_JOB_IDS`，`hero` 永遠指聖劍士
- `mock/` 是未追蹤的資料夾，不是專案的一部分，不要引用也不要提交
