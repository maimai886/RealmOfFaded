# 多國語系規劃

2026-09-16 使用者定案之後要出多國語系。還沒整批轉換，但從現在起新寫的程式一律照這份。

- 玩家看得到的字一律走文字表，不寫死在程式裡。表是 `locale/zh_TW.json`，介面用 `src/ui/texts.gd` 的 `Texts.text(鍵, {參數})` 取字
- 鍵用「畫面或模組.用途」，例如 `shop.not_enough_gold`；不用整句中文當鍵，句子一改翻譯就全部失效
- 組句子用具名參數，不用字串相接，因為不同語言的語序不一樣
- 伺服器不翻譯，回代碼不回句子；要代進句子的數字或 id 放在同一個回應的 `params`，名稱由客戶端自己查資料
- 資料裡的名稱、說明、NPC 對話，翻譯放另一份 `data/locale/<語言>/`，不塞回原本的資料檔
- 註解、log、稽核紀錄不翻譯

整批轉換會動到幾乎每個介面檔，等同時改介面的工作收斂之後一次做；到時候再決定要不要換成 Godot 的 `tr()`。
