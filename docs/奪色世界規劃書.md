# 奪色世界規劃書

2026-09-24 和使用者談出來的遊戲核心，2026-09-25 待定項目一次定案。舊專案做完了原型，Rust 版在 M4 照這份補回。

一句話：**世界是一幅畫，灰蝕把顏色吃掉只剩線稿；玩家是還沒上色的萌芽者，打倒偷走顏色的怪物把世界畫回來，用色魄強化自己、用色種改變招式。**

## 1. 世界觀

- 有顏色的地方是完成的水彩畫，被吃掉的地方只剩鉛筆線稿和畫紙
- 灰蝕的源頭在灰蝕地窟深處，地區王是它的分身，所以灰蝕永遠會長回來
- 萌芽者是從畫的種子長出來、還沒上色的人，白衣白褲的素體就是這樣；轉職是拿到自己的顏色
- 怪物被灰蝕感染、會吃顏色，身上鮮豔的顏色是偷來的；打倒牠們顏色回到世界，力量結晶成色魄，王的顏色結晶成色種
- 死亡就是被吃成線稿

## 2. 用語

| 用語 | 意思 |
|---|---|
| 屬性 | 規則：無、火、水、風、土、光、暗、時間、空間 |
| 代表色 | 屬性在特效和介面上的顏色，只是表現 |
| 彩度 | 顏色有多鮮豔，「奪色」奪的就是彩度；也是玩家的消耗型資源 |
| 線稿 | 彩度被吃光的樣子 |
| 色魄 | 卡片，一種怪一顆，插在裝備上給能力 |
| 色種 | 王掉的結晶，放在調色盤，給屬性和特性 |
| 調色盤 | 裝備頁面的另一頁，最多四顆色種 |
| 上色度 | 一張地圖整體被畫回來多少，全服共用 |
| 顏料 | 常見掉落，用來回彩度、捐壁畫、種花園 |

## 3. 屬性和顏色

2026-09-24 定案：屬性管規則，顏色管表現。
- 屬性和相剋表照 `data/elements.json`，不改
- 代表色只用在特效、技能圖示、介面色塊：火紅、水藍、風黃、土綠、光橙、暗紫、時間金、空間銀，無屬性沒有；光、時間、風三個暖色要調到分得開
- 染色、服裝、場景、NPC 的顏色完全自由，不代表屬性；黑白只留給灰蝕和線稿

## 4. 技能：形和屬性

- 技能本身只有「形」：魔力彈、箭矢、劍氣斬、護盾、衝刺、法陣，決定怎麼打、打哪裡；沒挑屬性就是無屬性
- 從調色盤挑一個屬性就換成那個屬性並多一個效果，例如魔力彈挑水變冰球、挑火變火球
- 每招只開放幾種屬性，技能資料寫 `colour_elements`，伺服器、提示框、挑屬性按鈕都照它擋。2026-09-25 使用者提：全開的話每招要設計九種變化
- 同一招可以放快捷列好幾格，每格挑不同屬性，技能等級共用
- 職業有固定屬性，寫在 `data/jobs.json` 的 `colour_element`，不佔調色盤四格；普攻用調色盤第一格，空著用職業固定屬性
- 冷卻：只有位移技和控場技有，這兩類不能上色；其他限制是彩度、SP、詠唱、收招
- 招式名稱：常用組合有專屬名字；其他用文字表的具名參數組成「水屬性劍氣斬」，不用字串相接

### 4.0 屬性效果

一張表管全部技能，技能只寫形的類型：近戰和飛彈是基準，範圍打折，持續地帶再打折。
命中效果和治療的附帶效果都在 `data/element_effects.json`：火燃燒、水緩速和機率冰凍、風彈到旁邊一個敵人、土降防、光補附近隊友、暗吸血；治療挑水解狀態、土加盾、火加攻擊、光補更多。時間和空間用屬性本身的遲滯和推開。

地面效果還沒做，等技能改地形一起：火燒草叢融冰面、水結冰面、風順風帶加速、土長石牆藤蔓、光照出線稿裡藏的東西、暗影子不易被發現、時間緩流、空間裂隙推人。

### 4.1 色槽

- 零格：被動和純數值增益；一格：大部分主動技；兩格：各職招牌技和大招，練滿才開第二格
- 不做三格以上，每招幾格寫在技能資料

### 4.2 兩格的組合

兩個屬性在組合表裡有定義就變組合效果，沒有定義就第一格決定屬性、第二格只給特性。法線兩張不同屬性的符疊在一起也查這張。組合表還沒進資料，第一版八組 2026-09-25 定案：

| 組合 | 名字 | 方向 |
|---|---|---|
| 火、水 | 蒸霧 | 霧裡的敵人命中下降，持續小傷害 |
| 火、風 | 爆雷 | 範圍爆炸，機率暈眩 |
| 水、風 | 凍雷 | 範圍傷害，機率冰凍 |
| 土、火 | 熔岩 | 燒人的熔岩地，走上去變慢 |
| 土、水 | 泥淖 | 大範圍緩速，機率絆住 |
| 土、風 | 沙暴 | 推開加降命中 |
| 光、暗 | 日蝕 | 單體大傷害，無視部分防禦 |
| 時間、空間 | 時裂 | 範圍裡的敵人短暫定住 |

### 4.3 四條線

架式、符、印記、信仰都留，只拿掉決定屬性的部分，逐招在 `docs/技能與流派.md`。
- 劍線架式只改普攻的節奏、範圍、推進；普攻回的彩度最多，用收尾技花掉
- 法線的符變成形：焰符、霜符、雷符合成爆符，另加炸完留地帶的留地符
- 弓線印記照舊、同隊共用，每種箭都是一格的飛彈
- 信線的治療一格，屬性換附帶效果

### 4.4 初心者

2026-09-25 使用者：「新手技能就是基本技能、急救、全彩爆發，後面兩個要去找 NPC 解任務得到」。
基本技能 9 級用技能點；急救找薇恩、全彩爆發找艾拉，見 `docs/轉職考試.md`。魔力彈歸術士。

## 5. 色魄和色種

加能力的是色魄，管屬性和變招的是色種，兩邊不重疊。

### 5.1 色魄

- 一種怪一顆，每種怪都掉；每顆只能插一種部位，照 RO 卡片，看怪的樣子猜得到插哪
- 部位七種：武器、盾、盔甲、頭飾、披風、鞋子、飾品；武器管攻擊、盾甲管防禦、鞋管移動迴避、頭飾飾品管能力值和功能
- 槽數跟著稀有度 0、1、2、3，在 `balance.json` 的 `colour_soul`；插上去拿不下來；精煉爆裝時一起消失
- 沒有等級或純度；掉率初值一般怪千分之一到三、菁英百分之一、地區王百分之五到十，照實際調
- 南門四顆的能力在 `data/items.json`

### 5.2 色種和調色盤

- 2026-09-24 使用者定：色種不插裝備，放在裝備頁面另一頁的調色盤，最多四顆
- 色種帶屬性和特性，放上去就生效，隨時拿下來換，不會消失；精煉爆裝不影響色種
- 技能欄每一招從調色盤挑一個屬性或留空；拿掉那顆色種時那招退回無屬性；可以存幾套配裝一鍵切換
- 手機在配裝畫面一次設好每招的屬性，戰鬥中不用碰
- 角色外觀跟著調色盤，代表色出現在衣服點綴和施法光上

### 5.3 色種從哪裡來

- 只從王來，2026-09-24 使用者定；地區王掉 20%，每個角色第一次參與打倒某隻王直接給一顆
- 帶那隻王的屬性和專屬特性，例如木樁王土屬性、特性年輪：技能每放一次疊一層威力，數字在 `balance.json` 的 `seed_traits`
- 分五階跟著王的等級段，高階要對應的裝備等級；深處的王才掉雙屬性色種
- 每個屬性從前期到後期都要有王會掉，排怪物名單時照這條檢查；第一顆在萌芽草原的木樁王
- 王的掉落都在地上，歸傷害最高的一方，隊伍算一方，擁有權 10 秒，一般怪 3 秒；隊伍裡照個人或隨機分配，見 `docs/隊伍規格.md`

## 6. 彩度

2026-09-24 使用者定：彩度是消耗型資源，保留打中怪會漲、歸零技能褪色、全彩爆發。待在灰色的地方會慢慢死，用顏色打架要付顏色。數字在 `docs/自有數值系統.md` 第 10 節。

- 掉：待在線稿區，越灰掉越快；放有色技能，詠唱完成時才扣。彩度沒了繼續待在線稿區改扣 HP
- 回：站在彩色的地方、打中怪、打倒怪、治療和擋傷、喝顏料；換屬性打回得比較多
- 歸零時有色技能褪回無色版本、改耗 SP
- 強行上色，2026-09-24 使用者選的：長按技能鈕用 HP 付彩度，會把自己放死；連續強行越來越貴；付出去的 HP 在血條上變線稿，治療補不回來，彩度回來才恢復；長按時先顯示會吃掉多少血
- 全彩爆發：每個職業一開始就有、不佔點，彩度 90 以上才能放、不能強行；以自己為中心半徑 4 公尺，對每隻怪自動挑手上最剋牠的屬性，放完彩度歸零、那一圈地面彩色 20 秒
- HP 越低角色越接近線稿，歸零時完全變線稿就是死亡；用換色著色器做，不多畫圖

## 7. 技能改地形

- 冰把水面凍成路、火燒掉草叢、土長出藤蔓橋或牆，三十秒到一分鐘褪掉，是戰術層不是永久改地圖
- 隊友的效果可以疊，給組隊直接的理由
- 伺服器一公尺一格記地面狀態，只傳有變化的格子，不存檔

## 8. 地圖上色度

| 時間 | 範圍 | 管什麼 |
|---|---|---|
| 幾秒到一分鐘 | 個人與隊伍 | 技能改地形、彩度條 |
| 幾小時 | 全服每張地圖 | 上色度的拉鋸 |
| 永久 | 個人 | 主線修復的地方、色魄、色種、畫冊 |

- 上色度是整張圖的平均彩度，伺服器定時存檔
- 灰蝕和會吃色的怪一直往回吃，永遠塗不完；地圖上人少時怪吃得慢，避免小伺服器永遠是灰的
- 地圖越灰，怪越痛、掉落越好；越彩色，附近城裡的商店越便宜，店在 `shops.json` 寫 `colour_maps`
- 上色度掉到警報線全服廣播、地區王醒來，回到安全線再廣播一次
- 常數全在 `balance.json` 的 `colour`；怪物寫 `eats_colour` 會吃腳下的顏色，寫 `colour_release` 的王死了整張圖亮回來
- 主線修復的地方用個人畫面，每人看到的晨曦鎮照自己的進度

## 9. 防止大家只玩同一套

- 屬性相剋，換地圖換王就要換屬性
- 菁英和王會適應最常被打的屬性，脫戰歸零、不回血，PVP 關掉，2026-09-25 定案
- 組合招需要隊伍裡有不同屬性；有些路要特定特性才過得去；換裝成本低
- 伺服器記錄色魄、色種和組合的使用率，太集中就改資料

## 10. 其他玩法

- 線稿裡藏東西：地圖寫 `colour_secrets`，那裡先被吃灰才算藏著，塗回九成冒出獎勵
- 畫冊圖鑑：每種怪一格，照打倒的隻數從線稿上色，塗滿寫出故事和會掉哪顆色魄；隻數和故事在 `monsters.json` 的 `codex`
- 全服壁畫：找艾拉捐顏料，分塊照順序畫，畫完一塊全服永久加成，資料在 `data/mural.json`
- 色種花園：找蜜拉種顏料，現實時間幾小時後收成更濃的顏料，資料在 `data/garden.json`
- 死亡變線稿：隊友能把你畫回來，沒人救就用死亡視窗回主城；2026-09-25 使用者定死了不能動
- 讀取畫面是地圖徽記從線稿照進度上色；捏角從線稿開始，挑髮色、膚色、服裝色一層層上色
- 2026-09-24 使用者看過「每個系統都在講畫」的點子，只留讀取畫面和捏角；職業是畫具、HP 是顏料管這類覺得太硬要，不做
- 排在原型之後：灰蝕入侵、每日修復委託、玩家暫時偷怪物屬性

## 11. 美術

大部分靠著色器：角色、怪物、地面褪色和變線稿共用一套，線稿從彩色貼圖自動抽，不畫第二套。
新圖只有顏料、色種、色魄的圖示和少量地形物件。全白的怪全彩和線稿看起來差不多，出圖要避開整隻白。

## 12. PVP、交易、外掛

- PVP 照樣付彩度；PVP 地圖沒有上色度，站著不掉也不回，只能靠打中和打倒對手回
- 色魄和色種都能交易
- 一小時打倒超過門檻的怪或王寫 `suspect.farming` 稽核，只記不罰，門檻在 `balance.json` 的 `farming_watch`

## 13. 還沒定

- 代表色的實際色值
- 彩度掉和回的速度、每招的彩度和 SP 消耗、強行上色的重置時間
- 色魄掉率、色種五階的等級段、組合表每一組的倍率
- 怪物名單和王的屬性分布：一種怪一顆色魄、色種只從王來，每多一種怪就多一套美術，先排名單再定產量
