# 奪色世界規劃書

2026-09-24 和使用者一路談出來的遊戲概念，2026-09-25 使用者把待定項目一次定案，開始照第 14 節做原型。
和現行規格衝突的地方列在第 13 節，做到那一塊之前先把那份文件改成一致。

一句話：**世界是一幅畫，灰蝕把顏色吃掉只剩線稿；玩家是還沒上色的萌芽者，打倒偷走顏色的怪物、把世界畫回來，同時用色魄強化自己、用色種改變自己的招式和地形。**

---

## 1. 世界觀

- **世界是一幅畫。** 有顏色的地方是完成的水彩畫，被吃掉的地方只剩鉛筆線稿和畫紙。
- **灰蝕在擦掉這幅畫。** 它的源頭在灰蝕地窟深處，各地的地區王是它的分身，所以灰蝕永遠會長回來。主線的長期目標是往源頭推進。
- **萌芽者是從畫的種子裡長出來、還沒上色的人。** 白衣白褲的素體就是這個樣子，轉職是拿到自己的顏色，裝備和服裝是往身上加顏色。
- **怪物是被灰蝕感染、會吃顏色的生物。** 牠們身上鮮豔的顏色是偷來的。打倒牠們，顏色回到世界，偷來的力量結晶成色魄掉下來，王身上的顏色結晶成色種。
- **死亡就是被吃成線稿。**
- 對話裡已經有「芽核」「晨曦幼苗」「灰蝕是什麼」，設定接得上，不用改現有台詞。

## 2. 用語

玩家看得到的詞一律照這張表，新寫的字走文字表。

| 用語 | 意思 |
|---|---|
| 屬性 | 規則本身：無、火、水、風、土、光、暗、時間、空間九種，相剋表不變 |
| 代表色 | 每個屬性在特效和介面上用的顏色，只是表現，不是規則 |
| 彩度 | 顏色有多鮮豔。世界、角色、怪物都有，「奪色」奪的就是彩度 |
| 線稿 | 彩度被吃光的樣子，只剩鉛筆線和畫紙 |
| 灰蝕 | 把世界吃成線稿的東西 |
| 色魄 | 卡片。怪物掉的結晶，一種怪一顆，插在裝備的固定部位，給能力 |
| 色種 | 王掉的結晶，放在裝備頁面的調色盤，最多四顆，給屬性和技能特性 |
| 調色盤 | 裝備頁面裡的另一頁，放色種，決定技能能挑哪些屬性 |
| 彩度條 | 消耗型資源，放有顏色的技能和待在線稿區會掉，不夠就扣 HP，見第 6 節 |
| 上色度 | 一張地圖整體被畫回來多少，全服共用 |
| 顏料 | 常見掉落，顏色照怪物屬性，用來染色、做藥水、捐給壁畫 |

## 3. 屬性和顏色：方案 C

2026-09-24 定案。考慮過三種做法：顏色完全等於屬性、兩者完全分開、屬性管規則顏色管表現，選第三種。

**為什麼不讓顏色直接等於屬性**：會撞到五個地方。所有看得到的顏色都會被當成規則，染紅衣服算不算火屬性說不清；怪物「偷了什麼顏色」和「本身是什麼屬性」變成兩件事；顏料的混色邏輯和屬性組合對不上，火加水不會是暗；「無色」在主題裡代表死亡，在規則裡只是普通攻擊；時間和空間本來就不是顏色。

**規則**：

- **屬性照舊。** 九種、相剋表、等級縮放全部沿用 `data/elements.json`，不改名，土和風都保留，時間和空間保留。
- **每個屬性有一個代表色，只用在特效、技能圖示、介面色塊上。** 2026-09-24 定案：火紅、水藍、風黃、土綠、光橙、暗紫、時間金、空間銀，無屬性沒有代表色。實際色值由美術做特效時定，光、時間、風三個暖色要調到分得開。
- **染色、服裝、場景、NPC 的顏色完全自由**，不代表任何屬性。
- **奪色奪的是彩度，不是某一種顏色。** 怪物把附近吸成線稿；怪物本身是什麼屬性照牠的本性決定。
- 黑白保留給灰蝕和線稿，任何屬性的代表色都不用黑白。

## 4. 技能：形和屬性

技能本身只有「形」，屬性和特性由色種帶進來。

- **形**：魔力彈、箭矢、劍氣斬、護盾、衝刺、法陣這類，決定怎麼打、打哪裡。沒插色種時是無屬性。
- **插上色種**：換成那個屬性，再加上那顆色種的特性。魔力彈插水屬性變冰球，插火屬性變火球，插風屬性變雷球。
- **每招限定能插的色種**：2026-09-25 使用者提：全部屬性都能插的話每招要設計九種變化，所以每招只開放幾種屬性。技能資料寫 `colour_elements`，伺服器、單機、技能說明的挑屬性按鈕都照 `Palette.can_use_element` 擋，技能的提示框寫出能插哪幾種；沒寫的技能暫時全部都能插。魔力彈開放火、水、風、土。
- **同一個屬性放進不同的形，效果不同**，照形的類型套規則，不一招一招手寫：

| 形的類型 | 拿到屬性時 | 水屬性的例子 |
|---|---|---|
| 近戰 | 換屬性和命中效果 | 冰刃，命中緩速 |
| 飛彈 | 換屬性和命中效果 | 冰球，命中緩速 |
| 範圍與符 | 換屬性、命中效果，炸完留地面 | 冰符，炸完留一塊冰面 |
| 牆與陷阱 | 換材質 | 冰牆，怪撞到會滑開 |
| 治療與輔助 | 換附帶效果 | 淨化，解除負面狀態 |

- 現有的火焰箭、冰霜箭、雷光箭合成一個「箭矢」，屬性由色種決定。其他同類技能照這個方向收斂。
- **職業有一個固定屬性當預設**，沒挑屬性的技能照樣是無屬性，職業的差別在它有哪些形。2026-09-25 定案：

| 線 | 職業和固定屬性 |
|---|---|
| 初心者 | 無 |
| 劍線 | 劍侍土；聖劍士、勇者光；劍客、劍豪風 |
| 法線 | 術士火；巫師、大賢者水；方術士時間；陰陽師空間 |
| 弓線 | 斥候、神射手風；獵人土；刺客、忍者暗 |
| 信線 | 信徒、神職者、神諭官光；行者、鬥聖火 |

- **同一招可以放在快捷列好幾格**，每格挑不同屬性，技能等級共用。術士把爆符放三格，就是火符、水符、風符。
- **冷卻，2026-09-25 定案**：有色技能和無色的攻擊技都不設冷卻，限制是彩度、SP、詠唱和收招。
  只有位移技和控場技留冷卻，這兩類是零格、不能上色。早先表上「衝刺在路徑上留地面效果」拿掉，有顏色又沒冷卻的衝刺等於無限位移。

### 4.0 屬性效果表

2026-09-25 定案：**一張表管全部技能**，技能資料只寫形的類型，不一招一招寫屬性效果。
形的類型決定效果多強：近戰和飛彈是基準，範圍打折、持續地帶再打折，數字放資料。

| 屬性 | 命中效果 | 地面 |
|---|---|---|
| 火 | 燃燒，每秒持續傷害 | 燒掉草叢、融掉冰面 |
| 水 | 緩速，機率冰凍 | 冰面，水面凍成路 |
| 風 | 彈到旁邊一個敵人 | 順風帶，走上去加速 |
| 土 | 降防 | 長出石牆或藤蔓 |
| 光 | 補附近隊友一點血 | 照亮，線稿裡藏的東西現形 |
| 暗 | 吸血 | 暗影，站在裡面不容易被發現 |
| 時間 | 遲滯，攻速和詠唱變慢 | 緩流，裡面的敵人變慢 |
| 空間 | 拉近或推開 | 裂隙，把踩到的敵人推出去 |
| 無 | 沒有 | 沒有 |

表放 `data/element_effects.json`，和 `data/elements.json` 的相剋表分開。2026-09-25 火、水、風、土、光、暗六種做好了，規則在 `src/core/colour_effects.gd`，只有挑了屬性的技能才有；時間和空間沿用屬性本身就有的遲滯和推開。地面那一欄還沒做，等技能改地形一起做。

### 4.1 色槽

- **零格**：被動技能、純數值增益。它們沒有形，加屬性只會變成一堆小數字。
- **一格**：大部分主動技能，包括攻擊、改地形、治療輔助。
- **兩格**：各職業的招牌技和大招，技能練滿才開第二格。
- **不做三格以上。** 一招疊三種屬性，玩家自己都記不住它現在是什麼。
- **普通攻擊**不用挑，用調色盤第一格的屬性，見第 5.2 節。
- 每個技能有幾格寫在技能資料裡，調整改資料不改程式。

### 4.2 兩格的組合

- 兩個屬性在組合表裡有定義時，變成組合效果，兩顆色種的特性都保留。
- 組合表沒有定義時，第一格決定屬性，第二格只提供特性。
- 組合表放在資料裡。組合是設計出來的效果，不用顏料的混色邏輯推。
- 法線兩張不同屬性的符疊在一起，查的也是這張表，見第 4.4 節。
- **第一版八組，2026-09-25 定案**：

| 組合 | 名字 | 方向 |
|---|---|---|
| 火、水 | 蒸霧 | 霧裡的敵人命中下降，持續小傷害 |
| 火、風 | 爆雷 | 範圍爆炸，機率暈眩 |
| 水、風 | 凍雷 | 範圍傷害，機率冰凍 |
| 土、火 | 熔岩 | 留一塊燒人的熔岩地，走上去變慢 |
| 土、水 | 泥淖 | 大範圍緩速，機率絆住 |
| 土、風 | 沙暴 | 推開加降命中 |
| 光、暗 | 日蝕 | 單體大傷害，無視一部分防禦 |
| 時間、空間 | 時裂 | 範圍裡的敵人短暫定住 |

### 4.3 招式名稱

- 常用組合有專屬名字，例如火球、冰球，寫在技能加屬性的對照表裡。
- 沒有專屬名字的自動組成「水屬性劍氣斬」這類名字，用文字表的具名參數組，不用字串相接。

### 4.4 四條線的核心機制，2026-09-25 定案

架式、符、印記、信仰四個機制都留，只拿掉它們決定屬性的部分，屬性一律從調色盤來。
`docs/技能與流派.md` 照這節改寫。

- **劍線，架式**：架式只改普攻的節奏、範圍、推進，不改屬性。收尾技是一格的近戰。普攻命中回的彩度最多，劍線是攢彩度的職業，用收尾技把彩度花掉。
- **法線，符**：符變成形。焰符、霜符、雷符合成一個「爆符」，另外加一個炸完留一塊地帶的「留地符」。爆符放在快捷列三格各挑一個屬性，就是以前的三張符。兩張不同屬性的符疊在一起查第 4.2 節的組合表，合符表不再另外一張。
- **弓線，印記**：印記照舊，同隊共用。每種箭都是一格的飛彈，屬性從調色盤挑。
- **信線，治療和守護**：治療技一格，屬性換附帶效果：水解負面狀態、土加護盾、火加攻擊、光補得更多，其他屬性照第 4.0 節的表。
- **二轉、三轉**照上面四條轉，逐招的對照寫在 `docs/技能與流派.md`。

## 5. 色魄和色種

2026-09-24 定名：**色魄是卡片，色種放在調色盤**，分成兩套。
加能力的是色魄，管屬性和技能變招的是色種，兩邊不重疊。

### 5.1 色魄：卡片

- **一種怪一顆，每隻怪都會掉，不只王。** 怪物被打倒時，偷走的顏色連同牠的魂魄結晶掉下來，所以帶著這隻怪的能力。
- **掉率稀有但不像 RO 的萬分之一。** 初值提議一般怪千分之一到千分之三、菁英約百分之一、地區王百分之五到十，照每小時能打幾隻再調，常數放 `data/balance.json`。
- **每顆色魄只能插一種部位，照 RO。** 部位就是現有的七種：武器、盾、盔甲、頭飾、披風、鞋子、飾品，寫在色魄資料裡。怪物的樣子決定牠插哪裡，玩家看怪就猜得到。
- **內容是能力**：能力值、對某類怪加傷、攻擊或受擊時機率觸發效果。效果照部位設計：武器管攻擊、盾和盔甲管防禦、鞋子管移動和迴避、頭飾和飾品管能力值和功能。
- **裝備的色魄槽數跟著稀有度**：普通 0、精良 1、稀有 2、傳承 3，和《裝備成長》的稀有度決定詞綴格數同一個規則，數字在 `balance.json` 的 `colour_soul`。
- **精煉爆裝時色魄一起消失**，見第 17 節第 1 條。
- 色魄沒有純度或等級，一顆就是一顆，和 RO 的卡片一樣。

南門四隻：

| 怪物 | 部位 | 能力 |
|---|---|---|
| 萊姆 | 盾 | 受擊有機率把一部分傷害彈回去 |
| 小樹苗 | 頭飾 | 站著不動時多回血 |
| 水晶兔 | 鞋子 | 迴避和移動速度增加 |
| 木樁王 | 盔甲 | 最大 HP 大幅增加、受到的傷害降低，王專屬 |

### 5.2 色種：放在調色盤

2026-09-24 使用者定的：**色種不插在裝備上，裝備頁面另外開一頁調色盤，最多放四顆。**
早先寫過一件裝備一格色種，七個部位加起來調色盤會有八種屬性，太多了，所以改掉。

- **色種帶兩樣東西**：屬性和特性。能力交給色魄和詞綴。
- **放上調色盤就生效**：屬性給技能挑，特性跟著那個屬性走。
- **可以隨時拿下來換**，不會消失，拿下來回到背包。以前「換色種就把舊的蓋掉」的寫法作廢。
- **色種不在裝備上，所以精煉爆裝不影響色種**，只有色魄會跟著裝備一起消失。
- **普通攻擊的屬性**：用調色盤第一格；那一格空著時用職業固定屬性，初心者是無屬性。2026-09-25 定案。

### 5.3 色種從哪裡來，定案

2026-09-24 使用者定的：**每隻怪都掉色魄，王除了色魄還會掉色種。色種只從王來。**
考慮過一般怪掉顏料再做成色種，沒採用。

- **王掉的色種帶這隻王的屬性和專屬特性**，例如木樁王掉土屬性、特性年輪：技能每用一次疊一層威力。
- **色種的強度跟著王的等級**：高等地區的王掉的色種特性更強、有裝備等級需求。這是讓玩家往高等地區推進的主要理由。
- **深處的王才會掉雙屬性色種**，一顆填滿技能的兩格或提供組合特性。
- **王要夠多、屬性要分布夠廣**：色種只從王來，每個屬性在前期到後期都要有王會掉，不然玩家湊不出調色盤。排怪物名單時照這條檢查，見第 17 節第 5 條。
- **第一顆色種在萌芽草原的木樁王**，新手很早就能體驗插色種變招。
- **掉率，2026-09-25 定案**：地區王掉色種 20%。每個角色第一次參與打倒某一隻王，那顆色種直接進背包，不用去地上搶。
- **色種分五階**，跟著王所在的等級段，第幾階就要對應的裝備等級，數字放 `data/balance.json`。
- 顏料照舊是常見掉落，用在染色、藥水、捐給壁畫，不拿來做色種。
- **王的掉落歸誰，定案**：
  - 所有道具都掉在地上，王也一樣，撿起來的時候才看資格。這和現行《隊伍規格》第 5 節的做法一致。
  - **有資格撿的是傷害最高的那一方**：傷害最高的是隊伍，就是那個隊伍的成員；傷害最高的是單人，就是那個人。其他人要等擁有權時間過了才撿得到。
  - **隊伍裡照隊伍的分配設定**：設成隨機，撿起來的東西隨機給一個隊員；設成個人，誰撿到就是誰的。
  - 王的擁有權時間 10 秒，一般怪維持 3 秒，2026-09-25 定案。
  - 隊伍分配只有個人和隨機兩種，2026-09-24 已經照這樣改好，見《隊伍規格》第 5 節。

### 5.4 調色盤

採用**調色盤**：調色盤決定你有哪些屬性，技能欄決定每招用哪一個。考慮過每個技能各插一顆，太難操作；也考慮過全身決定一個角色色，會讓所有技能變同一個屬性，組合玩法就沒了。

- 調色盤是裝備頁面裡的另一頁，最多放四顆色種。職業固定屬性另外算，不佔這四格，2026-09-24 定案。
- 技能欄上每一招從調色盤挑一個屬性，或留空用無屬性。選一次就記住；拿掉那顆色種時，那招自動退回無屬性。
- 可以存幾套配裝一鍵切換。
- **角色外觀跟著調色盤**：代表色出現在衣服點綴和施法光上，別人一眼看得出你的打法。

### 5.5 一件裝備上的東西

| 層 | 從哪來 | 管什麼 |
|---|---|---|
| 基礎數值 | 裝備本身 | 攻擊、防禦 |
| 詞綴 | 掉落時隨機，見《裝備成長》 | 數值 |
| 色魄 | 怪物掉，零到四格 | 能力 |
| 精煉 | 精煉砂 | 往上推數值，+5 以上會爆 |

色種不在裝備上，放在調色盤那一頁。色魄和詞綴都可以加能力值，照 RO 不刻意分工。
八種屬性詞綴改成加數值，武器本身也不再帶屬性，2026-09-25 定案，見第 17 節第 2 條。

## 6. 彩度條

2026-09-24 使用者定的：**彩度是消耗型的資源，同時保留打中怪會漲、歸零技能褪色、全彩爆發。**
待在灰色的地方會慢慢死，用顏色打架要付出顏色，打怪把顏色搶回來，奪色的主題直接變成戰鬥規則。

### 6.1 怎麼掉，定案

- **待在線稿區會慢慢掉。** 地圖上色度越低掉越快，彩色的地方不掉。
- **放有顏色的技能要消耗彩度。** 技能從調色盤挑了屬性就是有顏色；沒挑的無色技能不耗彩度。
- **彩度不夠就扣 HP。** 彩度歸零後，繼續待在線稿區、或硬放有顏色的技能，改成扣 HP。
- **有顏色的技能不設冷卻。** 例如火箭術想放就放，限制它的是彩度和詠唱時間，詠唱照舊。

### 6.2 怎麼回，定案

- **站在彩色的地方**：地圖上色度高的區域、自己或隊友技能塗過的地面，會慢慢回。
- **打中怪物**：每打中一下搶回一點顏色。
- **打倒怪物**：怪物死時把偷走的顏色吐出來，附近的人回一些彩度。
- **治療和擋傷**：補了多少血、擋下多少傷害也算搶回顏色，補師不打怪也回得了彩度，2026-09-25 定案。
- **顏料**：常見掉落的顏料可以直接用來回彩度，像藥水一樣，顏料除了染色也有日常用途。

### 6.3 歸零和全彩爆發，定案

- **彩度歸零時技能褪色**：有顏色的技能退回無色版本，耗 SP，直到彩度回來。
- **全彩爆發**：一招把現有的彩度全部榨乾，彩度越多威力越大。放完彩度歸零、技能褪色，要重新打怪累積。
  - **彩度 90 以上才能放**，上限 100，所以威力差距只在 90 到 100 之間，重點是「攢到九成就能放」。
  - **它是一個技能，初心者一開始就有**，每個職業都帶著，不佔職業技能點。
  - **範圍和威力，2026-09-25 定案**：以自己為中心半徑 4 公尺，彩度 90 時倍率 500%、100 時 700%，中間照比例。對每隻怪自動用自己手上最剋牠的屬性，手上的屬性是調色盤加職業固定屬性。放完那一圈地面變彩色 20 秒，站在上面回彩度。

### 6.4 HP 和線稿，定案

- **HP 越低，角色越接近線稿**：HP 滿時全彩，一路褪到歸零時完全變成線稿，就是死亡。
- 用現有的換色著色器照 HP 比例降彩度、加線稿，不用多畫圖。
- 早先「彩度越低角色越灰」改成跟著 HP 走，畫面的意思更直接。

### 6.5 SP、冷卻、放死

- **SP 保留**：無色技能和增益技能耗 SP，有顏色的招耗彩度，玩家一看就知道哪條管什麼。
- **所有有色技能都不設冷卻，大招也一樣**：限制只有彩度和詠唱。打王比的是彩度管理：什麼時候放大招、什麼時候退回彩色的地方補。
- **可以把自己放死，用強行上色**，2026-09-24 使用者選的：彩度歸零時技能預設褪色；長按技能鈕可以強行上色，改用 HP 付彩度，放出有顏色的版本，會把自己放死。兩條規則都保留，玩家自己決定拚不拚。

### 6.6 強行上色的換算

- **照比例算**：彩度上限所有人一樣，技能的彩度消耗就是佔上限幾成。強行上色時 HP 付同樣的比例再乘換算倍率，初值 1.5。例如一招要一成彩度，強行放就扣最大 HP 的 15%。前期後期、坦和法師一樣痛，不會因為 HP 堆高變便宜。
- **連續強行越來越貴**：幾秒內連續強行，倍率每次往上加，初值 1.5、2、2.5，停手幾秒回到 1.5。偶爾拚一招可以，一直靠扣血放技能撐不下去。
- **付出去的 HP 變成線稿，補不回來**：強行上色扣掉的那段 HP 在血條上變成灰色線條，暫時降低最大 HP，治療補不回來；只有彩度回來時那段才跟著恢復。不這樣做的話，補師無限補血就等於無限放有顏色的技能，彩度就沒意義了。
- **詠唱完成時才扣**：詠唱中取消不扣，誤按還能反悔。扣到歸零就是死亡。
- **先看清楚再拚**：長按時技能鈕和血條預先顯示這一招會吃掉多少血。
- **全彩爆發不能強行**：歸零時沒有東西可以榨，不能用 HP 換，否則強行爆發會變成最強的一招。
- 倍率、加倍幅度、重置時間、線稿 HP 恢復速度都放 `data/balance.json`，之後照實際打起來調。

### 6.7 還沒定

- 掉和回的速度、每招的彩度消耗和 SP 消耗，數字放 `data/balance.json`。
- 大招沒有冷卻，每招的彩度消耗和詠唱時間就是唯一的平衡手段，要照打王的實測來調。

## 7. 技能改變地形

- 地形怎麼變由技能的形和屬性決定：冰把水面凍成路、火燒掉草叢、土長出藤蔓橋或牆。
- 技能改出來的地形是暫時的，三十秒到一分鐘褪掉。它是戰術層，不是永久改地圖，大家各打各的不會吃掉彼此的玩法。
- 隊友的效果可以疊：一個人放水、一個人放冰，水面凍成路。這給組隊很直接的理由。
- 伺服器用一公尺一格記錄地面狀態，只傳有變化的格子，戰鬥狀態不存檔。

## 8. 線上遊戲的三層時間

地圖是大家共用的，所以顏色分三種時間長度，各管不同的事，才不會有人塗完之後後面的人沒事做。

| 時間 | 範圍 | 管什麼 |
|---|---|---|
| 幾秒到一分鐘 | 個人與隊伍 | 技能改地形和彩度條，戰術 |
| 幾小時 | 全服每張地圖 | 地圖上色度的拉鋸 |
| 永久 | 個人 | 主線修復的地方、職業屬性、色魄、色種、畫冊 |

### 8.1 地圖上色度

- 每張地圖一個全服共用的百分比，伺服器記錄，每幾分鐘存一次。
- 灰蝕會一直慢慢往回吃，怪物也會吸附近的顏色，所以永遠塗不完。
- **地圖越灰**：怪更多更強、掉落更好，大家在這張圖的彩度條一直往下掉。
- **地圖越彩色**：NPC 攤位開得多、商品打折、採集點變多，大家彩度回得快、上限高。
- 掉到很灰時全服廣播，地區王出現；打倒牠整張地圖一次亮回來。
- 每張地圖有上色貢獻榜，公會可以認養一張地圖維持它的顏色。

### 8.2 個人進度

- 主線劇情裡修復的地方用個人畫面：每個人看到的晨曦鎮照自己的進度越來越完整。
- 轉職拿到職業屬性、身上的色魄、色種和染色都是永久的。

## 9. 防止大家只玩同一套

- **屬性相剋**：換地圖、換王就要換屬性。
- **每張地圖被吃掉的東西不同**：某些地圖某些屬性特別弱或拿不到。
- **怪物吃掉你用最多的屬性**：只有菁英怪和王會。同一屬性打中牠每 20 下，牠對這個屬性的抗性加 10%，最多加 40%，脫離戰鬥歸零，不會因此回血。2026-09-25 定案並做好，數字在 `balance.json` 的 `adaptation`，這同時是劇情和平衡機制。
- **換屬性攻擊漲比較多彩度**，組合招需要隊伍裡有不同屬性。
- **功能型特性**：副本和地形有些路要特定特性才過得去，不只比傷害。
- **換裝成本低**，鼓勵實驗。
- **營運**：伺服器記錄色魄、色種和組合的使用率，太集中就改資料調整。

## 10. 其他玩法

- **色種花園**：城裡有自己的小花園，把多的顏料種下去，現實時間幾小時後收成高一階的顏料。給不打怪的時間一個回訪理由。
- **線稿裡藏東西**：灰蝕區只有線稿看不清細節，塗回顏色後才出現被藏起來的橋、寶箱、捷徑、NPC。
- **玩家也能奪色**：某些職業能暫時偷怪物的屬性和能力；或把怪吸成線稿讓牠變弱，但掉的顏料也比較少，讓玩家取捨。
- **全服壁畫**：晨曦鎮廣場一幅巨大壁畫，全服捐顏料一起完成，每完成一塊全服得到加成或開放新內容。
- **畫冊圖鑑**：怪物圖鑑一開始只有線稿，打得越多填得越滿，全彩時解鎖故事和色魄提示。
- **死亡變成線稿的自己**：死後變成線稿，隊友能把你畫回來，沒人救就用死亡視窗回主城。2026-09-25 使用者定案死了不能動：線稿的樣子保留，不做線稿走回噴泉，和伺服器「死人不能移動」的防作弊規則一致。

## 11. 美術需求

這個概念大部分靠著色器，不靠多畫圖。

**不用新圖**：

- 角色、怪物褪色和變線稿：降彩度加抽線，一段著色器全部共用。
- 地圖被吃成線稿：地面、植物、建築照範圍混合彩色和線稿版本。
- 線稿版本從彩色貼圖和圖集自動抽出來，不另外畫第二套。
- 怪物死亡噴出顏色：現有的粒子特效。

**少量新圖**：顏料、色種、色魄的道具圖示，色魄可以直接用怪物圖、地面效果的筆刷紋理一張套多色、藤蔓牆冰面這類地形物件。2026-09-25 道具圖示做好：顏料和色種用 `art_pipeline/icons_v2/colour_icons.py` 在 Blender 算，色魄是 `soul_cards.py` 合成的黃銅卡片，卡面是怪物圖集朝正面那一格。

**本來就要做、和這個概念無關**：場景畫風定稿，2026-09-24 用 Firefly 以城鎮截圖為參考已經證明能保住構圖；素體分件。

## 12. 資料和伺服器

- 全部伺服器權威：彩度、上色度、色魄、色種、地形狀態都由伺服器算，客戶端只送指令、只畫結果。
- `data/elements.json` 不動。代表色另外放一張對照表。
- 新增色魄資料：怪物、部位、能力、掉率。
- 新增色種資料：哪隻王掉、屬性、特性、階級、裝備需求。
- 裝備加色魄槽數；角色存檔加調色盤四格。
- `data/skills.json` 每個技能加形的類型和色槽數；加技能與屬性的名稱對照表和兩格組合表。
- 怪物掉落加色魄和顏料，王另外加色種。
- 地圖加上色度的起始值、回復與流失速度。

## 14. 原型和順序

先做最能展示核心玩法、美術成本最低的，好不好玩試了再擴大。

1. **褪色著色器**：角色、怪物、地面共用。做完就能在遊戲裡看到線稿和上色。2026-09-25 做好：
   - 角色和怪物在 `sprite_recolor.gdshaderinc`，`colour_amount` 跟著 HP，前半段褪色、後半段換成畫紙加鉛筆線，死亡整個變線稿。
   - 地面、植物、建築用一張全螢幕後製 `colour_field_post.gdshader`，查 `colour_field.gd` 一公尺一格的彩度；角色寫模板值，後製跳過它們。
   - 白色系的怪物像水晶兔，全彩和線稿看起來差不多，之後出圖要避開整隻白。
2. **萌芽草原原型**：小樹苗走過的地方變成線稿、打倒後恢復、掉色魄；打倒木樁王掉土屬性色種，魔力彈能用它變招。2026-09-25 做到：
   - 地面彩度在 `src/core/colour_map.gd`，伺服器和單機共用，怪物資料寫 `eats_colour` 就會吃腳下，死掉那一圈亮回來，常數在 `balance.json` 的 `colour`。
   - 南門四隻各有一顆色魄，木樁王另外掉年輪色種；王的掉落歸傷害最高的一方、擁有權 10 秒，第一次參與打倒直接給色種。
   - 色魄和色種現在是一般道具，插裝備和放調色盤在第 6 步。
   - 程式裡的新字開始走 `locale/zh_TW.json` 文字表，讀取在 `src/core/texts.gd`。
3. **死亡變線稿**和**線稿裡藏東西**。2026-09-25 做到：死亡變線稿在第 1 步的著色器裡；線稿裡藏的東西寫在地圖的 `colour_secrets`，那裡先被吃成灰才算藏著，塗回九成冒出獎勵掉在地上，要再灰一次才會重新藏好。萌芽草原在木樁王巢穴旁邊藏一份，打倒木樁王整張圖亮回來時冒出來。

## 17. 要補的洞

2026-09-24 逐條檢查整套規劃找出來的，2026-09-25 全部定案。

1. **精煉爆掉時色魄一起消失，定案。** 色種在調色盤不受影響。 照 RO，卡片跟著裝備一起沒了。精煉本身照《裝備成長》：+4 以內不會失敗，+5 以上失敗就爆，護符退一級、封印不掉級。這是色魄最主要的消耗，市場才不會被塞滿；要保住高價的色魄就得用保護道具或不去賭高精煉。
2. **攻擊屬性只從色種來，定案。** 現在武器本身有屬性、裝備有八種屬性詞綴、劍線架式會蓋掉武器屬性，加上色種一共四個來源。改成：玩家的屬性只來自調色盤，也就是色種加職業固定格；武器不再帶屬性；屬性詞綴改成加數值；架式只改打法和範圍，不改屬性。
3. **和《技能與流派》的衝突用「符也是形」解，定案。** 法線的符本來就圍繞屬性。每張符的屬性從調色盤挑：巫師的元素崩要三張不同屬性的符，正好要調色盤有三種屬性；方術士的時空符由職業固定格提供時間或空間。劍線架式改普攻的節奏和範圍，弓線印記改命中後的效果，兩者都不管屬性。第 13 節第一條照這個方向處理。
4. **初心者前期，定案。** 第一顆色種在萌芽草原的木樁王。2026-09-25 使用者改：初心者只有基本技能、急救、全彩爆發，魔力彈歸術士，見第 4.5 節。
5. **怪物名單，要排。** 一種怪一顆色魄，色種只從王來，整個系統靠怪物種類和王的分布撐，每多一種怪就要多一套美術；每個屬性從前期到後期都要有王會掉色種。先照地圖和等級排出整份怪物名單，再定美術的產量。
6. **人少的時候，定案。** 怪吃顏色的速度跟在線人數走，人少就吃慢一點，避免小伺服器的地圖永遠是灰的。灰蝕從全灰處往外吃的速度不看人數，吃到三成停，見決策紀錄 2026-09-25。
7. **PvP，定案。** 彩度在 PvP 照樣要付，有色技能一樣耗彩度、不夠就褪色或強行上色扣 HP，不會變成無限放招。PvP 地圖只是沒有全服上色度：站著不掉也不回，彩度只能靠打中別的玩家偷回來和打倒對手。「怪物吃掉最常用屬性」在 PvP 關掉。
8. **死亡懲罰，定案。** 扣這一級經驗的 1%，不掉道具，基本等級 10 以下不扣；變成線稿時被隊友畫回來就不扣，給組隊救人一個直接的理由。
9. **手機操作，定案。** 每招的屬性在配裝時一次設好，戰鬥中不用碰；手機的配裝畫面要能一次看到整條技能欄和調色盤。
10. **交易和外掛。** 色魄和色種都能交易，定案。伺服器偵測異常的掉落速度，抓掛機刷王。2026-09-25 做了偵測：一小時打倒超過 2400 隻怪或 6 隻王寫 `suspect.farming` 稽核，只記不罰，門檻在 `balance.json` 的 `farming_watch`。

額外的玩法，2026-09-25 收進規劃，排在原型之後：

- **每日修復委託**：NPC 請你把某一塊地方塗回到某個比例，給固定的顏料和經驗。

## 參考

- RO 的卡片系統：一種怪一張卡、插在裝備上、稀有度撐起交易市場。
- Path of Exile 的輔助寶石：技能的形不變，插的東西改變它的行為。
- Magicka：屬性疊加組合出新效果。
- Splatoon：塗地面當成資源和地盤。
- 魔獸世界的分相：同一個地方每個人看到自己的進度。
- 寶可夢的屬性色：代表色只做表現，玩家一眼看得出屬性。
