# 技能特效規格

2026-09-16 使用者：「現在技能特效有夠鳥 一點都不華麗啊」。這份寫清楚現在爛在哪、要做成什麼樣。

## 現在為什麼不華麗

不是顏色不對也不是不夠亮，是**每個特效只有一層**。

`src/world/skill_effects.gd` 有十個形狀：arc、bolt、burst、ring、disc、trap、flame、star、snow、aura。
每一個都是一張單色的圖，播放時只做「放大再淡出」，再依屬性染色。
以 burst 為例，實際的圖就是一顆淡黃色的八角星分成六格由小變大，沒別的了。

華麗的特效不是一張圖畫得比較漂亮，是**很多層在不同時間出現又消失**。現在缺的是層數和時間差。

## 一次打擊該有的層

不是每個技能都要全部有，但強力技能要接近全部：

| 層 | 作用 | 時間 |
|---|---|---|
| 預備 | 施法者身上或腳下先亮起來，讓人知道要出事了 | 出手前 |
| 核心 | 最亮的那一塊，中心接近白色不是純色相 | 命中當幀 |
| 衝擊波 | 一圈快速擴散並變薄的環，這是「有力量」的主要來源 | 命中當幀，比核心快消失 |
| 碎屑 | 往外飛的小顆粒，數量少速度快，方向不要平均分布 | 命中後 |
| 地面 | 打到地上留下的焦痕或光圈，慢慢淡掉 | 命中後留久一點 |
| 光 | 真的光源閃一下，讓周圍的地面和角色跟著亮 | 命中當幀，極短 |
| 殘留 | 煙、灰、光屑往上飄 | 最後 |

## 規則

- **中心要過曝**：亮部往白色收，不要整個特效都是同一個色相。現在的問題就是整張圖都是淡黃色
- **快進慢出**：出現要幾乎瞬間，消失可以慢。反過來就會覺得軟
- **層與層之間要錯開幾幀**，全部同時出現會糊成一團
- **屬性要看得出差別**：火要有向上翻捲和餘燼，冰要有尖銳的碎片和冷色反光，雷要有折線和一瞬間的全白，
  不能只是同一張圖換顏色。現在九個屬性共用同一組形狀只換色，這就是「看起來都一樣」的原因
- **打到東西和打空要不一樣**，命中才有那一圈衝擊波
- **不要為了華麗擋住畫面**：這是俯視角遊戲，特效不能蓋住腳下和怪物的位置

## 效能

手機是目標平台之一，所以：粒子用 CPUParticles3D 或 GPUParticles3D 都要設上限，
同畫面多人放技能時要有數量上限和距離淘汰，不能每個人都放滿。
貼圖照 `docs/精靈圖規格.md` 走圖集，不要一個特效一張圖。
改完要跑 `tests/test_vram_budget.gd` 確認沒有吃掉記憶體餘裕。

## 驗收

- 逐幀截一次普通攻擊、一個強力技能、一個範圍技能，看得出上面那幾層分別在哪一幀出現
- 火、冰、雷三個屬性擺在一起，遮住名字要分得出來是哪一個
- 在實際遊戲鏡頭距離下看，不是放大檢視
- 同畫面五個人一起放技能，畫面不掉幀、腳下還看得清楚
