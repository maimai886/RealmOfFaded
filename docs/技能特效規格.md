# 技能特效規格

2026-09-16 使用者：「現在技能特效有夠鳥 一點都不華麗啊」。問題不是顏色或亮度，是每個特效只有一層、只會放大再淡出。華麗靠的是很多層在不同時間出現又消失。

## 一次打擊的層

強力技能要接近全有，普通攻擊挑幾層就好：

| 層 | 作用 | 時間 |
|---|---|---|
| 預備 | 施法者身上或腳下先亮起來 | 出手前 |
| 核心 | 最亮的一塊，中心接近白色 | 命中當幀 |
| 衝擊波 | 快速擴散變薄的環，力量感的主要來源 | 命中當幀，比核心早消失 |
| 碎屑 | 往外飛的小顆粒，少而快，方向不平均 | 命中後 |
| 地面 | 焦痕或光圈 | 命中後留久一點 |
| 光 | 真的光源閃一下 | 命中當幀，極短 |
| 殘留 | 煙、灰、光屑往上飄 | 最後 |

## 規則

- 中心過曝往白收，不要整個特效同一個色相；快進慢出，層與層錯開幾幀
- 屬性要看得出差別：火向上翻捲帶餘燼，冰是尖銳碎片和冷色反光，雷是折線加一瞬間全白；不能同一張圖換色
- 打中才有衝擊波，打空要不一樣
- 俯視角遊戲，特效不能蓋住腳下和怪物的位置
- 粒子要設上限，同畫面多人放技能要有數量上限和距離淘汰；貼圖走圖集
- 每一招用哪些特效、顏色、聲音寫在 `data/vfx.json`

## 驗收

- 逐幀截普攻、一個強力技、一個範圍技，看得出每一層在哪一幀出現
- 火、冰、雷擺在一起遮住名字，分得出是哪一個
- 用實際鏡頭距離看，不放大；同畫面五個人一起放技能不掉幀，腳下還看得清楚
