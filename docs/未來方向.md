# 未來方向

只規劃不開發。Rust 重寫的 M0 到 M4 在 `docs/Rust重構規劃.md`，M4 對齊舊專案之後才接這裡的 M7 到 M12。現況在 `docs/進度.md`。

| 階段 | 做完的樣子 |
|---|---|
| M7 角色美術 | 每個職業有自己的服裝圖層、八方向有動作，轉職換外觀 |
| M8 職業與流派 | 二十一個職業都有技能樹，練滿買得起大約七成 |
| M9 出貨基礎 | 別人從外面連得上來玩，三個平台出得了包 |
| M10 世界擴張 | 地圖翻倍、第二座主城、不只一隻王，滿級有地方練 |
| M11 環境與生活 | 晝夜、天氣、公會、市集 |
| M12 PVP | 決鬥、競技場、公會戰 |

M7 和 M8 可以平行；M9 在有第二個玩家之前一定要做完；M12 吃前面全部，排最後。

- **M7**：男女共用一份素體，職業、髮型、頭飾、武器都是圖層，2026-09-24 使用者定的。動手前要使用者拍板衣服要不要照零件分開畫、髮型每個方位畫幾張。順手做 NPC 的對話立繪重畫成日系動畫風、怪物四視圖照遊戲俯角畫、佔位圖從執行路徑拿掉
- **M8**：內容在 `docs/技能與流派.md` 和 `docs/轉職與城市.md`，技能資料照 `docs/技能規劃.md` 的欄位，引擎不為任何職業寫特例
- **M9**：擋路的事在 `docs/上線架構檢查.md`：綁定位址可設、反向代理做 TLS、客戶端只認 wss；伺服器清單來源改成真的；匯出設定補齊，輸出模板約 1 GB 下載前先問；手機實機的觸控、瀏海、發熱、輸入法、轉向；存檔換資料庫並補交易保證；金鑰輪替、備份還原、維護下線。驗收是非開發機跑伺服器、兩台不同平台從外面連上來打一場、防作弊測試全過
- **M10**：內容在 `docs/世界地圖規劃.md`；世界不設等級門檻、不推任務；每種怪都要有出生點；沒音樂的地圖先補曲子再開新地圖
- **M11**：晝夜天氣在 `docs/環境系統.md`；公會先寫 `docs/公會規格.md` 再做；玩家市集或攤位；精煉的 +7 發光和爆裝特效
- **M12**：要新寫哪裡能打、死了扣什麼、平衡怎麼驗；打擊感時間軸第一次面對兩個真人，量測工具要兩端同時跑

每一輪都要顧：多國語系照 `docs/多國語系規劃.md`；效能預算在 `docs/美術技術框架.md`；美術來源和授權寫進 `docs/資產清單.json`，AI 產圖記工具和提示詞。
