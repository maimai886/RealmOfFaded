### 修好的十項和對應的回歸測試

回歸測試全部放在 `tests/test_qa_regressions.gd` 這次巡檢的那一節，每一項的註解寫清楚原本玩家會遇到什麼。

**D22 一份生機買到兩件事。** `command_bloom` 掛旗標時刻意不扣生機，理由是「打空不會白花」，
但萌芽癒合那一段沒有檢查旗標，所以同一份 50 生機可以先掛綻放一擊再拿去回血，
之後那一擊照樣 180%，扣生機時被 `clamp_vigor` 夾在 0 就看不出來。
改法是癒合之前先 `_clear_bloom` 把掛著的那一擊收掉，一份生機只買一件事，
玩家還是可以自己選要留著打還是現在回血。
回歸測試 `test_bloom_mend_does_not_double_spend_the_armed_strike`。

**D33 綻放窗口到期發不出事件。** `_clear_bloom` 第一行是「還在窗口裡嗎，不在就 return」，
但呼叫它的地方正是「已經不在窗口裡」的那一刻，所以 `bloom_end` 只有死亡那條路發得出來。
改法是判斷改看旗標有沒有掛著，不看還在不在窗口裡。
回歸測試 `test_bloom_window_expiry_emits_bloom_end`。

**D32 翻滾吃掉綻放一擊。** 生機是在揮擊當下扣的，傷害排在 `_pending_hits` 等 amotion 之後才結算，
翻滾取消會把那一筆丟掉，於是生機扣了、事件發了、傷害卻沒有。
改法是揮擊時把原本的 `bloom_until_ms` 記在那一筆待結算傷害上，丟掉它的時候把生機和旗標一起還回去，
還原的是原本的到期時間所以窗口不會被拖長。
回歸測試 `test_dodge_cancel_gives_the_bloom_strike_back`。

**D23 翻滾少走一格。** 伺服器固定一格 50 毫秒而且 `_now` 從 0 起算，所以閃避指令的起點一定是 50 的倍數。
`is_dodging` 用 `_now < start + 300`，位移只拿得到 start+50 到 start+250 共 5 格，8 公尺每秒乘 0.25 秒是 2.0 公尺。
客戶端預測是連續的，走的是完整的 2.4 公尺，所以每一次翻滾結尾都會被伺服器修正往回拉 0.4 公尺。
改法是把判斷改成 `<=`，結束那一刻算在裡面，剛好補回第六格。

### 特地查過而且沒問題的地方

- **任務系統的移除是乾淨的。** 沒有任務按鈕、沒有打得開的視窗、Alt+U 不作用、按鍵設定已隱藏、

  冷卻會跟著換地圖和重登一起帶走。客戶端被拒絕時也會把本機冷卻收回來，只有 `rate_limited` 這類刻意不收。
- **閃避和牆。** 翻滾位移和一般移動共用同一套連續掃掠碰撞，一格 0.4 公尺不會穿牆。
- **公式的邊界。** 每個除數都有 `maxi(1, …)`；減傷在結構上小於 100% 所以不可能變成治療；
  攻速夾在合理區間所以攻擊間隔不會是 0 或無限；經驗表嚴格遞增；加點費用伺服器獨立重算過。
- **屬性表。** `data/elements.json` 是完整的 9×9，和 `docs/自有數值系統.md` 第 3 節逐格對得上。
- **時間屬性的遲滯。** 最多三層、同一個狀態鍵、刷新不重複疊、會過期；降到底也撞不破攻速下限，不會變成永久定身。
- **空間屬性。** 無視防禦每次命中只套一次；0.6 公尺推開走地圖碰撞，會夾在邊界內也會沿牆滑。
- **召喚。** 不會遞迴，`max_alive` 兩邊都檢查，主人死掉時小怪一起清掉。
- **預告詠唱。** 怪死掉會取消，開火前會再檢查一次還活著。
- **巡邏路線。** 每一個巡邏點在載入時都驗過可以走，被擋住會換下一個點不會卡死。
- **精英倍率。** 每隻衍生怪從乾淨的 base 深拷貝再乘，不會重複套用。
- **採集點的伺服器端。** 重生秒數會被夾在合理範圍，冷卻在回應之前就蓋章，不會無限採。

- **交易的安全性。** 換地圖、斷線、死亡、距離太遠、開商店或倉庫、進入戰鬥都會取消交易；
