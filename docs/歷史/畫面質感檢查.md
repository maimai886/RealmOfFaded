# 畫面質感檢查

2026-09-17 使用者：「遊戲美術還是很爛 地圖不夠精緻 怪物不夠精緻 也沒有啥好看的打光 光暈 質感，
比較相近的應該是 Tiny Glade，他的色彩畫面都很好，為啥你不能設置跟他一樣」

## 我先試過最便宜的那條路，而且失敗了

改成 ACES 色調映射、環境光取自天空、加一點飽和和對比、把泛光門檻壓到 1 以下。
截圖比對之後**比原本更淡更平**，退了兩次參數還是沒有比較好，所以整組還原了。
這件事記在這裡，是為了讓下一個人不要再試一次同樣的東西。

結論：**畫面平的原因不在後製**。後製只能放大已經存在的明暗，原本就沒有明暗的畫面調不出來。

## 真正的原因，由重到輕

### 1. 畫面上幾乎沒有陰影 ── 2026-09-18 修好了

城鎮的截圖裡看不到任何一個物件在地上投影。原因不是陰影沒開，是 `shadow_opacity` 被壓到 0.38。
那個值是陰影擋掉多少光，不是陰影的顏色；配上環境光 0.8 加補光 0.3，明暗差只剩一成八，等於沒有陰影。
陰影不死黑靠的是環境光取天空色加反側的冷色補光，那兩項本來就已經做對了。

改的地方在 `src/world/map_environment.gd`：各地圖基調的 `shadow_opacity` 提到 0.85 到 0.95，
陰影距離 48 公尺，深度偏移 0.03、法線偏移 0.6、模糊 0.7 到 1.0，高畫質四段分割、低和中維持兩段。
一次只改一項實測，只提不透明度就有一成四的像素改變，只改距離和分割只有 2.5%，**不透明度才是主因**。

同時把擺設和樹的圓形接地影拿掉。它們本來就會投真影子，兩層疊在一起是假的。
圓影只留給角色、怪物，還有地窟水晶那種關掉投影的東西。

### 2. 材質全是平的漫射

手繪貼圖直接當 albedo，沒有粗糙度變化、沒有法線、金屬和石頭和布的反光一模一樣。
Tiny Glade 之所以有質感，很大一部分是同一盞燈打在石頭、草、木頭、水上的反應完全不同。
不需要做 PBR 全套，但至少讓石材、金屬、水、葉子有不同的粗糙度。

### 3. 渲染器是 mobile，很多東西從一開始就不能用

`project.godot` 的 `renderer/rendering_method` 是 `mobile`。Godot 的 Mobile 渲染器**不支援**
SDFGI 全域光照、SSAO 環境遮蔽、SSIL、體積霧、螢幕空間反射。
Tiny Glade 的柔和漫反射和顏色互相染色靠的就是這一類東西。

Godot 允許桌機和手機用不同的渲染器：`rendering_method` 給 Forward+、`rendering_method.mobile` 給 mobile。
這樣電腦版拿得到全域光照和環境遮蔽，手機版維持現在的能力。
**這是唯一一條能真的接近參考作品的路**，代價是兩種渲染路徑都要驗，而且畫面會因平台而異。

### 4. 場景的密度不夠

Tiny Glade 每一平方公尺都有小東西：草叢、碎石、落葉、高低起伏。
我們的地面大片大片是同一張貼圖鋪過去，沒有東西可看。這是美術量的問題不是技術問題。

## 要老實講的事

Tiny Glade 是自製引擎、用 radiance cascades 做即時全域光照，而且它是一個小場景的建造遊戲，
不是要在手機上跑的多人連線遊戲。**我們可以接近它的色彩和柔光的感覺，但不可能在手機上做到它的全域光照。**
把目標訂成「同一種舒服的顏色和柔和的光」是做得到的，訂成「一樣」是做不到的。
