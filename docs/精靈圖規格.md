# 角色與怪物精靈圖規格

產圖端和遊戲顯示端共同遵守的契約，兩邊都不能自己改格式，要改先改這裡。硬數字的總表在 `docs/美術技術框架.md`，畫風在 `docs/美術風格指南.md`。
舊專案的引擎寫法在 `../Sproutia` 的 `src/world/sprite_sheet.gd`、`src/world/actors/`，Rust 版在 `rust/crates/gdext/src/actors/`。

兩套規格並存，由 `meta.json` 的 `filter` 決定：

| | 玩家角色、NPC 立牌 | 怪物 |
|---|---|---|
| 密度 | 96 像素一公尺 | `frame_px = 進位到 64 的倍數(view_m × 112)`，128 到 320 |
| 取樣 | 像素圖 `filter: "nearest"`，銳利雙線性，著色器 `actor_sprite_pixel.gdshader` | `filter: "linear"`，平滑加 mipmap，`actor_sprite.gdshader` |
| 匯入 | 無損 | VRAM 壓縮高品質 |
| 描邊 | 一格寬帶色描邊，見「畫法」 | 還是柔和圖集時最外圈壓一層淡暗色；改像素後照角色 |

## 1. 像素角色

**96 像素一公尺**：俯角 −45、FOV 15 度，42.73 公尺時垂直視野 11.25 公尺，1080p 剛好 96，一比一不放大、2160p 剛好兩倍。密度不要動。
透視鏡頭下只有站在基準平面上的玩家自己是整數倍，別人不管怎麼訂都不是，這沒有解法。

**180 像素高**：使用者 2026-09-19 定，是他的設定圖換算成真像素的細度，所以角色在世界裡 1.875 公尺。
碰撞、影子、名字位置都照貼圖算，不用另外改。`paperdoll.py` 也能出 90 高、每公尺 48、`display_scale` 2 的版本，身高一樣。

**畫格與錨點**：`frame_size` `[176, 232]`、`anchor` `[88, 208]`。錨點是兩隻腳底的中點，不是最低那一格，
斜角站姿拿最低點當站立點人會像浮空。錨點下面留 24 給倒地，寬高取 8 的倍數。
輪廓外圈不能有偏白的像素，白底去背後要剝掉貼著透明又夠亮的那圈，不然縮小是一條白邊。

**身體比例**照 `docs/美術風格指南.md` 第 3 節換算成 180 高：頭高 44、頭寬 48、肩寬 52、單腿寬 23、兩腳中心距 31、胯高離地 67、
肩線離地 122、手臂 47、身體最寬 63、眼睛中心髮頂往下 35。髮尖、頭飾、武器可以超出。

**方向**：出貨的是五方向，`w`、`nw`、`sw` 翻出 `e`、`ne`、`se`；`directions` 寫八個時引擎不鏡射，順序 `s`、`sw`、`w`、`nw`、`n`、`ne`、`e`、`se`。
方向是角色朝向減鏡頭方位角，每 45 度一格。

2026-09-28 使用者定案玩家身體圖「跟 RO 一樣標準」：RO 的 13 種動作都要有，每種 8 個方向，畫 5 個、翻 3 個。
格數照 RO 原檔，走路已經量過；其他是從 RO 男初心者身體表數的大約值，做到那個動作時再照原檔量準。

| 動作 | 格數 | 循環 | 備註 |
|---|---|---|---|
| `idle` 站立 | 1 | 是 | RO 身體一格，頭另外有三個轉向 |
| `walk` 走路 | 8 | 是 | 每格 75 毫秒 |
| `sit` 坐下 | 1 | 是 | |
| `pickup` 撿東西 | 2 到 3 | 否 | |
| `standby` 戰鬥待命 | 3 | 是 | 戰鬥後的架勢 |
| `attack1` 到 `attack3` 攻擊 | 約 6 | 否 | 空手和不同武器各一種 |
| `hit` 受擊 | 2 到 3 | 否 | |
| `freeze1`、`freeze2` 定住 | 1 | 否 | 冰凍、石化用 |
| `die` 倒下 | 1 到 3 | 否 | |
| `cast` 詠唱 | 3 | 是 | |

動作時間以伺服器的 amotion 為準，fps 只管畫。滿動作的身體 8 欄排成 1408×3712 約 5.2 M 像素，一張地圖同時最多載 6 份身體圖集。

**銳利雙線性**：非整數倍時最近點會一排寬一排窄、描邊斷、移動時抖。做法是在圖集像素座標用 `fwidth` 量一個螢幕像素跨幾格，
離格線不到半個螢幕像素才往格線滑，其他時候夾在格子中心，放大時每格是硬邊方塊；透明度門檻 0.5，縮到 0.5 倍以下才用 mipmap。
匯入要開 `fix_alpha_border`，不然雙線性混到透明像素的顏色輪廓發黑。參考 t3ssel8r、Cole Cecil 的做法。

### 畫法

- **一格寬帶色描邊**：剪影最外一圈，顏色是那格材質色階中間那階乘 (0.30, 0.22, 0.24)；外圈本來就是畫的墨線時，材質照往內兩格最多的色階算。
  內部分區不加線，使用者畫的內部線條縮下來鎖到最近的顏色。每一層各自描外框
- 每個材質一條 4 到 5 階色階，色相分開；縮完限色，邊緣全有全無
- 從上往下看得到肩膀、靴子、領口的頂面
- 不畫發光、光暈、投影、背景

## 2. 紙娃娃圖層

RO 式換裝：身體一份圖集，頭髮、頭飾、武器、盾、披風各一份圖層，引擎照每一格的槽位疊。
產圖端 `art_pipeline/characters_v5/paperdoll.py` 讓身體和每一層同一格一起算，姿勢、錨點、格數一定一樣。
防具外觀是換掉身體的零件重出一份身體，不是再疊一層，疊上去的衣服手一擺就對不齊。

**像素化** `pixelize.py`，每層同一套步驟：工作畫布是目標的整數倍，180 高是 4 倍；面積平均縮小，顏色照透明度加權；
透明度 0.5 切成全有全無，出貨的圖一顆半透明都沒有；照 OKLab 鎖 `assets/generated/sprites/characters/ramps.json` 的色，先找最近再只在附近最多的那條色階裡找；
清孤立點，墨色不當雜點；最後描邊。只平移的零件位移取整到一格，待機起伏才不會一格清楚一格糊。

**身體 meta 多的欄位**：`paperdoll: 1`、`display_scale`、`head_attach[動作][方向][格] = [x, y, 角度]` 頭的圓心和轉角，順時針正。

**圖層 meta**：

```json
{
  "kind": "paperdoll_layer", "layer": "hair_front",
  "frame_size": [176, 232], "anchor": [88, 208], "pixels_per_meter": 96, "display_scale": 1,
  "directions": ["s", "sw", "w", "nw", "n"], "filter": "nearest", "layout": "cropped",
  "actions": {"idle": {"frames": 3, "fps": 5, "loop": true}},
  "cells": {"idle": {"s": [[x, y, 寬, 高, 左上角相對錨點的 x, y, 槽位]]}},
  "ramp": "hair_sand", "dye": "hair", "hides_hair": false
}
```

- `cropped` 每格裁到內容外框，寬高 0 是這格不畫；左上角放在身體錨點加偏移，可以是負數、可以超出身體畫格
- 鏡射方向翻 `w`、`nw`、`sw` 那格，水平偏移換成 `-(x + 寬)`
- `frame_size`、`anchor`、`pixels_per_meter`、`directions`、每個動作的 `frames` 必須和身體一樣，對不上就報錯、不畫，不准退回站姿
- `dye` 是換色歸哪一區，有就附同尺寸 `mask.png`；每顆都鎖在色階上，換色就是換成另一條色階的同一階。沒有遮罩的圖層保留原色
- 一份圖層只對一副骨架，名稱接 `_male`、`_female`，沒有才找共用的
- 每層預算 2 MB，超過 1 MB 產圖時列出來

**槽位**：身體 0，大的畫在前面；同一格兩層不同部位同槽位直接報錯。

| 部位 | s | sw | w | nw | n |
|---|---|---|---|---|---|
| 披風 `cape` | −30 | −30 | −30 | 5 | 5 |
| 後髮 `hair_back` | −20 | −20 | 10 | 10 | 10 |
| 前髮 `hair_front` | 20 | 20 | 20 | 20 | 20 |
| 下頭飾 `head_low` 口罩鬍子 | 30 | 30 | 30 | 30 | 30 |
| 中頭飾 `head_mid` 眼鏡面具 | 40 | 40 | 40 | 40 | 40 |
| 上頭飾 `head_top` 帽子頭盔 | 50 | 50 | 50 | 50 | 50 |
| 武器 `weapon` | 每格照手的深度 −10 或 60 | | | | |
| 盾 `shield` | 每格照拿盾那隻手 −12 或 55 | | | | |

- 武器在前面時，手末端是膚色的地方把武器挖空，露出握把上的手
- 斜向和側面的武器拿在近鏡頭那隻手，鏡射到右邊時換手，RO 也是
- 頭髮不可以畫出頭的圓放大 1.07 倍的外包絡，帽身要蓋得住它，所以帽子永遠在頭髮前；整頂包頭的頭盔寫 `hides_hair: true`，引擎不畫 `hair` 開頭的層

**引擎怎麼疊**：同一個角色每層的紙片推量都用身體的 `depth_nudge`，不然透視下會錯開；前後只改寫進深度的那片平面，
各層槽位換成緊密名次，每差一名推 0.004 公尺，名次夾在 −4 到 7，數字在 `data/paper_doll.json`。
哪些裝備欄位有外觀圖層也照那份，程式不寫死。換裝只換貼圖，沒讀過的圖層在背景讀，讀好那一幀才換。

## 3. 怪物

- 畫格照 `view_m` 算，`pixels_per_meter` 照模型高度反推，不憑感覺填
- 柔和圖集是 2 倍解析度再面積平均縮小，縮完就是成品，不像素化、不二值化透明度
- 顯示平滑加 mipmap，換色查色階橫向內插，不然漸層切回平塗

**部位擺錘 `swing` 區塊**，`mpuppet.py --swing` 產的，送審中還沒出貨：部位不畫進動作格，遊戲照身體真的加速度當擺錘甩。
圖集後面多一個佔位動作 `swing`，角色不播它。meta 的 `swing` 有 `angles` 預轉角度、`slots` 和 `mirror` 部位編號、`facing_x`、
`params` 擺的物理參數、`parts` 每方向每部位的小圖矩形和接點、`frames` 每格的身體旋轉縮放和接點。
物理：2.8 Hz、阻尼比 0.28、活著最多擺 40 度、接點 6 Hz 臨界阻尼濾波、固定 120 Hz 小步積分；參考 VRM SpringBone 和 Daniel Holden 的 Spring-It-On。
舊專案量到 20 隻同時甩約 3.5 毫秒，出貨前要壓。

## 4. 換色遮罩

`mask.png` 可選，R 255 頭髮、G 255 皮膚、B 255 主要布料；沒有時整張算主要布料，換色照樣有效。
整隻只有一種材質的怪不要放，省下和彩圖一樣多的記憶體。放的話和彩圖一樣大，或長寬同時縮成整數分之一，最多八分之一。
遮罩一律無損，它是區域圖，壓縮會把 0 和 255 壓成中間值。

## 5. 檔案位置和排列

```
assets/generated/sprites/characters/body/<gender>_novice/   sheet.png  meta.json  可選 mask.png
assets/generated/sprites/characters/layers/<model_attachment>/
assets/generated/sprites/monsters/<art.sheet>/
assets/generated/sprites/npcs/<npc_id>/
```

女生沒有自己的身體就用 `male_novice`；圖層名稱等於道具的 `model_attachment`；怪物資料夾名是 `data/monsters.json` 的 `art.sheet`。
找不到正式圖時退到 `placeholder/`，那個資料夾不出貨。

**`layout: "packed"`**：所有格子接成一條再照 `columns` 折行，`格號 = start + 方向 × frames + 格`，欄是格號除以欄數的餘數、列是商。
一個動作每個方向格數一樣、動作之間格號不重疊；`start` 用 `art_pipeline/common/atlas.py` 的 `pack_actions` 回傳的，不要自己算。
沒寫 `layout` 是舊的 `grid`：欄是格、列是 `row × 5 + 方向`。緊密排讓圖集像素數壓在 12,582,912 以內，超過整張地圖多付 64 MB。

```json
{
  "frame_size": [176, 232], "columns": 8, "layout": "packed", "pixels_per_meter": 96, "filter": "nearest",
  "anchor": [88, 208], "directions": ["s", "sw", "w", "nw", "n"],
  "actions": {
    "idle":   {"start": 0,  "frames": 4, "fps": 6,  "loop": true},
    "walk":   {"start": 20, "frames": 8, "fps": 12, "loop": true},
    "attack": {"start": 60, "frames": 6, "fps": 14, "loop": false, "hit_frame": 3}
  }
}
```

**可選欄位**：

| 欄位 | 預設 | 意思 |
|---|---|---|
| `depth_nudge` | 0.12 | 紙片往鏡頭推幾公尺，腳才不陷地；圖層跟著身體 |
| `top_row` | 載圖時量 | idle 面向鏡頭第 0 格最高的不透明列，算名字和血條高度 |
| `luma_ranges` | 載圖時量 | 遮罩每一區在 idle 第 0 格的原圖亮度範圍 |
| `shadow_radius` | 由格寬估 | 腳下圓影半徑，公尺 |
| `ramp_span` | `[1, 8]` | 原圖最暗和最亮對到色階第幾格 |
| `head_layer` | false | 頭畫在身體那層；true 才另外貼頭 |

`top_row` 和 `luma_ranges` 產圖端一定要寫，不寫的話換裝那一幀引擎要逐像素量，量過 96 到 117 毫秒。

## 6. 顯示規則

- 完整 billboard 正對鏡頭；Y 軸 billboard 會把角色照 cos 45 度壓成 0.71 倍，不能用
- `pixel_size = 1 / pixels_per_meter`，解析度改了只要密度跟著改，世界大小不變
- 腳底用 `anchor` 對齊世界座標；紙片深度用腳那片直立面算，站在台階牆前不會被切半
- 影子是腳下的圓形貼花；受擊閃白、死亡淡出、換色、顯示校正涵蓋身體和每一層；選取描邊只描整個人的外輪廓
- 精靈圖不跟著場景色調映射變色，見 `docs/精靈圖顯示校正.md`
