# 美術方向

場景和介面像什麼、怎麼做、怎麼檢查。角色、怪物的造型上色看 `docs/美術風格指南.md`，硬數字看 `docs/美術技術框架.md`，衝突時以那兩份為準。

## 1. 標竿

仙境傳說：低多邊形 3D 場景每一面貼手繪材質，烘焙的柔和陰影偏暖，樹是交叉的手繪葉片，角色是 2D 精靈圖，長焦俯視、遠處有霧。
救世者之樹：手繪 2D 場景看得到筆刷，飽和但和諧，光暖陰影帶紫，角色靠描邊和背景分層。

我們要抓的共通點：

1. 每個表面都有紋理、筆觸、深淺，沒有大面積單色平塗
2. 整張畫面同一個暖光源色，陰影偏紫或藍，亮部收在暖奶油色
3. 柔和陰影和環境遮蔽，物件和地面有接地感
4. 角色用描邊和背景分層，永遠一眼看得到
5. 霧、天空漸層、遠處降對比做出景深
6. 植物是葉團不是幾何形

## 2. 定案

| 項目 | 做法 |
|---|---|
| 玩家角色 | 像素圖集，96 像素一公尺，格式在 `docs/精靈圖規格.md` |
| 怪物 | 使用者畫的方向圖做成紙偶，密度政策 112 |
| NPC | 和玩家同畫格同密度的 Q 版立牌，對話用立繪，見 `docs/美術替換指南.md` |
| 地面 | 3 到 4 層手繪可平鋪材質混合，草、乾草、泥路、石板，遮罩由地圖資料決定，加花草碎石貼花 |
| 樹與植物 | 手繪葉片交叉組成的樹冠加簡單樹幹 |
| 建築 | 城鎮走 Meshy 圖轉 3D，見 `docs/城鎮建築產線.md`；素材包建築套自己的手繪貼圖 |
| 岩石崖壁 | 低多邊形加手繪岩石材質，崖面有層理，由圓岩堆成 |
| 光影 | 暖主光加冷補光、天空色環境光，頂點環境遮蔽加接地影，霧和天空漸層做景深 |
| 特效 | RO 式共用零件庫加法光，不用方塊粒子 |
| 介面 | 版面照 RO，外觀是深色玻璃，見 5b |

地面只在走不到的地方長高度，可行走範圍一律是平的，伺服器世界是二維。
AI 產圖只當起點，材質要做成無縫、統一色階、去掉雜訊；原檔存 `art_source/textures/`，處理後放 `assets/generated/textures/`。
所有產製都是可重跑的腳本，放 `art_pipeline/`。

## 3. 色彩與光

- 主光 `#ffeecb` 暖白，環境光取天空色偏藍，陰影不用純黑用偏紫的暗色
- 沒有中性灰、沒有純黑、飽和在中段、亮部往奶油色收，配色原則見 `docs/調查/RO配色參考.md`
- 每張地圖一個基調：草原明亮黃綠、城鎮暖、森林深綠帶青、碎石谷土黃帶橘、地窟藍紫帶火光
- 霧只當景深提示，鏡頭拉到最遠時角色和路仍然飽和，地窟例外
- 地窟靠深色霧和火把做氣氛，環境光仍不低於下限，角色永遠看得到
- 精靈圖不跟著場景色調映射走，見 `docs/精靈圖顯示校正.md`

## 4. 場景檢查表

每次交付截圖，拿仙境傳說同類場景放旁邊，逐條看：

1. 沒有超過 100 像素的單色平塗面
2. 地面看得出材質層次，路徑邊緣自然過渡
3. 樹是葉團，不是球和圓錐
4. 建築的屋頂、牆、基座三種材質分得出來
5. 物件底部有接地陰影
6. 角色在任何背景上都一眼分辨
7. 遠處有霧和降對比，有前中後景
8. 色相統一，沒有螢光色或純灰
9. 手機 844×390 縮小看仍認得出角色和路
10. 地圖材質總數在 2048² 等效四張以內

平貼在地上的貼花要靠近格子邊淡出，不然貼到亮石板上會變成暗色方塊，使用者以為是壞掉的影子。
落葉這類貼花的原圖四邊要畫成散開的，不要整格畫滿。

## 5b. 介面

版面照仙境傳說：小視窗、標題列、緊湊的列。外觀 2026-09-26 定案，規則寫在 `src/ui/ui_theme.gd` 開頭。

- **視窗、登入選角捏角的面板、HUD 全部是同一塊深色半透明玻璃**：近白字、細邊、圓角；數字照聊天框和對話框的 `slab_style` 和快捷列的格子，不另外發明配色
- 主要按鈕是聊天框「送出」那個藍，強調色只有這一個；裝飾只有一個淡金 `ORNAMENT`
- 面板全部用 `StyleBoxFlat` 畫；視窗打開從上緣扁平往下展開
- 去系統味：標題列沒有縮小鈕，關閉是一顆小圓叉，頁籤是底線式，四角不畫勾角；不要做出作業系統的樣子
- 深淺分層：內容區、格子、數值條槽比面板深一階；作業系統是每塊一樣亮靠細線分，遊戲介面靠深淺分
- 左上是無框狀態板：職業圖標圓徽、名字、HP 和 SP 圓角細條、經驗細線，任務追蹤掛在下面
- 右上小地圖是圓的，一圈米白細環、四個方位小菱形、正上方一個 N
- 右下圓鈕平常只露道具、技能和選單，按選單鈕一顆接一顆往上滑出
- 游標是暖金色，`art_pipeline/ui/cursors.py`
- 道具和技能圖示是手繪大圖切的，`art_pipeline/ui/icons.py` 縮進 40×40 加落影；缺圖的道具退回程式畫的方塊。
  職業圖標 21 個是使用者畫的白色線稿，`art_pipeline/ui/job_icons.py` 切成 64×64，畫面上用字色染
- 字型：一套內文字型四種字級，只有視窗標題另用源雲明體，Logo 用 Cinzel

**底線**：

1. 字和底的對比至少 4.5 比 1，每一種按鈕狀態滑過時字都不能消失
2. 字只落在平靜的底上，不貼邊、不裁掉、不重疊
3. 只有一個強調色和一個裝飾色
4. 內距至少 10、間距至少 6
5. 844×390、介面縮放 0.8 到 1.4、手機全螢幕分頁都正常，分頁鋪滿時不透明
6. 視窗最大化到任何尺寸都不會有東西跑出畫面
7. 樣式和貼圖一律快取，共用的樣式要改先 `duplicate()`

**檢查**：介面改完在 1440×810 截一輪、手機版面再截一輪，明亮晨曦鎮和昏暗地窟各一輪。
看有沒有第三種顏色、HUD 字在亮草地上讀不讀得到、有沒有像作業系統的東西、按鈕三種狀態分不分得出來、空格和有東西的格子分不分得開、
稀有度和成功失敗的顏色一眼分不分得出來。
