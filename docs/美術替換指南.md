# 美術替換指南

美術是一層可以整包換掉的東西：照這份交出檔案，遊戲就會用它，不用改程式。
格式契約在 `docs/精靈圖規格.md`，畫風在 `docs/美術風格指南.md`。

## 1. 誰用哪份圖集

玩家、NPC、怪物全部是吃多方向圖集的紙片角色，3D 角色 2026-09-24 整條拿掉了。

| 誰 | 圖集 | 看資料的哪個欄位 |
|---|---|---|
| 玩家 | 所有職業、男女共用 `characters/body/male_novice`；裝備疊 `characters/layers/<名稱>` | `gender`、`job_id` |
| NPC | `npcs/<npc_id>`，頭畫在身體那層 | `npc_id` |
| 怪物 | `monsters/<sheet>`，沒有再找 `monsters/<fallback_sheet>` | `data/monsters.json` 的 `art` |

路徑都在 `assets/generated/sprites/` 底下，找不到再找 `placeholder/`，那個資料夾不出貨。
程式不認任何一個 id；自己的圖集找不到時用玩家的共用底板頂著，同一份外觀只報一次錯。

## 2. 標準骨架

定義在 `art_pipeline/characters/humanoid.py`，比例參數在 `rigspec.py`，紙偶骨架和 `cbuild.py` 都用它。
骨頭名稱照 Mixamo，也就是 Unity Humanoid，不加 `mixamorig` 前綴，市面上的動作包可以直接套。換正式角色時骨架不能變，不然動作和裝備全部重做。

```
Root
  Hips
    Spine → Spine1 → Spine2
      Neck → Head → head              head 是頭飾掛點
      Left/RightShoulder → Arm → ForeArm → ForeArmTwist → Hand
        每隻手 Thumb、Index、Middle、Ring 各 1..3
        hand_l / hand_r                武器掛點
      back / body                      披風和身體外觀掛點
    Left/RightUpLeg → Leg → Foot → ToeBase → ToeEnd，加 UpLegTwist
  Left/RightHandIK、Left/RightFootIK   不變形，給要 IK 的動作包
```

共 62 根。`Root` 在地板上和 `Hips` 分開，翻滾打在 `Root`，身體才是繞自己翻。
動作沿用 KayKit 的 76 個，來源 `assets/vendor/kaykit/characters/Knight.glb`，這個檔和它的貼圖一定要留著。

## 3. 資料要加什麼

**髮型、眼型**：`data/appearances.json` 的 `options.hair_style.<gender>` 或 `options.eye_style` 加一筆 `{"name": "盤髮"}`，
捏臉介面和伺服器驗證都照筆數。現在素體的頭畫在身體那層，換髮型只換色不換圖，要換圖得先做頭髮圖層。

**裝備外觀**：`data/items.json` 那件裝備的 `model_attachment` 就是圖層名稱，引擎找 `characters/layers/<名稱>_<性別>/`，沒有再找 `characters/layers/<名稱>/`。
圖層和身體同畫格、同錨點、同動作。沒有圖層的裝備照樣能穿，只是不顯示外觀。

## 4. 怪物和 NPC 的圖集

```
monsters/<sheet>/   sheet.png  meta.json  可選 mask.png
npcs/<npc_id>/      sheet.png  meta.json  可選 mask.png
```

`mask.png` 只有分兩區以上的角色才放。`meta.json` 必填 `frame_size`、`columns`、`pixels_per_meter`、`anchor`、`directions`、`actions`、`filter`；
引擎不假設任何產圖端的數字，比例和舊的完全不同也沒關係。格式錯了載入時會直接說哪個欄位怎麼了，例如
`actions.attack.frames 是 10，比 columns 的 8 還多`、`anchor (96, 250) 落在格子 192x192 之外`、`meta.json 少了 idle 動作`。

## 4.5 NPC 對話立繪

對話框右邊那張大圖，下緣被對話框切掉。純資料，換圖不用改程式：圖放 `assets/ui/portraits/<立繪編號>.png`，
`data/npcs.json` 每個 NPC 的 `portrait` 填編號。沒有立繪的 NPC 一樣能講話，對話框會占滿整排。

| 項目 | 值 |
|---|---|
| 原圖 | 1024×1536 直式，裁到人物本身再縮到高 960 |
| 背景 | 全透明，不留白，對話框自己算位置 |
| 構圖 | 站姿全身，頭到腳都在畫面裡 |
| 格式 | PNG，一般介面貼圖匯入，不開 VRAM 壓縮 |
| 像素數 | 50 到 66 萬 |

**產這一組圖的描述**：整組一致比單張好看重要。先把第一張調到滿意，剩下的只換「角色」那一段，其他一個字都不動。
2026-09-24 重畫成賽璐璐日系動畫風加白邊；下面是最初那一組的固定描述，是這批圖的來源紀錄：

> 原創角色立繪，全透明背景去背，沒有外框。
> 角色：<只有這一段每個人不一樣>
> 比例：三頭身的 Q 版，頭大約佔全身的三分之一，身體短而圓，手短，手是圓潤的連指形狀，圓頭鞋。
> 全部由大圓形組成、沒有銳角，剪影一眼就認得出來。
> 臉：畫上去的不是做出來的。很大的眼睛有眼白、虹膜從上暗到下亮有漸層、深色瞳孔、兩點白色高光。
> 細眼線、額頭上看得到細短眉毛、鼻子只有一點陰影、小嘴、淡淡的腮紅。
> 取景：畫面裡只有一個角色，站姿全身從頭頂到腳，身體轉四分之三面向觀眾，置中，
> 四邊都留一點空白讓人物不碰到畫面邊緣。畫面裡沒有別的東西：沒有背景、沒有邊框、沒有文字、沒有地面陰影。
> 畫風：柔和漸層的賽璐璐上色，亮到暗是平滑過渡，暗部帶一點冷色反光；乾淨的細線稿，
> 線是暖深棕不是黑；材質乾淨沒有雜訊也沒有布紋。整體偏暖的中低飽和粉彩配色，
> 加一兩個小面積的高飽和重點色，亮部收在暖奶油色，沒有中性灰、沒有純黑。
> 手繪 2D 遊戲立繪，不是 3D 算圖，不是照片。

## 5. 匯入與驗證

匯入設定照 `docs/美術技術框架.md` 第 7 節，產圖管線會自己寫 `.import`；手工放圖之後跑一次 `godot --headless --path . --import`。
進遊戲用 `scenes/dev/actor_preview.tscn -- --body=圖集資料夾 --at=x,z --cam=距離` 截圖，逐條看：
腳底踩在地上沒陷沒浮、武器圖層在手上且每個方向前後順序對、換髮色膚色服裝色有作用而眼睛嘴巴不跟著變、大小和旁邊的怪物建築比起來合理。
