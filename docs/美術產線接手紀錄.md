**怪物**：

```
python art_pipeline/monsters/mpuppet.py leaf_sprout art_source/monsters/南門/草葉/views5 --candidate --swing
```

拿掉 `--candidate` 直接寫進 `assets/generated/sprites/monsters/<art.sheet>/`。新怪先在 `data/monsters.json` 加一筆：
`art.sheet` 是資料夾名、`art.height` 是身高唯一來源、`art.view_m` 是取景、`art.motion` 選 `hop`、`waddle`、`stomp`。
部位切分的常數在 `mpuppet.py` 最上面的 `APPENDAGE_`。四隻腳會跑的怪只會整隻晃，腿要另外切，還沒做。

**NPC 立牌**：`art_pipeline/npcs/npc_volume.py` 拿舊圖當參考保留長相，挑好的去背存 `art_source/npcs/volume/`，再跑 `npc_sheet.py`。

**檢查圖集髒邊**：`python art_pipeline/common/sheet_clean.py <sheet.png> --mark 看.png`，列出離島、霧、亮邊。

**遊戲內看角色**：`scenes/dev/actor_preview.tscn -- --body=圖集資料夾 --at=x,z --cam=距離`，`0,0` 是石板廣場、`7,6` 是草地。

**美術管線測試**：`blender -b --factory-startup --python-exit-code 1 -P art_pipeline/tests/run.py`。

**已經證明有效、要保留的做法**：

- 去白底照「墨線乘透明度加白紙乘剩下」反算透明度和墨色，邊緣不留淡粉白，`mpuppet.cut_on_white`
- 像素化照材質鎖色：先找最近色，再只在附近最多的那條色階裡找，墨線才不會一段褐一段橘
- 桌機走 Forward+，mobile 渲染器不支援全域光照、環境遮蔽、體積霧
- 抗鋸齒用 FXAA，不用 TAA，TAA 會讓紙片角色和葉片拖影
- 素材包建築套自己的手繪貼圖，用世界座標三向投影，筆觸大小不隨模型縮放
- 草毯用 8 公尺一格的 MultiMesh、法線朝上、不投影，看不到裸地

**接 ComfyUI 的坑**：

- 畫圖模型和轉 3D 模型不能同時留在記憶體，16 GB 會不夠或烘成一片白
- `LoadImage` 照檔名快取，餵進去的圖檔名要帶最後那張圖的內容雜湊，而且不覆寫已存在的檔
- 有節點驗證不過時照樣回 200，只寫在 `node_errors`，看到就要擋
- KSampler 的 denoise 小於 1 時實際跑的是 步數除以 denoise 取整的最後幾步，4 步時 0.8 以上等於 1.0
- 使用者貼在對話裡的圖不會落到硬碟，要從對話紀錄 jsonl 裡 `image` 區塊的 base64 解出來存進 `art_source`

## 4. 試過沒用的，不要再試

**角色，照時間順序**：

| 試了什麼 | 為什麼不行 |
|---|---|
| AetherAI Pulsar 轉方向 | 每個方向換一張臉一套衣服，又糊；代幣白花兩次 |
| Qwen 多角度 LoRA 轉方向 | 同一個人做得到，但俯角參數沒作用，產出的俯角等於畫稿的俯角 |
| Wan 2.2 圖生影片做動作 | 腿不交替、服裝每幾格就變、鏡頭自己拉近，調參數更糟 |
| Qwen 逐格編姿勢、加骨架參考圖、換 OpenPose 走路包 | 每一格模型重新猜一次，格與格兜不起來；側面常多一隻手 |
| Trellis.2、Pixal3D 生成 3D 網格直接算圖 | 網格皺、UV 碎，臉和線稿是貼圖細節，八種清法都救不回 |
| 幾何人偶當最終美術 | 使用者說是廉價垃圾 |
| 無脖身體加一顆標準頭 | 頭浮在肩膀上接不起來 |
| 2D 紙偶切使用者素體 | 側面腿疊成一條、袖子連著衣服一起動；像素圖切太碎，使用者說「還是破成那樣」，而且換裝做不下去 |
| 紙偶加明暗、身體 3D 頭 2D 兩種小樣 | 都比 RO 淡，手臂和步幅各有毛病，使用者都沒選 |
| Meshy 身體加畫稿臉的全 3D 第 2 版 | 使用者「都不行」 |
| 用 Blender 素體自己捏頭臉頭髮 | 使用者說「角色太醜是在跟我開玩笑嗎」；沒經過設計的造型一定醜，要先出設計圖給使用者挑 |
| 上半身整塊、腿切兩塊平移 | 使用者說不對，也沒辦法換裝和做別的動作 |
| 把定稿的臉投影到 Meshy 頭上 | 俯角下 Meshy 的瀏海往前凸，蓋住半張臉 |
| 3D 算圖每 4 像素平均縮成像素 | 眼白、髮絲、部件交界比 4 像素細的全糊 |
| 素體頭加 Meshy 服裝和頭髮三層的八方向預算圖 | 使用者說「完全失敗」並刪了算圖；軟的 3D 算圖離像素定稿太遠，Meshy 貼圖雜紋清不乾淨 |
| Qwen 照定稿逐格重畫 3D 姿勢圖 | 使用者說「根本崩壞」：腿糊成一根、頭一格大一格小、頭髮每格不同。唯一同時留得住姿勢和畫風的是 8 步 denoise 0.875、姿勢圖放圖 1 定稿放圖 2，仍然逐格不一致 |
| RO 身體表當底圖、加 ControlNet Union | 全部變回定稿站姿；RO 身體只有 75 格高，放大後模型不當姿勢；那個 ControlNet 接在 Edit 模型上幾乎沒作用 |

**角色的細節做法**：

- Klein 提示詞寫「陰影往紫藍偏、顏色更深」，皮膚整片變紫；要寫保留原本暖色、只有最暗處微冷
- 手點臉，使用者說「是來搞笑的嗎」
- 面積平均加清孤立點縮像素，眼睛和墨線被清光；像素化時整張調色盤找最近色，線變虛線、白衣變黃；清孤立點把墨線算進去，墨線變虛線
- 關節圓頭補在透明度大於 0 的地方，縮圖留下的淡邊被塗成不透明膚色；軀幹不往四肢長重疊邊，每個關節露一塊灰
- 3D 那邊：Freestyle 描線在 Meshy 頭髮上縮小變灰霧；反向外殼描邊讓褲子從上衣穿出來變黑斑；在有光影的圖上找邊，陰影分界變碎線、臉像瘀青；
  色調硬對齊 2D 把褲子壓黑；縮 Meshy 貼圖再分色會在 UV 碎塊邊緣滲色
- 綁骨：Meshy 網格不封閉，熱擴散綁定全失敗，要分區加反距離權重；綁在 T 姿勢骨架再用反矩陣推回，肩膀轉快 90 度撕開
- `base_fit.blend` 裡 Cycles 的選取對作用中烘焙一直出全黑，原因沒查出來
- 3D 頭髮硬邊高光，頭頂多兩塊白島像禿頭

**場景**：

- 只調後製救不了沒有明暗的畫面，後製只放大已經存在的明暗
- 測試場開景深，一圈同距離的角色全糊
- 夜晚用濃霧加黑背景，地面被吞成一片藍；夜晚要飽和的藍色月光加影子
- 鏡頭俯角降到 24 度去配合角色圖，使用者說很暈；2D 垂直壓縮假裝俯角只會變矮胖
- 素材包的樹和草不分平台直接用，草原 386 萬三角形，手機預算 20 萬
- 用「能不能走」判斷草毯長不長，房子四周禿一圈
- 拿圖的亮度梯度當法線打光，角色只有約 100 像素高，量到等於沒作用
- 城鎮建築用本機 TRELLIS 2 或 Blender 手做，見 `docs/城鎮建築產線.md`

## 5. 規矩

- 付費的東西每一次都先問；本機和免費的自己做。下載免費資源前講清楚來源、授權、大小，itch.io 要使用者本人點
- 不要拿別人素材包或別的遊戲的圖餵生成工具，概念圖一律自己設計
- 動手前先查 `.claude/skills/` 對應的 skill，跳過那一次面數超標 19 倍
- 自己截圖看過、真的比較好才給使用者；成品要和定稿並排比，不是和上一版比
- 一次只改一個變因，生圖之前先驗輸入；補丁套完確認真的套上了
- 八個方位都要看，壞的那一面常常不是正在修的那一面
- 沒看過的東西不要講得像事實，先搜尋、先打開檔案
