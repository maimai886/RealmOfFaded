# 美術與特效驗收標準

美術和特效要先過 Nora 美術總監和 Felix 特效審查，兩位都及格才交給使用者。
2026-09-27 使用者：「特效跟美術可以多一點人手把關，他們可以自行討論做法以及及不及格，有沒有達到要求，不要只是改出來就告訴我好了」。

## 流程

1. Leo 或 Iris 先寫做法：要表達什麼、參考哪個成熟遊戲的哪個效果、分幾層、顏色和時間怎麼排。Nora 和 Felix 看過才動手
2. 做第一版，截亮地板和草地各一張放大對照圖
3. Nora 和 Felix 照下面清單逐條給及格、不及格、不適用，不及格寫哪裡、怎麼改
4. 任一條不及格就退回；同一件東西三輪過不了，停下來回報使用者
5. 兩位都及格才交，圖在前，附審了幾輪、每輪退回的原因
6. 使用者退件的話加進「使用者說過的話」

做的人和審的人不直接叫對方，都經過製作人轉，原文照貼。

## 通用清單

| 項目 | 及格的樣子 |
|---|---|
| 意思對 | 一看就知道是什麼：岩膚是石頭、喝止是聲波、升級是天使翅膀；沒有和意思無關的零件 |
| 不廉價 | 有層次和細節，不是一團色塊、一根色條、一個平塗的圓；放在 RO 和救世者之樹旁邊不丟臉 |
| 風格一致 | 和場景、角色同一個世界，受光左上，不壓灰角色 |
| 大小比例 | 和角色身高比合理，預設鏡頭距離看得出來，不蓋掉半個畫面 |
| 看得清楚 | 亮石板、草地、暗樹林都分得出來；不被草蓋掉；白色的東西在亮地板上要有邊或光暈 |
| 不擋角色 | 不長時間蓋住角色本人和血條、名字 |
| 方向對 | 朝目標、朝滑鼠、朝面向的都對，四個方向各看一次 |
| 時間節奏 | 有預備、爆發、收尾，和動作、命中、聲音對得上，不殘留 |
| 連按不累積 | 連續放、連續喝，亮度和數量不會越疊越多 |
| 不卡頓 | 遊戲中不新建網格、材質、貼圖、粒子，量過產生那一幀 |
| 技術正確 | 透明、邊緣、縮放、匯入照 `docs/美術技術框架.md`；新素材來源記在 `docs/資產清單.json` |

## 美術另外審

| 項目 | 及格的樣子 |
|---|---|
| 長相來源 | 角色長相和筆觸只來自使用者畫的圖或使用者定的定稿；生成的網格和照姿勢重畫都失敗過 |
| 手 | NPC 立繪每隻手放大確認手指數和方向 |
| 立體感 | 場景小人斜側身、左上光右半身陰影、深色描邊、沒有白邊 |
| 精緻程度 | 照需求：翅膀要精緻寫實；圖示要和其他手繪圖示同一套 |

## 使用者說過的話

每一條都是使用者親口退件或要求過的，審的時候逐條對：

- 角色畫風：2026-09-28 看完紙偶、Meshy 全 3D、官方素體全 3D 三種小樣都說不行，貼了 `art_source/ref/user_pixel_ref_2026-09-28.webp`：「我要的參考圖是這樣」，白底版 `user_pixel_ref_sheet_2026-09-28.png`。
  目測一格約 4 圖素、角色約 80 格高，約 3 頭身；深色飽和、深色描邊、明暗四階以上帶色相偏移、服裝細節密，量到平均亮度約 100、飽和度 40 到 50，我們第 3 版是 199 和 20
- 角色造型：2026-09-28 第 4 版穿衣初心者，使用者說「有好一點但是角色太醜是在跟我開玩笑嗎」。
  頭、臉、頭髮用程式捏、沒有經過設計就會醜；造型要先有設計圖給使用者挑，再照設計做
- 角色 3D 轉八方向：2026-09-28 素體頭加 Meshy 服裝和頭髮三層的版本，使用者說「完全失敗」，把算圖刪了：
  「我要的是乾淨 符合畫風 沒壞的腳色 不是一堆半殘品」。畫風指定稿 `ori_restyle/klein_14.png`：清楚的像素格、深色描邊、臉亮眼睛大、色塊平；
  軟的 3D 算圖縮小、Meshy 貼圖的雜紋、一堆剩下沒修的小問題都算不及格。審的時候拿成品和定稿並排比，不是和上一版比；
  中間圖、分層示範、「剩下幾條不擋進度」都不要交
- 角色逐格 AI 重畫：2026-09-28 3D 姿勢圖給 Qwen 每格照定稿重畫的走路，使用者說「你生成出來的根本崩壞」。
  兩條腿糊成一根、頭一格大一格小、身體一格斜一格正、頭髮每格不同；單張看像樣不算數，要逐格並排和播動畫看有沒有跳、腿分不分得開
- 升級翅膀：一根一根攤開像扇子「沒有翅膀感」；膠囊圓瓣「太醜」；葉子形加描邊「太像卡通不夠莊嚴」；「要大一點精緻真實一點」
- 升級特效：「特效不足沒有帥氣特效」；播的時候「會卡」
- 普攻命中：「我喜歡原本的」火花，不要疊特效包的命中光
- 崩岩落：「不要打完還一團黑黑的在那」，要爆發和地面裂縫
- 喝止：「為啥要帶一個球，有啥相關」
- 岩膚：「特效很醜，不符合技能」
- 喝藥：「要閃那顏色的光」「不要全身變亮」「連按會一直發光」
- 全彩爆發：「好廉價」
- 範圍圈和鎖定：「做得太爛」「用戶體驗很差」「不要那個很粗的橘色」「不需要顯示射程」
- 技能特效：「方向不對」「技能攻擊時不播普攻的特效」
- 游標：「要改大一點」「不夠帥」「怎麼會失真」
- 技能樹：「你這是樹嗎」「像拼接，樹根很奇怪」
- 美術產出：「過了這麼久也沒給我看到任何東西」；做出第一張就要看，但要是審過的第一張
- 技能特效：「現在技能特效都太卡通，我要像 RO 那樣有點真實跟華麗打擊感的」，「包括喝藥水特效」
