# 美術與特效驗收標準

美術和特效做出來不是直接給使用者看，要先過兩位審查：Nora 美術總監看好不好看、風格對不對，
Felix 特效審查看在遊戲裡站不站得住。兩位都及格才交給使用者。
2026-09-27 使用者：「特效跟美術可以多一點人手把關，他們可以自行討論做法以及及不及格，有沒有達到要求，不要只是改出來就告訴我好了」。

## 流程

1. **先寫做法再動手**：Leo 或 Iris 寫一段做法，包含要表達什麼、參考了哪些成熟遊戲的哪個效果、分幾層、顏色和時間怎麼排。
   交給 Nora 和 Felix 先看，兩位可以改做法；做法沒過不動手
2. **做第一版**：照做法做，錄影或截圖，放大到看得清楚的對照圖，亮地板和草地各一張
3. **互審打分**：Nora 和 Felix 各自照下面的清單逐條給「及格、不及格、不適用」，不及格要寫清楚哪裡、怎麼改
4. **退回重做**：任一條不及格就退回做的人，改完再審；同一件東西三輪還過不了，停下來把卡住的地方回報使用者
5. **交給使用者**：兩位都及格才交，回報時圖在前，附上審查紀錄：審了幾輪、每輪退回的原因、最後怎麼解決的
6. **使用者退件**：使用者不滿意的意見加進下面的「使用者說過的話」，以後每一次都要照著審

製作人負責轉交：做的人和審查的人不能直接叫對方，做法、成品、審查意見都經過製作人轉，轉的時候原文照貼不刪。

## 通用清單，每一件都要審

| 項目 | 及格的樣子 |
|---|---|
| 意思對 | 一看就知道是什麼：岩膚是石頭、喝止是聲波、升級是天使翅膀；沒有和意思無關的零件，例如一顆不知道是什麼的光球 |
| 不廉價 | 有層次和細節，不是一團色塊、一根色條、一個平塗的圓；放在 RO 和救世者之樹旁邊不丟臉 |
| 風格一致 | 2.5D 賽璐璐：平塗硬邊陰影、受光兩段、左上光；不壓灰角色；和場景、角色同一個世界 |
| 大小比例 | 和角色身高比起來合理，在預設鏡頭距離下看得出來，也不會蓋掉半個畫面 |
| 看得清楚 | 亮的石板地、草地、暗的樹林各看一次都分得出來；不被草蓋掉；白色的東西在亮地板上要有邊或光暈 |
| 不擋角色 | 不長時間蓋住角色本人和血條、名字；閃一下可以，停著不行 |
| 方向對 | 朝目標、朝滑鼠、朝面向的東西方向都對，放在四個方向各看一次 |
| 時間節奏 | 有預備、爆發、收尾；和動作、命中、聲音對得上；不拖泥帶水，也不殘留，例如打完還一團黑煙 |
| 連按不累積 | 連續放、連續喝，亮度和數量不會越疊越多 |
| 不卡頓 | 遊戲中不新建網格、材質、貼圖、粒子，做一次重播；量過產生的那一幀，寫在紀錄裡 |
| 技術正確 | 透明、邊緣、縮放、匯入設定照 `docs/美術技術框架.md`；新素材的來源和授權記在 `docs/資產清單.json` |

## 美術另外審

| 項目 | 及格的樣子 |
|---|---|
| 長相來源 | 角色長相和筆觸只來自使用者畫的圖；生成的網格和照姿勢重畫都失敗過，不准用 |
| 手 | NPC 立繪每隻手放大確認手指數和方向 |
| 立體感 | 場景小人斜側身、左上光右半身陰影、深色描邊、沒有白邊；不要太平面 |
| 精緻寫實的程度 | 要照需求：翅膀這種要精緻寫實；圖示要和其他手繪圖示同一套 |

## 使用者說過的話

每一條都是使用者親口退件或要求過的，審的時候逐條對：

- 升級翅膀：一根一根攤開像扇子「沒有翅膀感」；膠囊圓瓣「太醜」；葉子形加描邊「太像卡通不夠莊嚴」；「要大一點精緻真實一點」
- 升級特效：「特效不足沒有帥氣特效」；播的時候「會卡」
- 普攻命中：「我喜歡原本的」火花，不要疊特效包的命中光
- 崩岩落：「不要打完還一團黑黑的在那」，要爆發和地面裂縫
- 喝止：「為啥要帶一個球，有啥相關」
- 岩膚：「特效很醜，不符合技能」
- 喝藥：「要閃那顏色的光」「不要全身變亮」「連按會一直發光」
- 全彩爆發：「好廉價」
- 範圍圈和鎖定：「做得太爛」「用戶體驗很差」「不要那個很粗的橘色」「不需要顯示射程」
- 技能特效：「方向不對」「技能攻擊時不播普攻的特效」
- 游標：「要改大一點」「不夠帥」「怎麼會失真」
- 技能樹：「你這是樹嗎」「像拼接，樹根很奇怪」
- 美術產出：「過了這麼久也沒給我看到任何東西」；做出第一張就要看，但要是審過的第一張
- 技能特效：「現在技能特效都太卡通，我要像 RO 那樣有點真實跟華麗打擊感的」，「包括喝藥水特效」

- 2026-09-27 重擊和暴擊的畫面閃光一律閃，不加「減少閃光」開關
