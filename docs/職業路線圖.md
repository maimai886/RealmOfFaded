# 職業路線圖

2026-09-17 使用者定的職業地圖：八條線、四個階級，每個一轉分岔成兩條二轉，每個二轉接一個三轉，共二十一個職業。
資料全部在 `data/jobs.json`，路線照 `next_jobs`，固定屬性是 `colour_element`，程式不寫死職業清單。

| 線 | 一轉 | 二轉 | 三轉 |
|---|---|---|---|
| 劍 A | 劍侍 `squire` | 聖劍士 `holyblade` | 勇者 `champion` |
| 劍 B | 劍侍 `squire` | 劍客 `bladesman` | 劍豪 `blademaster` |
| 法 A | 術士 `sorcerer` | 巫師 `wizard` | 大賢者 `archsage` |
| 法 B | 術士 `sorcerer` | 方術士 `thaumaturge` | 陰陽師 `onmyoji` |
| 弓 A | 斥候 `scout` | 獵人 `hunter` | 神射手 `sniper` |
| 弓 B | 斥候 `scout` | 刺客 `assassin` | 忍者 `ninja` |
| 信 A | 信徒 `devout` | 神職者 `clergy` | 神諭官 `oracle` |
| 信 B | 信徒 `devout` | 行者 `ascetic` | 鬥聖 `warsaint` |

每條線都從初心者 `novice` 開始。

## 代號規則

- `hero` 永遠指聖劍士，舊存檔讀進來一律換成 `holyblade`，所以勇者不能用 `hero`，否則新存檔會被當成舊存檔換掉而且不報錯。
- 其他舊代號也留在對照表：`magician` 換 `sorcerer`、`elemancer` 換 `wizard`、`windchaser` 換 `hunter`。
- 改代號時顯示名稱和代號一起換，不留半套。

## 現況

- 二十一個職業的資料和轉職路線都通，每一步都有 NPC 可以轉。
- 職業圖標二十一個都有，來源是使用者畫的 `art_source/ui/job_icons_raw.png`，由 `art_pipeline/ui/job_icons.py` 切成 `assets/ui/icons/jobs/<代號>.png`；新職業要補一格。
- 有技能的只有初心者、一轉四職、聖劍士、巫師、獵人、神職者、行者，其他職業技能視窗是空的一頁，這是刻意的，不能當掉。技能規劃在 `docs/技能與流派.md`。
- 所有職業和男女現在共用同一份素體，職業差別之後做成服裝圖層，`art_id` 就是自己的代號。
- 刺客和忍者的最佳武器暫時是弓，等短刃執做出來再換成短劍。
- 行者和鬥聖暫時掛 `magic_skills`，因為它們現在用信徒的法術；自己的體術做出來就拿掉。
- 職業等級上限和轉職門檻在 `data/balance.json` 的 `levels`，經驗表在 `data/exp_tables.json`；2026-09-19 定案的兩輪制在 `docs/轉生與等級.md`，還沒做進資料。
