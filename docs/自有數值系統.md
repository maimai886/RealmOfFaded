# Realm of Faded 自有數值系統

2026-09-16 定案。這份取代原本「全部照 RO Renewal」的做法，是 ROF 自己的一套算法。
玩起來仍然是類 RO 的手動戰鬥節奏，但屬性的分工、減傷的形狀、屬性相剋的形狀、攻速、經驗曲線都是我們自己的。
屬性名稱用玩家熟悉的九種：無屬性、火、水、風、土、光、暗、時間、空間。

資源三條：HP、SP、彩度。彩度是 2026-09-24 使用者定的消耗型資源，數值在第 9 節。

`docs/歷史/參考規格.md` 從現在起只是「我們借了什麼、在哪裡分家」的紀錄，實作以這份為準。
所有常數放在 `data/balance.json`，程式不寫死數字；公式實作在 `src/core/formulas.gd`。

---

## 0. 為什麼要自己一套

照抄 rAthena 有三個實際問題，不只是原創性：

1. RO 的減傷是「乘一個接近 1 的分式再減掉軟 DEF」，低等級打高 DEF 怪只剩最低傷害 1，看起來像沒打到；高等級又幾乎沒有減傷。
2. RO 的命中率是 `HIT − FLEE` 直接當百分比，兩個都是一百多的數字相減，AGI 加 20 點只換到 20% 命中，感受很不線性，而且很容易撞到上下限。
3. RO 的六項屬性在 Renewal 之後分工模糊，AGI 和 DEX 都影響攻速，LUK 幾乎只影響暴擊，配點沒有真正的選擇。

我們的目標：六項屬性各有明確、互不重疊的工作；所有曲線都是「比例型」而不是「相減型」，任何等級差都不會出現免疫或秒殺。

原創不等於改名字。2026-09-16 使用者定調：屬性名稱用玩家一眼就懂的九種，不自創新名詞，
自己的東西要做在**算法**上。所以屬性叫火水風土光暗時間空間，但相剋的形狀、等級縮放、
還有時間和空間的機制都是我們自己的。

## 1. 六項屬性

名字沿用 STR、AGI、VIT、INT、DEX、LUK，讓玩家一眼認得出是這個類型的遊戲，但工作內容是我們自己的。

| 屬性 | 中文 | 負責 |
|---|---|---|
| STR | 力量 | 物理攻擊力，而且是武器攻擊的倍率來源；負重上限 |
| AGI | 敏捷 | 每秒攻擊次數；迴避 |
| VIT | 體魄 | 最大 HP；韌性也就是防禦的一部分；HP 自然恢復 |
| INT | 心智 | 魔法攻擊力；SP 上限；SP 自然恢復 |
| DEX | 靈巧 | 命中；詠唱速度；遠程職業的主攻擊屬性 |
| LUK | 幸運 | 暴擊率與暴擊倍率的上限；迴避與純淨閃避；精煉、製作、擲詞綴的運氣 |

和 RO 的差別
- RO 的 AGI 和 DEX 一起決定 ASPD，我們只用 AGI 決定攻速，弓系才讓 DEX 補一半。攻速想快就加 AGI，不必兩個都加。
- RO 的 LUK 只有暴擊和完全迴避，我們把它做成「擲骰的時候站在你這一邊」的屬性：
  暴擊的倍率變成一個帶子而 LUK 撐的是上限，再接上精煉、製作、擲詞綴這三個系統的運氣，見第 2.6 節。
  **LUK 不影響掉落率。** 2026-09-17 定案，理由在第 2.6 節最後一段。
- RO 的 VIT 只有 HP 和軟 DEF，我們的韌性同時吃 VIT 和等級，而且走比例型的減傷曲線，所以堆 VIT 一路到滿都有回報。
- RO 的 STR 只是加法，我們讓 STR 同時放大武器攻擊，裝備因此一直有感，不會越後期越無所謂。

### 1.1 加點費用

從 x 加到 x+1 要花 `⌊x/10⌋ + 1` 點。

| 區間 | 每點花費 | 累積到該值 |
|---|---|---|
| 1 → 10 | 1 | 9 |
| 10 → 20 | 2 | 29 |
| 20 → 30 | 3 | 59 |
| 30 → 40 | 4 | 99 |
| 40 → 50 | 5 | 149 |
| 50 → 60 | 6 | 209 |

RO 是 `⌊(x−1)/10⌋ + 2`，也就是最低就要 2 點。我們前十點只要 1 點，開局六十點可以立刻把主屬性拉到 20 出頭，第一個小時就打得動東西。
後段每十點升一級費用，和 RO 一樣會變貴，但貴得比較慢，六十級時一個角色大約能養出「兩項滿、一項四十、一項三十」的身材。

起始點數 60，升一級拿 `3 + ⌊Lv/5⌋` 點。60 級累積 579 點。RO 是起始 48、每級 `⌊Lv/5⌋ + 3`，我們把起點加高，是為了讓剛創的角色就有東西可以決定。

## 2. 傷害

### 2.1 攻擊力

```
主屬性 = 近戰 STR，遠程 DEX
副屬性 = 近戰 DEX，遠程 STR
基礎攻 = 主屬性 + 等級 × 0.5 + 副屬性 × 0.25 + LUK × 0.2
ATK   = ⌊基礎攻⌋ + ⌊武器攻 × (1 + 主屬性 / 100)⌋
```

`MATK` 同形狀，主屬性換成 INT，並且 INT 本身權重是 1.5：

```
MATK = ⌊INT × 1.5 + 等級 × 0.5 + DEX × 0.25⌋ + ⌊武器魔攻 × (1 + INT / 100)⌋
```

和 RO 的差別：RO 是 `STR + DEX/5 + LUK/3 + Lv/4 + 武器ATK`，武器和屬性各加各的，越後期武器佔比越低。
我們把武器放進倍率裡，STR 60 時一把武器等於 1.6 把，撿到好武器一定有感；同時屬性本身還是線性，不會變成 pre-renewal 那種 `⌊STR/10⌋²` 的滾雪球。

### 2.2 減傷：百分比曲線

```
總防 = 裝備 DEF + 韌性，韌性 = ⌊VIT × 0.8 + 等級 × 0.4⌋
減傷率 = 總防 / (總防 + K)，K = 50 + 10 × 攻擊方等級
最後傷害 = ⌊攻擊力 × 浮動 × 屬性倍率 × (1 − 減傷率)⌋，最少 1
```

魔法用同一個形狀，換成 `總魔防 = MDEF + ⌊INT × 0.5 + 等級 × 0.3⌋`、`Km = 40 + 8 × 攻擊方等級`。

和 RO 的差別
- RO Renewal 是 `傷害 × (4000 + eDEF) / (4000 + 10 × eDEF) − sDEF`，硬 DEF 走分式、軟 DEF 直接相減。相減的那一項是低等級打不動高 DEF 怪的元凶，而且 4000 這個常數不隨等級變，等級一高 DEF 就等於沒用。
- 我們只有一個數字「總防」，軟的硬的都加進去，然後走一條標準的 `x/(x+K)` 曲線。它永遠小於 1，所以沒有任何怪會免疫；`K` 隨攻擊方等級上升，所以同一件裝備會隨著敵人變強而慢慢失效，裝備更新有意義。
- 設計錨點：同等級的怪，減傷率固定在 25% 附近，也就是怪物 DEF ≈ (50 + 10 × 等級) / 3。

### 2.3 命中對迴避：機率曲線

```
命中 ACC = ⌊20 + 等級 + DEX × 1.5⌋ + 裝備命中
迴避 EVA = ⌊20 + 等級 + AGI × 1.5 + LUK × 0.3⌋ + 裝備迴避
命中率% = 160 × ACC / (ACC + EVA)，夾在 10% 到 95%
```

兩邊相等時 80%。ACC 是 EVA 的兩倍時撞到上限 95%，ACC 只有 EVA 的四分之一時還有 32%。

和 RO 的差別：RO 是 `HIT − FLEE` 直接當百分比，兩個一百多的數字相減，等級差 10 級就從 90% 掉到 5%，而且 175 和 100 這兩個起始常數沒有任何意義。
我們用比值，曲線平滑、兩端都不會鎖死，而且 AGI 從 5 加到 60 真的把被打中的機率從 95% 壓到 66%，加點看得到回報。

### 2.4 暴擊

```
暴擊千分比 = 20 + LUK × 3 + ⌊等級 / 2⌋，再扣掉目標 LUK × 3
暴擊倍率的地板% = 150                 不管 LUK 多少
暴擊倍率的上限% = 150 + LUK × 1.0     這是 LUK 真正買到的東西
這一次的暴擊倍率  = 在地板和上限之間均勻擲一次
純淨閃避千分比 = LUK × 2              連暴擊也躲得掉
```

**LUK 買的是「一次暴擊最多能打多痛」，不是每一次都打那麼痛。** 所以 LUK 流的傷害是高變異的：
LUK 60 的暴擊在 150% 到 210% 之間跳，平均 180%；LUK 99 是 150% 到 249%，平均 199.5%。
平均值正好等於「地板加上 LUK × 0.5」，也就是還沒有上限這個概念之前的固定倍率，所以這個形狀沒有偷偷改期望傷害，
改的是手感：同樣一個 LUK 流角色，偶爾會打出一下特別痛的，那一下才是堆 LUK 的人在等的東西。

和 RO 的差別：RO 暴擊倍率固定 1.4 倍，暴擊率 `10 + LUK×3 + Lv/10`，完全迴避是 `LUK + 10`。
我們讓暴擊倍率變成一個會跟著 LUK 撐開的帶子，LUK 60 是 1.5 到 2.1 倍，LUK 流才有爆發力也才有變異；
完全迴避拿掉 RO 那個「LUK 1 也送 1%」的常數，純粹靠 LUK。


### 2.6 幸運在戰鬥之外

2026-09-17 定案。LUK 除了上面那幾條，還接上三個「要擲骰」的系統。曲線全部是同一個形狀：

```
幸運千分比 = LUK / (LUK + soft) × 1000，再夾一個上限
實際成功率 = 100% − (100% − 基礎成功率) × (1 − 幸運千分比 / 1000)
```

常數在 `data/balance.json` 的 `luck`，實作在 `src/core/formulas.gd` 的 `refine_luck_permille`、
`craft_luck_permille`、`affix_luck_permille` 和共用的 `lucky_success_percent`。

| 出口 | soft | 上限 | LUK 30 | LUK 60 | LUK 99 |
|---|---|---|---|---|---|
| 精煉成功率 | 300 | 200‰ | 90‰ | 166‰ | 200‰ |
| 製作成功率 | 200 | 350‰ | 130‰ | 230‰ | 330‰ |
| 擲詞綴再擲一次的機會 | 60 | 650‰ | 333‰ | 500‰ | 622‰ |

**為什麼是「砍掉一部分失敗機率」而不是「加幾個百分點」。** 加百分點的話，安全等級本來就 100%，
那幾點幸運等於丟進水裡；而且加得越多越接近穩贏，最後會變成「LUK 夠高就不用怕」。
砍失敗機率剛好相反：本來就不會失敗的地方幸運一點用都沒有，越危險的地方同樣的幸運砍下去越有感，
而且不管幸運多高都砍不到 100%，程式裡再壓一道 99% 的上限。**會賭的那幾級永遠是一個賭注。**

**為什麼三條的上限不一樣。** 精煉失敗會把裝備打爆，所以它的上限最低，只有兩成；
製作失敗只賠一半材料，賭注小很多，所以放到三成五；擲詞綴根本不會失敗，
幸運買的只是「再擲一次取比較好的那一個」的機會，帶的上限一點都沒有變，所以放得最寬。
換句話說：**損失越重的那個系統，幸運能幫的越少。**

**擲詞綴那一條為什麼安全。** 每一條詞綴的最大值寫在 `data/affixes.json`，幸運只影響擲出來的點數
有多常靠近那個最大值，擲不出超過上限的值。而且重鑄本來就是「花錢重擲整組」的管道，
任何人不加 LUK 也走得到同一個天花板，所以這一條是幫你省重鑄的次數，不是幫你解鎖東西。
掉落的裝備算的是打倒那隻怪的人的幸運，做出來的算做的人的幸運。

**刻意沒有給 LUK 的東西**

- **掉落率。** 文件以前寫了但程式從來沒有實作，2026-09-17 決定把這條宣告拿掉而不是補上去。
  理由不是做不到：掉落率屬性會變成一種稅，每個人都得加一點，不然就覺得自己在打折扣價的怪，
  那和「六項屬性各有明確的工作、配點是真的選擇」是反方向的。而且掉落率當下感覺不到，
  玩家只會事後看表格，不會在打的時候覺得這一點加得值得。真的要調掉落率就直接調 `monsters.json` 的 `chance`。
- **經驗和金幣加成**：同一個理由，而且會直接和練等步調那一節的保證打架。
- **命中**：命中是 DEX 的工作，兩個屬性搶同一件事就是 RO Renewal 那個「AGI 和 DEX 都影響攻速」的老問題。
- **狀態異常抗性、詠唱速度、負重**：各有各的屬性，LUK 不要變成「加一點什麼都有」。

**LUK 是副屬性不是主屬性。** `tests/test_balance.gd` 的
`test_dumping_everything_into_luk_is_a_trade_not_a_free_win` 每次跑都印出這張表：
點數全部丟進 LUK 的角色打死同等級怪要花一般配點的兩倍時間，撐得也沒有比較久。
所以 LUK 不是一條可以走到底的路，它是一條「分一些點過去換暴擊和運氣」的路，這是刻意的。

### 2.5 技能怎麼乘進來

技能的 `damage_percent` 乘在攻擊力上，順序是：攻擊力 → 浮動 80～120% → 技能倍率 → 屬性倍率 → 減傷 → 最少 1 → 暴擊倍率。
和普攻唯一的差別是多了技能倍率那一段，公式本體共用，所以普攻改了技能一定跟著改。

## 3. 屬性相剋

屬性名稱用玩家一眼就懂的九種，不自創新名詞：**無屬性、火、水、風、土、光、暗、時間、空間**。
RO 有十種屬性、四個防禦等級、四張 10×10 表共 400 格，大部分格子是 100。我們只有一張 9×9 表加一條等級縮放規則。

| id | 名稱 | 定位 |
|---|---|---|
| `neutral` | 無屬性 | 基準線，打誰都 100%，被誰打也 100%。不賺也不賠，所以是起手和萬用的選擇 |
| `fire` | 火 | 四元素循環的一員 |
| `water` | 水 | 四元素循環的一員 |
| `wind` | 風 | 四元素循環的一員 |
| `earth` | 土 | 四元素循環的一員 |
| `light` | 光 | 和暗互為死敵，對四元素完全中立 |
| `dark` | 暗 | 和光互為死敵，灰蝕化的怪都是這一屬 |
| `time` | 時間 | 和空間互為死敵，身分是機制不是倍率，見 3.2 |
| `space` | 空間 | 和時間互為死敵，身分是機制不是倍率，見 3.2 |

規則只有四條

1. 四元素走一個循環：**水剋火、火剋風、風剋土、土剋水**。剋是 150%，反方向 70%，循環上不相鄰的兩個互不影響。
   說法：水澆熄火、火吞掉風、風磨蝕土、土吸收水。
2. **光和暗互為死敵，互打 175%**，對四元素兩個方向都是 100%。高風險高回報，沒有安全的一邊。
3. **時間和空間互為死敵，互打 150%**，對其他一律 100%。
4. 打同屬性一律 80%；無屬性不管在哪一邊都是 100%。

### 3.1 屬性等級與夾限

資料欄位沿用 `element_level` 1 到 4，意義是「把偏離 100 的幅度每級放大一成」：

```
實際倍率 = 100 + (基本倍率 − 100) × (1 + 0.1 × (等級 − 1))
最後夾在 50% 到 175%
```

水打 1 級火是 150%，打 4 級火是 `100 + 50 × 1.3 = 165%`；火打 4 級水是 `100 − 30 × 1.3 = 61%`；打同屬性 4 級是 74%。
光打暗本來就在 175% 的上限，屬性等級再高也不會突破。

和 RO 的差別：RO 為了四個等級維護四張獨立的表，改一個數字要改四個地方，而且有很多 0% 的格子，
玩家會遇到「這隻怪我永遠打不動」。我們只有一張表加一條規則，下限 50% 打得動只是不划算，上限 175% 也不會一擊斃命。

### 3.2 時間和空間的機制

第九和第十種傷害屬性要有存在的理由，所以這兩種的身分是機制，不是倍率。常數在 `data/balance.json` 的 `element_effects`。

**時間：遲滯**

- 時間屬性打中會在目標身上疊一層**遲滯**，最多三層，每層攻速降 8%，持續 4 秒，再被打中就刷新時間並加一層。
- 三層時攻擊間隔變成原本的 1.32 倍。遲滯是一個狀態不是三個，和冰凍、暈眩一樣由伺服器維護、走同一套 `buff_start` 事件，畫面上是頭上一顆淡紫星。
- 同一下也會把**攻擊方自己的增益**剩餘時間延長 1 秒，但延長後不會超過那個增益本來的長度，所以不能靠一直打怪把增益養成永久的。

**空間：切開空間而不是切開盔甲**

- 空間屬性的傷害**無視目標 30% 的防禦**，再走一般的減傷曲線。厚甲怪特別怕空間。
- 空間是負責位移的屬性：推開、拉近、換位都歸它。技能沒有自己寫擊退時，空間屬性的命中本身就會把目標推開 0.6 公尺，連普通攻擊也一樣，事件會帶 `space_push`。

### 3.3 玩家怎麼拿到屬性

2026-09-25 奪色世界定案，規則在 `docs/奪色世界規劃書.md` 第 4 節和第 5 節：

- **調色盤決定攻擊屬性。** 技能放在快捷列那一格挑調色盤裡的一個屬性，沒挑就是無屬性；

  防禦屬性不跟著走，不然換一顆火色種等於順便穿了一身火抗。
- 調色盤最多四顆色種，色種只從王掉；職業固定屬性另外算，不佔四格，每職是什麼在 `docs/技能與流派.md` 第 2 節。
- 光：聖劍士、信徒、神職者、勇者、神諭官的固定屬性是光，其他職業要把光的色種放上調色盤。

- 時間和空間：方術士固定時間、陰陽師固定空間，其他職業靠深處王掉的色種。
- 暗：刺客和忍者的固定屬性是暗；暗屬性的怪被光打是 175%。

### 3.4 對應

- 怪物：露珠果凍水、苔蘚與甲蟲與石類土、蜂與禽鳥風、發光的菌菇光、骷髏行屍與被灰蝕抽乾的樹暗。

## 4. 攻速

直接定義「每秒攻擊次數」，再換算成打擊感規格要的毫秒，`docs/打擊感規格.md` 的時間軸契約完全不變。

```
每秒攻擊次數 aps = 武器基礎 aps × (1 + 攻速屬性 × 1.5 / 100)，上限 2.5
  攻速屬性：近戰 = AGI，遠程 = AGI + DEX × 0.5
amotion 毫秒 = 500 / aps
adelay 毫秒  = 1000 / aps = 2 × amotion
```

程式裡 aps 一律用千分比整數存，`jobs.json` 的 `aspd_base` 就是武器基礎 aps 的千分比。

|---|---|---|---|---|---|---|---|---|
| 初心者 | 0.86 | 0.85 | 0.83 | — | 0.74 | — | — | −0.03 |
| 劍侍 | 0.86 | 0.88 | 0.88 | 0.80 | — | — | — | −0.02 |
| 術士 | 0.80 | 0.80 | — | — | 0.78 | — | — | −0.03 |
| 斥候 | 0.86 | 0.85 | — | — | — | — | 0.82 | −0.03 |
| 信徒 | 0.84 | 0.84 | — | — | 0.74 | 0.80 | — | −0.025 |
| 聖劍士 | 0.88 | 0.90 | 0.92 | 0.84 | — | — | — | −0.02 |
| 巫師 | 0.82 | 0.82 | — | — | 0.84 | — | — | −0.02 |
| 獵人 | 0.88 | 0.86 | — | — | — | — | 0.88 | −0.03 |
| 神職者 | 0.86 | 0.86 | — | — | 0.78 | 0.86 | — | −0.02 |

提爐是信徒和神職者專屬的武器種類 `censer`，甩起來比劍慢、比法杖快。
這條路線要站在隊伍中間才救得到人，所以攻擊距離 1.8 公尺，比劍侍的 1.6 遠一點。

對照：1 級初心者 AGI 1 拿短刀，aps = 0.85 × 1.015 = 0.863，amotion 580ms、adelay 1159ms。
RO Renewal 同樣條件是 amotion 590ms、adelay 1180ms，幾乎一樣，所以開局的打擊感和量測過的數字接在一起，不用重新調打擊感。

和 RO 的差別：RO 是 `int(196 + sqrt(DEX²/5 + AGI²/2)/4) − 職業基礎值`，再 `amotion = 2000 − ASPD × 10`。
那條式子的 196、2000、上限 190 都是歷史包袱，而且是先算一個沒有單位的 ASPD 再倒推時間，看不出「這把武器一秒揮幾下」。
我們直接定義一秒揮幾下，職業表一眼看得懂，AGI 60 時劍侍雙手劍 adelay 從 RO 的 980ms 變成 621ms，AGI 真的能把攻速拉起來。

技能和增益的攻速加成鍵維持 `aspd_fixed`、`aspd_percent`、`amotion_add_ms`、`aspd_cap` 四個，
意義改成：`aspd_fixed` 一點等於 aps 加 0.02、`aspd_percent` 乘在 aps 上、`amotion_add_ms` 一樣直接加毫秒、`aspd_cap` 是 aps 千分比上限。
技能資料不用改，換算比例寫在 `balance.json` 的 `aspd_fixed_permille_per_point`。

### 5.3 HP 和 SP

```
HP 基底 = 40 + 成長 × (Lv − 1) + 曲率 × (Lv − 1)² / 100
最大 HP = ⌊HP 基底 × (1 + VIT × 0.015)⌋
SP 基底 = 15 + SP成長 × (Lv − 1) + SP曲率 × (Lv − 1)² / 100
最大 SP = ⌊SP 基底 × (1 + INT × 0.020)⌋
```

成長和曲率寫在 `jobs.json` 的 `hp_growth`、`hp_curve`、`sp_growth`、`sp_curve`。
RO 是一個從 2 累加到 Lv 的迴圈加上 `HpIncrease/100`，結果一樣是二次曲線但看不出參數的意思；我們直接寫成一次項加二次項，要調哪一段一目了然。

### 5.4 經驗曲線與步調目標

```
升到下一級要的基本經驗 = round(30 × Lv^1.85 + 70 × Lv)
每級要打的同等級怪隻數 = 8 + 0.17 × Lv
怪物基本經驗 = round(升級經驗 / 每級隻數)
怪物職業經驗 = round(基本經驗 × 0.55)
```

怪物經驗是從「每級要打幾隻」反推的，所以步調是保證的，不是調出來的。

| 等級帶 | 每級隻數 | 說明 |
|---|---|---|
| 1 – 10 | 8 – 10 | 萌芽草原，一隻約 4 到 6 秒，升一級大約 1 分鐘 |
| 11 – 20 | 10 – 11 | 低語森林 |
| 21 – 32 | 12 – 13 | 碎石谷與灰蝕地窟 |
| 33 – 60 | 14 – 18 | 之後的內容 |

RO 官方 1 倍速同等級怪要 40 到 60 隻升一級。我們取五分之一左右，理由是手機單次遊玩時間短，十分鐘內要看得到升級。
前期又比後期更快（8 隻對 18 隻），前二十級刻意壓縮，讓新角色很快走完「選職業」這段。

最後那二十級給的技能點沒有東西可以買，所以現在是「又貴又沒有回報」。先解決技能點再回頭看這裡的數字。

## 8. 金幣：怪物不掉錢，錢只能賣戰利品

2026-09-18 定案：**打怪不掉金幣，所有金幣只能靠把戰利品賣給商人取得。**
2026-09-17 那一版怪物會掉錢而且是主要收入，只活了一天；那一版的曲線和 `gold_min`、`gold_max` 欄位全部拿掉了。
首殺獎勵也只剩經驗，不再給錢。任務獎勵的金幣先不動，任務目前整套關著。

### 8.1 曲線

```
一隻一般怪身上的戰利品賣給商人的期望值 = 14 + 2.0 × Lv + 0.30 × Lv²
期望值 = Σ 每一項掉落的 機率 × 平均數量 × 賣價，只算賣得掉的道具
```

常數在 `data/balance.json` 的 `loot_value`，公式在 `Formulas.monster_loot_value`。
這條曲線不是程式在用的，程式只擲掉落表；它是 `data/monsters.json` 掉落表和 `data/items.json` 賣價要對齊的目標。
`tests/test_world_content.gd` 的 `test_every_monster_loot_value_follows_the_curve` 守住：
一般怪的期望值不能偏離曲線三成以上，精英和 Boss 至少要值一隻同級的一般怪，召喚出來的小怪不能有掉落表。

形狀是二次曲線不是線性，因為要買的東西本身就是跳著漲的：長劍 1,500、鋼刃劍 9,000、守林劍 42,000。
線性的收入會讓中後期永遠買不起當期裝備。

### 8.2 怎麼對到曲線

每一隻一般怪有一個主材料，機率四到五成，賣價照等級帶往上跳；次要材料、低機率的藥水和裝備補剩下的兩三成。
材料賣價這次全部重定，例如露珠凝膠 18、脆骨 24、灰狼皮 200、蝠翼 300、灰蝕餘燼 400、空殼甲片 700，
買價一律是賣價的兩倍。二十五級以上的怪光靠一顆材料不夠，用 `amount_max` 讓主材料一次掉一到三個。

`no_sell` 的東西不算收入，萌芽種子就是這樣，所以苔蘚人的錢來自苔蘚不是種子。
賣價高的消耗品掉落會把曲線撐爆，花蜜從 25% 壓到 3%。

伺服器只會發道具掉落。`_roll_drops` 只擲掉落表，掉落物和撿取事件沒有 `gold` 欄位，
資料裡就算寫了 `gold_min`、`gold_max` 或首殺的 `gold`，伺服器也不理，`test_monsters_never_drop_money_even_if_data_says_so` 守著這一條。
客戶端撿金幣的顯示路徑留著，之後任務或商店退款要用。

## 9. 彩度

2026-09-24 到 09-25 使用者一路定的，規則在 `docs/奪色世界規劃書.md` 第 6 節。這一節只寫算法和數字，

### 9.1 掉和回

|---|---|---|
| 掉 | 待在線稿區 | 每秒掉，地圖上色度越低掉越快，彩色的地方不掉 |
| 掉 | 放有色的技能 | 每招的彩度消耗寫在技能上，詠唱完成時才扣 |
| 回 | 站在彩色的地方 | 上色度高的區域、自己或隊友技能塗過的地面，每秒回 |
| 回 | 打中怪 | 每打中一下回一點；劍線的普攻回得最多；換屬性打比一直用同一個屬性回得多 |
| 回 | 打倒怪 | 怪死時附近的人各回一些 |
| 回 | 治療和擋傷 | 補了多少血、擋下多少傷害照比例回，補師不打怪也回得了 |
| 回 | 顏料 | 像藥水一樣直接喝 |

- **彩度歸零**：有色的技能退回無色版本，改耗 SP，直到彩度回來。
- 彩度不夠時繼續待在線稿區，改成扣 HP。
- 每一格的速度和每招的消耗都是待調。

### 9.2 強行上色

彩度不夠時長按技能鈕可以用 HP 付彩度，放出有色的版本。照比例算，前期後期、坦和法師一樣痛：

```
強行上色扣的 HP = 最大 HP × 技能彩度消耗 ÷ 彩度上限 × 換算倍率
換算倍率 = 1.5 + 0.5 × 這幾秒內已經連續強行的次數
```

- 一招要一成彩度，第一次強行扣最大 HP 的 15%，緊接著第二次 20%、第三次 25%，停手幾秒倍率回到 1.5。重置秒數待調
- **付出去的 HP 變成線稿**：那一段在血條上畫成灰線，暫時降低最大 HP，治療補不回來，彩度回來時才跟著恢復。恢復速度待調
- 詠唱完成時才扣，詠唱中取消不扣；扣到 0 就是死亡
- 長按時技能鈕和血條先顯示這一招會吃掉多少血
- 全彩爆發不能強行

### 9.3 全彩爆發

每個職業一開始就有，不佔點，見 `docs/技能與流派.md` 第 5.1 節。

```
能放：彩度 ≥ 90
倍率 = 500% + (彩度 − 90) × 20%，彩度 90 是 500%，100 是 700%
```

- 以自己為中心半徑 4 公尺，放完彩度歸零、技能褪色
- 對每隻怪自動用自己手上最剋牠的屬性，手上的屬性是調色盤加職業固定屬性
- 放完那一圈地面彩色 20 秒，站在上面回彩度

### 9.4 怪物適應屬性

只有菁英和王會。同一個屬性打中牠每 20 下，牠對這個屬性的抗性 +10%，最多 +40%。

```
適應抗性 = min(⌊同屬性命中數 ÷ 20⌋ × 10%, 40%)
最後傷害 = 相剋表算完的傷害 × (1 − 適應抗性)
```

- 脫離戰鬥歸零，不會因此回血；每個屬性分開算，換屬性打就不吃這個抗性
- 無屬性不算，PVP 關掉
- 這是讓打王的人換著用調色盤的主要理由，和第 9.1 節「換屬性打回比較多彩度」是同一個方向

### 9.5 擁有權和死亡

- **掉落擁有權**：王 10 秒，一般怪維持 3 秒；有資格撿的是傷害最高的一方，隊伍就是整隊，照《隊伍規格》第 5 節的分配
- **死亡**：扣這一級經驗的 1%，見第 5.5 節

### 9.6 色魄和色種的數字

- 色魄掉率初值：一般怪千分之一到千分之三、菁英約百分之一、地區王百分之五到十，照每小時能打幾隻調
- 色種：地區王掉 20%；每個角色第一次參與打倒某一隻王，那顆色種直接進背包
- 色種分五階，跟著王所在的等級段，第幾階就要對應的裝備等級；特性的倍率跟著階級長，每一階的數字待調
