# Realm of Faded 自有數值系統

2026-09-16 定案，ROF 自己的算法，不照抄 RO Renewal。所有常數在 `data/balance.json`，程式不寫死數字。
Rust 版放 `rust/crates/core`，還沒搬的部分照舊專案 `../Sproutia/src/core/formulas.gd` 的行為。

目標：六項屬性各做各的事不重疊；所有曲線都是比例型不是相減型，任何等級差都不會免疫或秒殺。
2026-09-16 使用者定調：屬性名稱用玩家一眼就懂的，原創要做在算法上，不是改名字。

## 1. 六項屬性

| 屬性 | 負責 |
|---|---|
| STR | 物理攻擊力，也是武器攻擊的倍率；負重 |
| AGI | 每秒攻擊次數；迴避 |
| VIT | 最大 HP；韌性，算進防禦；HP 恢復 |
| INT | 魔攻；SP 上限與恢復 |
| DEX | 命中；詠唱速度；遠程的主攻擊屬性 |
| LUK | 暴擊率和暴擊倍率上限；迴避和純淨閃避；精煉、製作、擲詞綴的運氣 |

- 開局 60 點，升一級給 `3 + ⌊Lv/5⌋` 點；從 x 加到 x+1 花 `⌊x/10⌋ + 1` 點，前十點只要 1 點
- LUK 不影響掉落率、經驗和金幣，2026-09-17 定案：掉落率屬性會變成人人都得加的稅，配點就不是選擇了

## 2. 傷害

```
主屬性 = 近戰 STR，遠程 DEX；副屬性反過來
ATK  = ⌊主屬性 + 等級 × 0.5 + 副屬性 × 0.25 + LUK × 0.2⌋ + ⌊武器攻 × (1 + 主屬性 / 100)⌋
MATK = ⌊INT × 1.5 + 等級 × 0.5 + DEX × 0.25⌋ + ⌊武器魔攻 × (1 + INT / 100)⌋

總防 = 裝備 DEF + ⌊VIT × 0.8 + 等級 × 0.4⌋
減傷率 = 總防 / (總防 + 50 + 10 × 攻擊方等級)
總魔防 = MDEF + ⌊INT × 0.5 + 等級 × 0.3⌋，魔法的 K = 40 + 8 × 攻擊方等級

命中 = ⌊20 + 等級 + DEX × 1.5⌋ + 裝備命中
迴避 = ⌊20 + 等級 + AGI × 1.5 + LUK × 0.3⌋ + 裝備迴避
命中率% = 160 × 命中 / (命中 + 迴避)，夾在 10 到 95

暴擊千分比 = 20 + LUK × 3 + ⌊等級 / 2⌋ − 目標 LUK × 3
暴擊倍率 = 在 150% 和 150% + LUK × 1% 之間均勻擲
純淨閃避千分比 = LUK × 2，連暴擊也躲得掉
```

- 計算順序：攻擊力、浮動 80～120%、技能倍率、屬性倍率、減傷、最少 1、暴擊倍率。普攻和技能共用同一條，只差技能倍率
- 設計錨點：同等級的怪減傷率在 25% 左右，也就是怪物 DEF 約 `(50 + 10 × 等級) / 3`

## 3. 幸運在戰鬥之外

```
幸運千分比 = LUK / (LUK + soft) × 1000，再夾上限
實際成功率 = 100% − (100% − 基礎成功率) × (1 − 幸運千分比 / 1000)，最高 99%
```

soft 和上限在 `balance.json` 的 `luck`，精煉、製作、擲詞綴各一組。
幸運砍的是失敗機率，所以本來不會失敗的地方沒用、越危險越有感；損失越重的系統上限越低，精煉最低。
擲詞綴的幸運只是「再擲一次取好的」，擲不出帶子的上限。

## 4. 屬性相剋

九種：無、火、水、風、土、光、暗、時間、空間。表在 `data/elements.json`，規則四條：

1. 水剋火、火剋風、風剋土、土剋水，剋 150%、反方向 70%，不相鄰的互不影響
2. 光暗互打 175%，對四元素 100%
3. 時間空間互打 150%，對其他 100%
4. 打同屬性 80%；無屬性不管在哪邊都是 100%

屬性等級 1 到 4：`實際倍率 = 100 + (基本倍率 − 100) × (1 + 0.1 × (等級 − 1))`，最後夾在 50% 到 175%。

時間和空間的身分是機制，常數在 `balance.json` 的 `element_effects`：
- 時間打中疊遲滯，每層降攻速、最多三層，同時延長攻擊方自己的增益，但不超過增益原本的長度
- 空間無視目標三成防禦，命中會把目標推開，連普攻也是

玩家的攻擊屬性只從調色盤和職業固定屬性來，規則在 `docs/奪色世界規劃書.md` 第 4、5 節；防禦屬性不跟著變。

## 5. 攻速

```
每秒攻擊次數 = 武器基礎 × (1 + 攻速屬性 × 1.5 / 100)，上限 2.5
攻速屬性：近戰 AGI，遠程 AGI + DEX × 0.5
amotion 毫秒 = 500 / 每秒次數，adelay = 2 × amotion
```

每個職業每種武器的基礎值在 `data/jobs.json` 的 `aspd_base`，千分比整數。
技能的 `aspd_fixed` 一點等於加 0.02 次，`aspd_percent` 乘上去，`amotion_add_ms` 直接加毫秒，`aspd_cap` 是上限。
開局數字刻意和 RO 幾乎一樣，`docs/打擊感規格.md` 的時間軸不用重調。

## 6. 成長

- 現行資料：基本等級上限 60；職業等級上限初心者 10、一轉 50、二轉 70、三轉 70；轉職門檻初心者 10、一轉 30、二轉 40，都在 `balance.json` 的 `levels`
- 2026-09-19 使用者改成基本 99、兩輪制加轉生、職業上限 10／30／50／70、每級 1 點不再逢五加一，規格在 `docs/轉生與等級.md` 和 `docs/技能與流派.md` 第 1 節，資料和程式還沒改
- 初心者總共 10 技能點：建角 1 點加每升一職業等級 1 點，2026-09-25 使用者：「改成拿到 10 點，創角色就 1 點」
- 技能樹容量要大於點數，練滿買得起大約七成，2026-09-17 使用者定：加大技能樹，不降給點速度
- 升基本等級 HP 和 SP 照職業曲線長，不補滿：

```
最大 HP = ⌊(40 + 成長 × (Lv − 1) + 曲率 × (Lv − 1)² / 100) × (1 + VIT × 0.015)⌋
最大 SP = ⌊(15 + 成長 × (Lv − 1) + 曲率 × (Lv − 1)² / 100) × (1 + INT × 0.02)⌋
```

成長和曲率在 `jobs.json`。

經驗由「每級要打幾隻同等級怪」反推，步調是保證的：

```
升級經驗 = round(30 × Lv^1.85 + 70 × Lv)
每級隻數 = 8 + 0.17 × Lv
怪物基本經驗 = round(升級經驗 / 每級隻數)，職業經驗是它的 55%
```

表在 `data/exp_tables.json`。RO 同等級要四五十隻，我們取五分之一左右，手機十分鐘內要看得到升級。

死亡扣這一級所需經驗的 1%，扣到 0 不降級；基本等級 10 以下不扣；變成線稿時被隊友救起來退回；不掉道具。
2026-09-25 從 0.5% 改成 1%，給組隊救人一個理由。

## 7. 平衡目標

| 項目 | 目標 |
|---|---|
| 打死同等級基準怪 | 3 到 13 秒，第一段最快 |
| 基準怪打死玩家 | 至少是玩家打死牠的 2.5 倍時間，而且要挨 11 下以上 |
| 死亡率 | 專心打每 30 隻同等級怪最多死 1 次 |
| 裸角對練過 | 同等級傷害差 2 到 9 倍，其中裝備佔 1.5 到 3.5 倍 |
| 藥水 | 一瓶回當期最大 HP 的 20% 到 45% |
| 各職業線 | 同一階最快和最慢差不超過 12 倍；近戰最快、遠程次之、信徒線最慢但撐得住 |

武器規則，數字在 `data/items.json`：
- 每個職業在每個等級帶拿自己的武器要比通用匕首強
- 通用匕首不超過同等級最強專屬近戰武器的 0.76 倍，照 RO 匕首對雙手劍的最高比例
- 拿弓一定要裝箭，箭的攻擊加進武器；弓加箭是同等級雙手劍的 0.8 到 0.9 倍

怪物基準曲線在 `balance.json` 的 `monster_curve`，每隻怪再乘 `monster_profiles` 的個性倍率，最終數值寫進 `data/monsters.json`。

## 8. 王

2026-09-27 使用者：「王的最低等級也至少要30級，所以木樁王不是新手期可以打的，血也要更多，你可以參考 RO 惡魔波利、天使波利，都是低等王但是都是新手打不贏的」。

- 寫 `boss` 或 `mini_boss` 的怪等級不低於 `balance.json` 的 `boss_rules.min_level`
- 新手區可以有王，但那是放在新手區的高等怪，照 RO 天使波利、惡魔波利
- HP 約同等級曲線的 20 倍，同等級練過的玩家單人普攻 25 到 400 下
- ATK 約曲線的 1.85 倍，同等級玩家挨六七下倒
- 經驗是同等級一般怪的 10 倍；野外王重生 60 分鐘
- 狀態和擊退免疫；不追出自己的地盤，移動比人慢，新手跑得掉
- 必掉一份精煉或製作用的稀有材料
- 招式預告和判定在 `docs/世界地圖規劃.md` 第 5 節

## 9. 金幣

2026-09-18 定案：**打怪不掉金幣，錢只能賣戰利品。** 首殺獎勵只給經驗。

```
一般怪戰利品的期望賣價 = 14 + 2.0 × Lv + 0.30 × Lv²
```

常數在 `balance.json` 的 `loot_value`，是掉落表和賣價要對齊的目標，程式只擲掉落表：
- 一般怪偏離曲線不超過三成，精英和王至少值一隻同級一般怪，召喚的小怪沒有掉落
- 每隻怪一個主材料，機率四到五成；材料買價是賣價的兩倍；`no_sell` 的不算收入
- 收入守線：存到下一套裝備 8 到 110 分鐘、一瓶當期藥水最多 2.5 分鐘、當期武器推到 +7 至少 25 分鐘、硬推 +10 至少 150 分鐘

## 10. 彩度

規則在 `docs/奪色世界規劃書.md` 第 6 節，常數在 `balance.json` 的 `chroma`，由伺服器算。上限所有人一樣 100。

```
強行上色扣的 HP = 最大 HP × 技能彩度消耗 ÷ 100 × 換算倍率
換算倍率 = 1.5 + 0.5 × 最近連續強行的次數，停手一段時間回到 1.5
全彩爆發倍率 = 500% + (彩度 − 90) × 20%，彩度 90 以上才能放
怪物適應抗性 = min(⌊同屬性命中數 ÷ 20⌋ × 10%, 40%)，只有菁英和王，脫戰歸零
```

適應常數在 `adaptation`，地面彩度在 `colour`，色種特性在 `seed_traits`，色魄槽數在 `colour_soul`。
屬性效果的強度在 `data/element_effects.json`。彩度掉和回的速度、每招消耗還要照實際打起來調。
