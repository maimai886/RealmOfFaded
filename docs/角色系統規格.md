# 角色系統規格

角色的造型標準和分層，美術和程式共同的契約。比例和畫風以 `docs/美術風格指南.md` 為準，圖集格式和錨點在 `docs/精靈圖規格.md`。

## 1. 造型

- 4.07 頭身，量自使用者畫的初心者設定圖，表在 `docs/美術風格指南.md` 的比例那一節
- 頭飽滿圓潤、下巴短，眼睛大、有眼白虹膜和高光，小嘴加腮紅，鼻子不畫或一點
- 手是簡化的尖楔形不畫手指，腳是小圓靴，四肢圓潤、關節不明顯
- 武器刻意放大，剪影就看得出職業；頭盔帽子是獨立一塊，會蓋住部分頭髮
- 不畫黑色描邊，靠柔和漸層和邊緣光分開背景

## 2. 分層

- 玩家、NPC、怪物都是圖集，2026-09-24 起 3D 角色整條拿掉
- 2026-09-24 使用者定：所有職業、男女共用一份素體 `male_novice`，職業差別做成服裝圖層，髮型、頭飾、武器也是圖層
- 每一層和身體同畫格、同錨點、同動作，引擎把同一格疊起來；前後順序在 `data/paper_doll.json`
- 裝備在 `data/items.json` 用 `model_attachment` 指圖層名，先找 `<名稱>_<性別>`，沒有再找 `<名稱>`；沒有圖層的裝備只算數值不顯示
- 掛點固定 `hand_r`、`hand_l`、`head`、`back`、`body`；程式不為任何角色 id 寫特例

## 3. 表情

做在頭那一層，現在頭畫在身體裡還沒有表情。表情只是表現，伺服器不用知道。

- 必備：normal、blink、happy、angry、hurt、dead、surprised、talk
- 優先序：dead、hurt、angry、talk、normal
- 眨眼隨機，間隔 2.5 到 6 秒，持續 0.12 秒

## 4. 髮型與染色

- 髮型和眼型是頭圖集的編號，找不到退回 `h0_e0`；男女的髮型清單分開，介面從資料讀
- 髮色、膚色、服裝色用換色遮罩加色階，不另外做貼圖；色階在 `data/appearances.json`

## 5. 男女

- 男肩線較寬、髮型偏短、剪裁較直；女腰線內收、下襬較長、髮型偏長
- 同職業男女同一套配色和識別元素，一眼看得出是同一職業

## 6. 驗收

- 換髮型、頭飾、武器在遊戲裡即時生效
- 預設鏡頭距離下五官看得清楚
- 手機中等畫質同時十個角色不掉幀
- 新增髮型或裝備外觀只加資料和圖集，不改程式
