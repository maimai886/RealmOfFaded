# 角色系統規格

2026-09-16 使用者提供 SURIYUN Little Heroes 的角色總覽圖當作規格，要求：照那個風格做角色、每個職業都要有男女、之後要能換表情、換髮型、換裝備。
這份文件定義角色的造型標準和分層架構，是美術和程式共同的契約。風格的色彩與上色原則見 `docs/美術風格指南.md`。

## 1. 造型標準

**這一節的頭身比已作廢。現行是 4.07 頭身，量自使用者自己畫的初心者設定圖，
整張表和量法在 `docs/美術風格指南.md` 第 2.1 節，骨架由 `art_pipeline/characters_v3/rigspec.py` 的參數算出來。**
下面留著只為了讀得懂 2026-09-17 以前的模型。**不要照那一條做新東西。**
眼睛、嘴巴、手腳那幾條沒有作廢，作廢的只有比例那一條。

照參考圖量到的比例和特徵，所有角色都要符合：

- ~~**頭身比約 2 頭**，頭佔全高的 45 到 50 個百分比。比之前的 3.2 頭更 Q~~ **已作廢，見上面**
- 頭是飽滿的圓形，下巴短而圓，沒有脖子線條，頭直接接在肩上
- **眼睛很大**，單眼寬度約臉寬的四分之一，有眼白、彩色虹膜、深色上眼線、一到兩點白色高光
- 小嘴，兩頰有淡粉色腮紅，鼻子不畫或只有一點
- **手是簡化的尖楔形**，不做手指；腳是小圓靴，腳踝不分段
- 身體短小，四肢圓潤粗短，關節不明顯
- **武器刻意放大**，長劍約與角色同高，法杖和弓同理，剪影才看得出職業
- 頭盔、帽子是獨立的一塊，戴上去會蓋住部分頭髮
- 不畫黑色描邊，靠柔和漸層和邊緣光和背景分開

## 2. 分層架構

參考圖裡頭盔和武器是分開擺的，代表整套就是組合出來的。我們照同樣的分層，每一層是一份和身體同畫格、同錨點、同動作的圖集，
引擎把同一格疊起來，格式在 `docs/精靈圖規格.md`：

| 層 | 內容 | 在哪裡 | 換的時機 |
|---|---|---|---|
| 身體 | 軀幹、四肢、基礎服裝 | `characters/body/<性別>_novice`，現在男女共用 `male_novice` | 換職業、換防具外觀 |
| 頭 | 頭、臉、頭髮 | `characters/head/<性別>_h<髮型>_e<眼型>`；現在的底板 meta 寫 `head_layer: false`，頭畫在身體那層 | 創角、理髮 |
| 裝備 | 武器、頭飾、披風、防具外觀，每一件一層 | `characters/layers/<名稱>`，名稱是道具的 `model_attachment` | 換裝備 |

每一層都有自己的資料定義，程式不做任何依角色 id 的特例。
掛點名稱固定為 `hand_r`、`hand_l`、`head`、`back`、`body`，產圖層時照紙偶骨架的掛點對位。

## 3. 表情系統

表情做在頭那一層，一格一個表情。現在頭畫在身體那層，還沒有表情，閒置時的眨眼也要等頭拆出來才有。

必備表情：

| 表情 | 用在哪 |
|---|---|
| normal | 平常 |
| blink | 眨眼，閒置時隨機插入 |
| happy | 升級、完成任務、交易成功 |
| angry | 攻擊、施法 |
| hurt | 受擊 |
| dead | 死亡 |
| surprised | 被打斷、被暴擊 |
| talk | 對話中 |

規則：

- 表情由表現層決定，不影響任何遊戲數值，伺服器不需要知道
- 眨眼是隨機的，間隔 2.5 到 6 秒，持續 0.12 秒，`sprite_actor.gd` 的 `BLINK_INTERVAL` 和 `BLINK_SECONDS`
- 戰鬥中的表情優先序：dead 大於 hurt 大於 angry 大於 talk 大於 normal

## 4. 髮型與染色

- 髮型和眼型是頭圖集的資料夾編號，找不到那一組時退回 `h0_e0`
- 染色靠換色遮罩加色階，不另外做貼圖；髮色、膚色、服裝色的色階定義在 `data/appearances.json`，
  著色器是 `src/world/actors/shaders/sprite_recolor.gdshader`
- 男女的髮型清單分開，數量可以不同，介面從資料讀不寫死

## 5. 裝備外觀

- `data/items.json` 的裝備項目用 `model_attachment` 指定圖層名稱，引擎先找 `<名稱>_<性別>`，沒有再找 `<名稱>`
- 沒有圖層的裝備不顯示外觀，只算數值，這樣資料不齊也能玩
- 圖層每一格記著在身體前面還是後面，換方向、換動作時前後順序跟著變

## 6. 每個職業的男女

二十一個職業各要男女兩套，共四十二套身體層，職業表在 `docs/職業路線圖.md`。造型差異照參考圖的做法：

2026-09-24 起所有職業、男女都用同一份素體底板 `male_novice`，職業之間的差別之後做成服裝圖層，下面這幾條是畫服裝時的方向。
程式現在不看職業，一律找 `<性別>_novice`，女生沒有自己的就用 `male_novice`，見 `SpriteSheet.character_body_dir`。

- 男：肩線較寬、髮型偏短、服裝剪裁較直
- 女：腰線內收、裙擺或下襬較長、髮型偏長
- 同職業的男女用同一套配色和同樣的識別元素，一眼看得出是同一個職業

## 7. 技術選擇

2026-09-18 定案：玩家角色走圖集，格式在 `docs/精靈圖規格.md`「像素角色圖集」。
代價是表情、髮型、裝備要像 RO 一樣做成分層的圖，所以骨架先統一成一副，讓一件裝備的圖層只出一份。
2026-09-24 NPC 也改成圖集，3D 角色整條拿掉，玩家、NPC、怪物全部是 `sprite_actor.gd`。
整體畫面仍然是 3D 場景加固定鏡頭的 2.5D，角色是面向鏡頭的紙片。

## 8. 資料檔

- `data/appearances.json`：每個職業的站立、攻擊、施法動作名稱和命中比例，捏臉選項和髮色、膚色、服裝色的色階
- `data/items.json`：裝備的 `model_attachment`
- `data/jobs.json`：職業的 `art_id`，美術檔名用的那個字

## 9. 驗收標準

1. 二十一個職業男女共四十二套都做出來，同職業男女一眼認得出是同一個職業
2. 換髮型、換頭飾、換武器在遊戲裡即時生效，不用重開
3. 表情會隨戰鬥狀態變化，眨眼自然
4. 在鏡頭預設距離下，臉部五官清楚可辨
5. 手機中等畫質下，畫面上同時十個角色不掉幀
6. 新增一個髮型或一件裝備外觀只需要加資料和圖集，不用改程式
