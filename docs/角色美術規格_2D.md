# 角色 2D 貼圖美術規格

用 create-game-assets 的流程鎖定的規格。**先照這份驗收，通過才用付費 API 量產，不再沒確認就花錢。**

## 一、技術框架

| 項目 | 值 | 來源 |
|---|---|---|
| 引擎 | Godot 4.7，2D | |
| 視角 | 俯角約 38 度 | 照 RO |
| 像素密度 | 96 px/m | 不動 |
| 世界身高 | 1.875 m | = 180 ÷ 96 |

## 二、分層規格（2D 換裝／換髮的基礎）

RO 的做法：身體、頭（髮型）、眼睛、頭飾、背飾分層，各層有錨點，疊起來成一個角色。2D 版照做：

| 層 | 內容 | 錨點 |
|---|---|---|
| 身體 | 職業×性別×動作×方向，**光頭無臉** | 兩腳底中點 (88,208) |
| 頭部錨點 | 身體每一格記錄「頭部中心座標」 | 每格一個 (hx, hy) |
| 眼睛 | 疊在光頭臉上，只有正面/斜前/側看得到 | 對齊頭部錨點 |
| 頭髮 | 疊在光頭上，蓋住頭頂 | 對齊頭部錨點 |
| 頭飾／背飾 | 之後加 | 對齊頭部／身體錨點 |

## 三、換髮的硬性前提（這次的關鍵教訓）

**要用同一套髮型疊到所有角色身上，所有身體的「頭部」必須規格統一：**

1. **頭部大小一致**：同性別所有職業的光頭,頭寬必須相同（誤差 < 3 px）。
2. **頸部接點一致**：頭接到身體的位置（頸部 y、中心 x）必須固定。
3. **頭部錨點記錄**：每個身體每一格都要存頭部錨點座標，髮型才對得準。

**目前素材不合格**：`art_source/characters_8dir` 的來源 `all_b.png`／`all_g.png` 是不同次生成拼的九宮格，
頭寬男 59~90 px（差 31）、女 59~83 px（差 24），頭/身比 0.21~0.30。
→ 這樣同一套髮型套上去會忽大忽小，**換髮型不能用**。這是量產前沒鎖規格、沒驗收就花代幣造成的。

## 四、頭部統一的方案（待使用者選）

| 方案 | 做法 | 代價 |
|---|---|---|
| A 標準頭重置 | 定義一個標準光頭頭部（固定大小/頸接點），把每個角色的頭 inpaint／替換成標準頭 | 每角色一次頭部處理，畫風要接得順 |
| B 源頭重生 | 用固定頭部的統一底模重新生成 9 職業，頭天生一致 | 重畫全部角色 |
| C 縮放對齊 | 後處理把每個角色整體縮放，讓頭對齊標準框 | 身體會跟著變大小，不一定準 |

## 五、產線流程（照 create-game-assets）

1. 鎖規格（本文件）
2. **本機驗證換髮機制**（不花錢）：拿一個光頭身體 + 一個髮型，用固定頭部錨點疊合，確認對得準、蓋得住
3. 批准一個 hero（初心者）完整達標：光頭身體 + 頭部錨點 + 眼睛 + 一款髮型，在遊戲規格下驗收
4. hero 通過才量產其他職業（此時才用付費 API）
5. 每次付費前：先把要送的輸入圖排出來，確認每個完整、頭部達標，使用者點頭才送

## 六、代幣紀律

- 付費 API（AetherAI Pulsar 等）只在規格與 hero 驗證通過後用。
- 每次送出前先本機檢查：裁切完整（不缺頭腳）、頭部達標、比例正常。
- 一次一個確認無誤再批量；不再沒檢查就整批送。
