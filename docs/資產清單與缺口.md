## 2. 佔位圖同時「在執行路徑上」和「不會出貨」

這是最嚴重的一條，因為它在開發機上完全看不出來。

`src/world/sprite_sheet.gd` 的 `search_roots` 是 `[正式, 佔位]`，
`find_dir()` 是唯一的解析入口，**沒有任何 dev 旗標、debug 判斷或編輯器判斷擋著它**。

`export_presets.cfg` 三個平台的排除清單都有 `assets/generated/sprites/placeholder/*`，
`.gitignore` 也忽略它，`git ls-files` 在那個資料夾回傳零筆。

2026-09-24 起玩家角色一律用 `male_novice`，不再經過佔位圖；怪物一隻都沒有中招。
`placeholder/` 還在搜尋路徑上，之後任何一種新怪或新職業忘了給圖，開發機上會靜靜地用佔位圖、出貨包裡是空的。

這不是優雅降級，是編輯器能跑、輸出不能跑的落差。要嘛把它們做成正式資產，
要嘛讓 `search_roots` 在輸出版本裡不要包含佔位路徑，兩件事都不做就是把問題留到出貨當天。

## 7. 角色美術：自己做、買、還是找人畫

**這是使用者還沒做的決定**，這一節的用途是把三條路的代價攤開，不是替使用者挑一條。
價錢是 `docs/調查/素材採購選項.md` 2026-09-16 查到的，有幾項標著特價，過幾天要重查。

### 現在的位置

- 決策狀態寫在 `docs/調查/素材採購選項.md` 開頭：**2026-09-16 定案不買，自己做到同等級**
- 2026-09-18 使用者自己畫了初心者的設定圖和二十一個職業圖標，比例和畫風的代表作就是那張設定圖
- 2026-09-23 晚上起角色是 2D 紙偶，八個方向和動作由使用者畫的視圖切零件照骨架動，這一塊解掉了
- 2026-09-24 定案所有職業、男女共用一份素體，現在缺的是：服裝圖層、髮型圖層、每個方位各一張的武器圖

### 三條路

| | 自己做 | 買現成 | 找人畫 |
|---|---|---|---|
| **現金** | 0 | 角色相關約 52.5 到 87.5 美元；完整七包組合 272.43 美元 | 沒有報價。調查中找到的一個時薪參考是 15 美元 |
| **時間** | 已經投入不知道多少輪，還差 1.36 倍的比例和整套髮型 | 買完仍然要跑一次我們的管線、對骨架、調比例 | 要先能給出合格的概念圖，見下面 |
| **風格吻合** | 完全可控，但六次都沒過 | 最接近的是 Astarish 的 3D Chibi Fantasy Character Pack 1，3 到 3.5 頭身、賽璐璐上色，30 美元。其餘的頭身比都不對 | 完全可控 |
| **授權** | 乾淨 | Unity Single Entity 不涵蓋外包；GameDev Market 的衍生作品智財歸賣方；所有平台都禁止讓玩家把素材挖出來 | 要寫清楚著作權歸屬 |
| **可維護性** | 改一個數字重跑腳本 | 改比例要動買來的網格，沒有腳本 | 要再付錢 |

### 買的話，實測過的兩件事

`docs/美術風格指南.md` 附錄 A.8 記著一次實測，結論是**先看概念圖，不是先看買哪一家**：

| 概念圖 | 回來的角色 | 關節對不對得上 |
|---|---|---|
| 真正的插畫 | 有頭髮的頭型、有腰身的長衫、皮帶、分開的腿、靴子 | **不對**，手臂高度差 0.045 公尺，動起來小臂扇成薄板 |
| 我們自己算的素模圖 | 一團粉紅色的塊體，沒有腰身沒有下襬沒有腿 | **對**，手臂縮放 1.025、高度差 0.011 |

正確的路線是在我們自己的素模圖上面畫插畫：素模圖決定姿勢和關節位置，插畫決定衣服頭髮鞋子和明暗。
**在拿得到這種概念圖之前不要再買，這件事實測過了。**

### 另一件實測過的事：多方向 2D 精靈圖買不到

`docs/調查/素材採購選項.md` 第 2 節查得很徹底：符合我們規格的成品，
也就是五個手繪方向、每格 192 像素、待機走路攻擊施法受擊死亡全套動作的 2D 精靈圖包，
**市面上沒有這個商品類別**。所以這一段只有兩條路：
自己做，現在走的是 2D 紙偶，或者找人畫。

## 2026-09-26 技能特效包

使用者提供一批免費特效包，要求直接套進遊戲，放在 `assets/vendor/` 底下，怎麼用寫在 `data/vfx.json`，放的程式是 `src/world/vfx_library.gd`。

| 資料夾 | 作者 | 授權 | 風險 |
|---|---|---|---|
| `binbun_vfx_vol2/` | Binbun3D | CC0，包裡附授權檔 | 低 |
| `binbun_vfx/` | Binbun3D | 包裡沒附授權檔，使用者確認下載頁寫免費、可商用、不用標示作者 | 低 |
| `magic_cast_vfx_lite/`、`elemental_impacts_lite/`、`buff_pickup_vfx_lite/` | Sean Elovirta | MIT，要保留授權文字 | 低 |
| `free_hit_vfx/` | 未寫 | README 寫可商用、不用標示作者 | 低 |

| `shield_vfx/`、`tornado_vfx/` | 未寫 | 使用者確認下載頁寫免費、可商用、不用標示作者 | 低 |
