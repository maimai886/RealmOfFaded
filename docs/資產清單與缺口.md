# 資產清單與缺口

每個資產家族的來源、工具、授權、有沒有出貨，記在機器讀的 `docs/資產清單.json`，那份是授權紀錄。這份只講清單上的洞。

## 1. 缺的

| 缺什麼 | 現在會怎樣 |
|---|---|
| 職業外觀的服裝 | 所有職業、男女都是 `male_novice` 素體，轉職不換外觀 |
| 髮型圖層 | 全部光頭；`data/appearances.json` 還在給玩家選髮型眼型，選了不會變，要嘛做圖層要嘛先收起選項 |
| 每個方位各一張的武器圖 | 只有小刀，而且是道具圖示壓窄的暫用品 |
| 29 個道具圖示 | 退回程式畫的方塊 |
| 低語森林、碎石谷、灰蝕地窟 B1、B2 的音樂 | 四張地圖全程沒有背景音樂 |
| `bolt_fire`、`bolt_ice`、`bolt_lightning`、`meteor` 特效圖集 | 在磁碟上但舊專案從沒載入，`meteor_fall` 畫的是程式產的佔位圖 |

地圖擺設模型、南門四隻怪的圖集、九張立繪、介面皮膚、游標、地形材質都在。

佔位圖 `assets/generated/sprites/placeholder/` 在找圖的路徑上卻不出貨，也不進版本庫。任何新怪或新職業忘了給正式圖，
開發機上會安靜地用佔位圖、出貨包裡是空的。要嘛出貨版本不搜佔位路徑，要嘛出貨前檢查。

## 2. 來源或授權不明

| 資產 | 風險 | 問題 |
|---|---|---|
| `art_source/textures/raw/` 30 張，下游 `assets/generated/textures/` | 高 | AI 產的，工具和提示詞沒記 |
| `assets/ui/portraits/` 9 張 | 高 | AI 產的，工具沒記；最初那組的提示詞在 `docs/美術替換指南.md` 4.5 |
| `art_source/ui/` 18 張，下游 skin、icons、worldmap | 中 | AI 產的，工具沒記；`skin.py` 只取裝飾零件的透明度重新上色 |
| `assets/ui/icons/` 100 個 | 中 | 兩條管線寫同一個資料夾，一條程式畫、一條切 AI 大圖，哪個走哪條沒記 |
| 四個字型家族 | 低 | OFL 授權文字都在，只有 jf-openhuninn 記了來源和版本 |
| 四首音樂 | 低 | 使用者確認是 Suno 付費方案產的，可商用，證據記在 `docs/資產清單.json`；沒有發票或截圖 |

從現在起 AI 產圖要記工具和提示詞。沒有 CREDITS 檔也沒有致謝畫面，CC0 不強制，但之後買任何要標示的素材就沒地方放。

## 3. 在磁碟上但沒人用

| 資產 | 檔數 |
|---|---|
| `assets/vendor/kenney_ui_rpg/` | 90 |
| `assets/generated/models/town/` | 40 |
| `assets/ui/icons/` 根目錄 | 12 |
| 沒接上的 Kenney 音效 | 88 |

這不是刪除清單。看起來像死的但要留的：`assets/generated/models/characters/` 的 18 件裝備網格，`cbuild.py --layer` 從這裡拿；
`assets/vendor/kaykit/characters/Knight.glb` 和貼圖，骨架和動作的來源。

## 4. 角色美術自己做還是買

2026-09-16 定案不買，自己做。2026-09-16 查過，多方向手繪 2D 精靈圖包市面上沒有這個商品類別；買 3D 角色包最接近的是 Astarish 的 3D Chibi Fantasy Character Pack 1，30 美元。
現在的角色狀況看 `docs/美術產線接手紀錄.md`。

## 5. 2026-09-26 技能特效包

使用者提供的免費特效包，放在 `assets/vendor/`，用法寫在 `data/vfx.json`。

| 資料夾 | 作者 | 授權 |
|---|---|---|
| `binbun_vfx_vol2/` | Binbun3D | CC0，包裡附授權檔 |
| `binbun_vfx/` | Binbun3D | 包裡沒附授權檔，使用者確認下載頁寫免費、可商用、不用標示 |
| `magic_cast_vfx_lite/`、`elemental_impacts_lite/`、`buff_pickup_vfx_lite/` | Sean Elovirta | MIT，要保留授權文字 |
| `free_hit_vfx/` | 未寫 | README 寫可商用、不用標示 |
| `shield_vfx/`、`tornado_vfx/` | 未寫 | 使用者確認下載頁寫免費、可商用、不用標示 |

同一批的 MusicAOE 是 Godot 3 格式載不起來、hologram 是科幻全像投影不搭畫風，都沒放進來。

## 6. 建議順序

1. 佔位圖那條路修掉
2. AI 產圖開始記工具和提示詞
3. 補道具圖示、服裝和髮型圖層、四張地圖的音樂
4. 建 CREDITS 檔
