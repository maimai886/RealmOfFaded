# 轉職與城市

2026-09-18 規劃，還沒開發。一轉四職各一座專屬城市，導師之後搬過去，二轉三轉也在那裡轉。
一轉的考試內容以 `docs/轉職考試.md` 為準，這份只管城市、考試共用的骨架和二轉三轉的原則。

## 1. 原則

使用者要原版 RO 的自由感：

- 不教學：沒有引導箭頭、沒有「接下來去哪」的彈窗，規則只在玩家問導師時講一次。
- 不設等級門檻：城市和考試地圖 1 級也走得進去，路上的怪就是門檻。
- NPC 不推任務：導師只回應玩家自己開口的「我想成為某某」；鎮民被問到才說「劍侍在礪岩堡學」。
- 失敗沒有懲罰，只有重來：找導師再開一次，用掉的道具不退。
- 考試是一個人的事：考試裡的敵人和目標只認開考的那個角色。
- 同一個玩家轉四個職業，四次的感覺要完全不一樣；手機用搖桿加閃避鈕也要做得完。
- 導師搬走後，晨曦鎮只留艾拉、商人、倉庫、傳送員。

## 2. 城市

世界是一條南北脊椎：草原、晨曦鎮、森林、谷地、地窟。四座一轉城市接在脊椎兩側，彼此不相鄰。
地名照 `docs/世界觀.md` 第 6 節，每個地方有官方名和當地人叫的老名字；代號照 `data/maps/` 小寫加底線。

在懸梢寨北邊霧嶺深處的山坳，石階和鳥居一路上山；上層是朱柱白牆的陰陽寮，下層是町屋、旅館、道場、刀鍛冶，另有五重塔、神社、山伏堂，建築走 `docs/城鎮建築產線.md`。
人講話客氣、拐彎抹角。霧嶺那一支的二轉三轉都在這裡轉：劍客、劍豪、方術士、陰陽師、刺客、忍者、行者、鬥聖；一轉還是在四座城。

## 3. 考試共用的骨架

- **私有實體**：考試裡的敵人、護送對象、標記只屬於一個角色，欄位 `owner`。只有 owner 打得到它，它只打 owner，別人看得到但點不到；owner 離圖、死亡、考試結束它就消失。快照帶 `owner`，客戶端拿它決定能不能點。
- 不做一人一份的地圖副本，私有實體就夠用。
- 失敗時伺服器發 `trial.failed`，客戶端只顯示一行系統訊息，進度清掉、私有實體消失。
- 考試資料只記 NPC 代號，不記地圖和座標，規則同 `docs/轉職考試.md` 第 4 節。

## 4. 二轉三轉的原則

- 二轉在一轉的城轉，導師同一位，考題由城裡另一個 NPC 出。
- 同一個一轉分岔的兩職要考兩種完全不同的題目，例如一邊考守、一邊考快。
- 方術士、行者、刺客的傳統在霧嶺，二轉考試離開晨曦諸邦，到懸梢寨以北的山裡和雲居京。
- 三轉的考試在各城地城的最底層，地城是三轉的前置。
- 門檻只有職業等級和考試，沒有前置任務鏈、沒有聲望。
