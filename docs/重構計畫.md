# 重構計畫

> 2026-09-27 起這份寫的是舊專案 `../Sproutia` 的程式。新專案照 `Rust重構規劃.md` 重寫，寫到哪一塊就把那一段改成新的。

2026-09-18 依 `docs/程式規範.md` 的稽核結果排的。風險由低到高，每一項寫改什麼、為什麼、動哪些檔、怎麼驗證。
低風險的機械式整理當天就做，做完在這裡標「已做」加 commit；中高風險的只規劃，等使用者點頭再動。

硬規則：每一批改完跑 `tests/run_tests.gd` 維持 1299 個，只有 `test_full_flow_over_websocket` 可以因為本機 ping 延遲紅、`art_pipeline/tests/run.py` 維持 61 個 0 失敗；不改遊戲行為、數值、資料檔內容；不動 `art_source/`、`assets/`。
