# 開發指令

Rust 新專案現在用得到的指令。舊專案的截圖旗標、開發後台、遊戲內 `/` 指令都還沒重做，要對照去 `../Sproutia/docs/開發指令.md`。

## 開遊戲

使用者自己雙擊 `manager.bat` 或 `manager.command` 開：編好伺服器和擴充，開一個 7780 伺服器視窗和一個遊戲視窗，關掉伺服器視窗就停。AI 不替使用者開遊戲，也不關使用者正在跑的遊戲。

Windows 這台的 Godot 在 `D:\Godot_v4.7.2-stable_win64.exe\`，外層那個 `.exe` 是資料夾名；指令列用裡面的 `Godot_v4.7.2-stable_win64_console.exe`。管理器的位置可以用環境變數 `GODOT` 蓋掉。

## Rust

都在 `rust/` 底下跑：

| 用途 | 指令 |
|---|---|
| 全部測試 | `cargo test --workspace` |
| 編擴充，Godot 開著時 Windows 會鎖 DLL | `cargo build -p rof-gdext` |
| 開伺服器，Ctrl+C 關 | `cargo run -p rof-server -- --port=7780` |

伺服器另外收 `--game-data=資料夾`，不給就從目前位置往上找 `data/`；`--config=檔案` 換伺服器列表，預設 `rust/crates/server/config/servers.json`。舊專案佔了 7777 到 7779，不要碰。

## 客戶端參數

冒煙測試在根目錄跑 `godot --headless --path . --script res://tests/smoke.gd`。

| 參數 | 做什麼 |
|---|---|
| `--server=主機:埠` | 連哪台伺服器，預設 `127.0.0.1:7780` |
| `--dev-login=帳號:密碼` | 只有 debug 版有：自動登入，沒有角色就建，接著進地圖；`--dev-character=名字` 指定角色 |
| `--dev-walk=x,z` | 只有 debug 版有：進地圖後自己點地走到那裡 |
| `--shot=路徑` | 畫面穩定後截圖存 PNG 並結束；`--shot-wait=秒` 多等一段，驗色調用 6 秒 |

預覽場景在 `scenes/dev/`，都能配 `--shot`：

- `actor_preview.tscn`：`--body=圖集資料夾` 放一個站著、一個走路的角色，`--at=x,z` 挪位置，`--cam=` 鏡頭距離，預設 52
- `camera_preview.tscn`：鏡頭和點地游標，`--cursor=x,z` 把游標那格擺在畫面正中，加 `--blocked` 畫成不可走
- `map_preview.tscn`：地圖

## 美術產線

美術產線是 Python 和 Blender，照舊。現況和續跑方法在 `docs/美術產線接手紀錄.md`。

- Blender 一定要加 `--python-exit-code 1`，不然腳本出錯結束碼還是 0；Windows 上在 `D:\Program Files\Blender Foundation\Blender 5.2\blender.exe`
- 美術管線測試：`blender -b --factory-startup --python-exit-code 1 -P art_pipeline/tests/run.py`
- 產完素材要跑 `godot --headless --path . --import`
- 新的音樂檔進來先跑 `python art_pipeline/audio/strip_tags.py` 拿掉標籤，再匯入
