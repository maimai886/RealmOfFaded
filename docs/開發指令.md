# 開發指令

> 2026-09-27 起這份寫的是舊專案 `../Sproutia` 的程式。新專案照 `Rust重構規劃.md` 重寫，寫到哪一塊就把那一段改成新的。

以下指令都在專案根目錄 `~/Desktop/project/RealmOfFaded` 執行。

```bash
alias godot=/Applications/Godot.app/Contents/MacOS/Godot
alias blender=/Applications/Blender.app/Contents/MacOS/Blender
```

Windows 上這台機器的 Godot 在 `D:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe`。
**外層那個 `.exe` 是資料夾名，不是執行檔**，少一層會得到「不是可執行的程式」或 `Is a directory`。

## 後台管理器

Windows 雙擊 `manager.bat`，macOS 雙擊 `manager.command`，瀏覽器會開 `http://127.0.0.1:7800/`。
程式在 `tools/manager/`，只用 Python 內建函式庫，三個平台同一份。關掉面板不會關遊戲和伺服器。

| 分頁 | 做什麼 |
|---|---|
| 開關 | 啟動和存檔關閉兩個版本的伺服器、開遊戲、單機、同步到穩定版 |
| 紀錄與測試 | 跑單元測試、重新匯入素材、即時看 `server.log` 和 `client.log` |
| 角色與資料 | 下面那個開發後台直接嵌在這一頁，不用另外開 7790；帳號和角色清單伺服器沒開也看得到，只讀 |
| 存檔備份 | 把整個 `server_data` 打包到 `server_backups/`，可以下載、上傳、還原；換電腦搬存檔用這個 |
| 設定 | Godot 位置、兩個版本的 port，只記在這台電腦的 `tools/manager/local.json` |

- 關伺服器一律走停止檔，伺服器存完檔才退出；還原之前會自動先備份現在的存檔，伺服器開著不給還原
- 備份檔裡有帳號資料和 `server_secret.key`，`server_backups/` 不進版本庫也不進客戶端輸出
- 預設 port 被別的程式佔用時面板會講是哪個程式，到設定換 port。
  2026-09-19 在一台華碩筆電上 7778 被 Armoury Crate 佔走，就是這樣發現的；
  那台電腦的開發版改用 7779，下面指令表裡的 7778 在那台要自己換掉
- 面板不是第二個權威：改角色和遊戲資料一律交給伺服器自己的開發後台，存檔有簽章，面板只讀不改
- 2026-09-19 使用者說兩個後台頁面「整合成一個就好 跑來跑去煩死了」。面板把 `/admin/<版本>/` 代理到那個版本的開發後台，
  嵌在「角色與資料」分頁。開發後台只綁本機又拒絕帶 Origin 的請求，代理固定連 `127.0.0.1` 的那個 port、不帶 Origin；
  放到雲端主機時外面連不到開發後台，只能經過面板，也就一定先過面板的登入。
  為了能被代理，`server/dev/web/app.js` 的請求改成相對路徑，直接開 `http://127.0.0.1:7790/` 照樣能用
- 面板同一時間只會有一個：已經在跑的時候再開一次，只會幫你打開瀏覽器。
  Windows 上不擋的話第二個行程綁同一個 port 也不報錯，請求卻全部跑到舊的那一個
- 放到雲端主機：`ROF_MANAGER_TOKEN=<至少 16 個字> python3 tools/manager/manager.py --host=0.0.0.0 --remote`，
  沒設權杖就拒絕綁本機以外的位址；`--remote` 會拿掉開遊戲視窗的按鈕；對外一定要經過 HTTPS 反向代理

原本的啟動腳本 `play.sh` 和它的 Windows 版 `play.ps1` 在 2026-09-19 刪掉了，功能全部在面板裡。
`server/run_server.sh` 留著：它把作業系統送來的 SIGTERM 轉成停止檔，雲端主機用 systemd 管伺服器時要靠它才能存完檔再退出。

## 遊戲內開發指令與開發後台

指令由**伺服器**執行。沒有 `--dev-commands` 的伺服器連 `dev.command` 這個訊息類型都不認得，
硬送過去記一次違規；後台網頁也完全不存在。防串改測試一條都沒放寬，見 `docs/伺服器架構.md` 第 3.2 節。

### 啟動

```bash
server/run_server.sh --port=7778 --data=server_data --dev-commands
```

啟動訊息會印後台網址 `http://127.0.0.1:7790/`，只綁本機。
換 port 用 `--admin-port=8080`，不要後台用 `--admin-port=off`。

### 聊天框

進遊戲後直接打，例如 `/help`、`/give 紅色藥水 50`、`/tp 灰蝕地窟 B1`，結果印在聊天記錄。
`/p` 隊伍、`/w` 密語照舊，其他斜線開頭都是開發指令。
要 id 的地方都可以打名字：只對到一個就當 id，對到多個會列候選。

### 後台網頁

`http://127.0.0.1:7790/`，兩個分頁。

**角色**：左邊所有帳號和角色，綠點是線上。選一個之後可以給道具、給裝備、給金幣、設等級和點數、
轉職、學技能、傳送、補血復活、無敵、加速、生怪、清怪，也可以直接打一行指令。
送出的就是上表那一條指令，效果立刻推到遊戲畫面，回報同時進遊戲的聊天記錄。**只能改線上角色**。

**遊戲資料**：編輯 `data/*.json`，那些檔案是唯一的真相，頁面只是編輯器。

- 選檔案、選項目，欄位攤開改，按「存這一項的改動」
- 只換改到的那幾個位元組，鍵序和排版不動，diff 就是那幾行
- 新增或刪除整筆用「切換原始文字」
- 存檔前用遊戲自己的載入程式驗一次，驗不過整筆拒絕，檔案不動
- 舊檔備份到 `server_data/data_backups/`，每檔最多 30 份
- 存完立刻重新載入。地圖上的怪要重生才換數值；地圖檔、出生點、新地圖要重開伺服器
- 標「平衡測試會檢查」的檔案改了 `tests/test_balance.gd` 可能會紅，要更新測試的預期值，不要放寬

可編輯：怪物、技能、道具與裝備、精煉曲線、詞綴、配方、商店、職業、經驗表、`balance.json`、屬性相剋、任務。
**規則留在程式裡，這裡只調數值。**

### 稽核

指令寫 `dev.command`，帶帳號、角色 id、指令和參數；資料編輯寫 `dev.data_edit`，帶檔名、欄位、備份檔名。
金幣、轉職、換地圖照舊走 `gold.change`、`job.change`、`map.transfer`。

## 美術素材

要整批換掉角色或怪物的圖，照 `docs/美術替換指南.md` 做，那份寫了資料夾、meta 欄位、

Blender 一定要加 `--python-exit-code 1`，不然腳本出錯時結束碼還是 0。

`tileable.py` 會做無縫、統一色階、縮尺寸，並一併寫好 `.import`（3D 用的貼圖要有 mipmap）。
`art_source/` 有 `.gdignore`，裡面的 `.blend` 和原圖 Godot 不會掃，沒有這個檔的話 headless 匯入會因為 Blender 匯入器沒設定而整批不匯入。

## 畫面選項與快捷列

`--dev-set=section.key=value` 只改這次執行的一項設定，不寫進設定檔，可以重複給，量單項差多少用。
名字就是 `src/game_state.gd` 的 SCHEMA，例如 `--dev-set=graphics.scene_detail=low`、`--dev-set=interface.hotbar_rows=4`。
`--dev-quality=low` 是一次換一整組，兩個可以一起用，`--dev-set` 後套。

| 用途 | 指令 |

| 走設定視窗真正的選擇路徑選一項，驗撞鍵的提示 | 上一行再加 `--dev-settings-pick=controls.hotbar_row2_keys=function` |

## 手機操作與版面

閃避翻滾：電腦空白鍵，手機是攻擊鈕正上方那一顆；規格在 `docs/打擊感規格.md` 第 7 節。

電腦上加 `--dev-touch` 就會打開觸控介面，滑鼠當成一根手指，不用實機也能檢查搖桿、攻擊鈕、點擊鎖定。
視窗寬度不到 900 或比例比 16:9 寬時自動切成手機版面：視窗變成全螢幕分頁、HUD 重排、介面縮放讓邏輯高度固定 400。

截圖和結束的共用參數：`--dev-shot=路徑` 幾秒後把視窗存成 PNG 並結束，`--dev-shot-ms=N` 改等待毫秒，`--dev-shot-keep` 存完不結束，`--dev-quit-ms=N` 只計時結束不截圖。
存的是真正的視窗大小，Movie Maker 一律輸出專案設定的 1280×720，手機尺寸要看真實比例就用 `--dev-shot`。

| 用途 | 指令 |
|---|---|
| 手機尺寸看遊戲畫面 | `godot --path . --resolution 844x390 res://scenes/dev/playground.tscn -- --offline --map=town --dev-touch --dev-shot=/tmp/shots/game.png` |
| 手機尺寸看全螢幕分頁，名稱同 `--dev-open` | `godot --path . --resolution 844x390 res://scenes/dev/playground.tscn -- --offline --map=town --dev-touch --dev-open=inventory --dev-shot=/tmp/shots/inventory.png` |
| 連線版的手機畫面，從登入一路到進地圖 | `godot --path . --resolution 932x430 -- --dev-page=game --dev-touch --dev-shot=/tmp/shots/game.png --dev-shot-ms=9000` |
| 模擬瀏海和圓角，四個數字是左上右下的實際像素 | `godot --path . --resolution 844x390 res://scenes/dev/playground.tscn -- --offline --map=town --dev-touch --dev-safe-area=47,0,47,21 --dev-shot=/tmp/shots/safe.png` |
| 強制版面，檢查切換：電腦尺寸跑手機版面用 `phone`，手機尺寸跑桌機版面用 `desktop` | `godot --path . --resolution 1280x720 res://scenes/dev/playground.tscn -- --offline --dev-layout=phone --dev-touch` |
| 三個畫質等級的效能比較，每三秒印一次 `[perf]`；`--dev-quality` 只影響這次執行，不寫進設定檔。超出手機預算時會在後面多印 `[perf][超出預算]` | `for q in low medium high; do godot --path . --resolution 844x390 res://scenes/dev/playground.tscn -- --offline --map=town --dev-perf --dev-quality=$q --dev-quit-after-ms=13000; done` |
| 顯示記憶體細分：場景載完六秒後印一次完整明細，最貴的貼圖和網格、算圖目標估算、還有配置器為最大那一份圖集保留了多少。要配 `--dev-perf` 一起用，怎麼讀見 `docs/效能與記憶體.md` | `godot --path . --resolution 1280x720 res://scenes/dev/playground.tscn -- --offline --map=meadow --dev-perf --dev-vram --dev-quality=high --dev-quit-after-ms=15000` |

## 寫測試

- Godot 測試檔放在 `tests/test_*.gd`，寫成 `extends "res://tests/test_case.gd"`，方法名稱用 `test_` 開頭
- 斷言：`assert_eq`、`assert_true`、`assert_near`
- 測試檔載入失敗，或測試中出現引擎錯誤，都會算成失敗
- 美術管線測試放在 `art_pipeline/tests/test_*.py`，函式名稱用 `test_` 開頭，用 assert 判斷
