# 音效對照

遊戲事件對應到哪一個音檔、放多大聲、怎麼變化，程式碼在 `src/audio/sound_map.gd`，這份是它的說明和檢查紀錄。
換素材只要改 `sound_map.gd` 的 `files`，程式不用動；改完跑 `tests/test_audio.gd` 會檢查檔案在不在、音量音高有沒有超出範圍。

## 1. 原則：一個音效要自己賺到位子

一開始做完是 73 個事件，開視窗有聲音、換分頁有聲音、走路一直有聲音。
2026-09-16 使用者的回饋是「有些音效也太鳥　連開介面都要音效是怎樣？　走路也要？」，這個回饋是對的。

每個動作都配一個聲音，遊戲就會廉價。標竿的仙境傳說本來就**沒有腳步聲，也沒有開關視窗的聲音**。
所以規則定成一句話：

> **一個音效要能說出玩家不看畫面就不知道的事。說不出來就不要有。**

依這條規則砍過一輪之後：

| | 數量 |
|---|---|
| 一開始做完 | 73 |
| 做減法那一輪刪掉 | −13 |
| 做減法那一輪新增 | +3（學會技能、時間與空間兩種屬性） |
| 打擊感那一輪新增 | +4（四層低頻身體層） |
| 2026-09-17 腳步聲整套移除 | −5 |
| **目前總數** | **62** |

62 個裡面：

| | 數量 |
|---|---|
| 預設會響 | 48（41 個動作音 + 4 個只被疊上去的低頻層 + 3 個環境層） |
| 預設關閉，玩家自己去設定打開 | 14（全部是介面音效） |

砍掉什麼、為什麼，在第 6 節。

## 3. 怎麼檢查的

聽不到聲音，所以用 `sox` 讀每個檔的波形統計，記下長度、峰值和 RMS，再對照檔名決定用途。

- 沒有靜音檔，也沒有長度是 0 的檔案
- 素材峰值大多貼在 −1 dBFS 附近，有些正好在 0 dBFS，沒有餘裕，所以每個事件都給負的音量
- 因為量過，所以對照表裡的輸出欄位是真的：設定音量加上素材本身的峰值。素材峰值和 −1 dBFS 差超過 1 分貝的，
  會寫在 `peak_db` 欄位裡，測試靠它檢查整體音量
- **預設會響的音效（不含環境層）單層輸出落在 −19.9 到 −6.9 dBFS 之間，差 13.0 dB**，聽起來像一套混音而不是各自為政
- **有疊低頻身體層的命中音，兩層相加之後最大是 −3.8 dBFS（暴擊），離 0 還有 3.8 dB 餘裕**，
  就算同一幀好幾個聲音一起出來也不會爆掉。相加是用最壞情況算的：假設兩層的波峰完全對齊直接相加
- 環境層一律在 −24 dBFS 以下，只是背景
- **距離衰減也量過**：`AudioStreamPlayer3D` 的反比衰減在近距離是放大不是衰減，設錯會讓所有近身的聲音爆掉並被
  `max_db` 夾成一樣大聲，細節和修法在第 4 節
- `tests/test_audio.gd` 會自動驗證：檔案存在、長度大於 0.005 秒、音量在 −40～0 dB、音高加減隨機量之後仍在範圍內、
  預設會響的音效音量落在同一個帶裡、環境層夠小聲、預設關閉的兩類真的是關的、
  每一級命中都有低頻身體層、四級之間拉得開、揮擊一定比它的命中小聲、疊起來不會爆、近距離不會被放大

## 4. 打擊感：為什麼本來會弱，怎麼修的

使用者第二次的回饋是「打擊音效弱」。量過之後發現不是音量調得不夠大，是**衰減模型設錯，近距離的聲音全部爆掉而且被夾成一樣大聲**。

### 找到的問題

`AudioStreamPlayer3D` 的反比衰減在比 `unit_size` 近的地方是**放大**不是衰減，而且最後會被 `max_db` 夾住，
`max_db` 的預設值是 **+3 dB**。原本 `unit_size` 設 8、`max_db` 沒動，聽音點又掛在玩家身上，所以近身戰鬥的實際輸出是：

| 事件 | 設定的輸出 | 兩公尺的距離加成 | 夾住前 | 實際聽到 |
|---|---|---|---|---|
| `swing_fist` | −17.5 | +18.1 | +0.6 | **+0.6 爆掉** |
| `hit_light` | −8.8 | +11.2 | +2.4 | **+2.4 爆掉** |
| `hit_heavy` | −6.9 | +11.2 | +4.3 | **+3.0 夾住而且爆掉** |
| `hit_crit` | −5.6 | +11.2 | +5.6 | **+3.0 夾住而且爆掉** |

三件事同時發生：

1. **全部超過 0 dBFS**。削掉頂的暫態就是「弱」的聲音，因為打擊感來自那一瞬間的暫態，頂被削平就沒有了
2. **強擊和暴擊一起撞到 +3 dB 的天花板，變成一模一樣大聲**，級別根本分不出來
3. **揮擊只比命中小 1.8 dB**，自己的攻擊聲把自己的命中聲蓋掉

前兩輪寫在這份文件裡的音量表，在聲音一放到玩家附近的時候就全部失效了。這是我的錯，該一開始就量。

### 修法

**一、衰減模型**。`max_db` 改成 **0**（設定的音量就是上限，不會被放大），`unit_size` 改成 **2**（近身戰鬥的距離），
每遠一倍小 6 dB，30 公尺外聽不到。

**二、玩家自己的戰鬥不定位**。聽音點在玩家身上，自己的攻擊、自己挨打、自己打死的怪走一組不定位的播放器，
永遠是設定的音量，在混音裡站最前面；別人的戰鬥才走 3D 依距離衰減。

**三、分層做重量，不是加大音量**。每一級命中都是兩層同一幀播出來：
上面是短促的接觸聲，下面是把厚的素材壓低音高做出來的低頻身體，做法和地窟的低頻隆隆一樣。

| 級別 | 接觸層 | 低頻身體層 | 身體層長度 |
|---|---|---|---|
| 一般 | 中拳 `impactPunch_medium` | `impactGeneric_light` 壓到 0.42 倍 | 0.28–0.33 秒 |
| 強擊 | 重拳 `impactPunch_heavy` | `impactSoft_medium` 壓到 0.38 倍 | 0.31–0.48 秒 |
| 暴擊 | 金屬平板脆響 `impactPlate_heavy` | `impactSoft_medium` 壓到 0.28 倍 | 0.42–0.65 秒 |
| 擊殺 | 種族死亡聲 | `impactMetal_heavy` 壓到 0.30 倍 | 0.39–1.20 秒 |

四級之間音色、厚度、長度都不一樣，不是同一個聲音調音量，閉著眼睛也分得出打到的是哪一種。

### 修完之後量到的

| | 修正前實際聽到 | 修正後 |
|---|---|---|
| 揮擊 `swing_fist` | +0.6 爆掉 | **−17.5** |
| 一般命中 | +2.4 爆掉 | **−10.4** |
| 強擊 | +3.0 夾住爆掉 | **−7.0** |
| 暴擊 | +3.0 夾住爆掉 | **−3.8** |
| 擊殺 | +1.3 爆掉 | **−6.9** |
| 玩家挨打 | +3.0 夾住爆掉 | **−8.3** |

- 階梯：一般 → 強擊 **+3.3 dB**，強擊 → 暴擊 **+3.2 dB**，擊殺落在兩者之間但音色完全不同
- 揮擊比它自己的一般命中低 **7.1 dB**（修正前只低 1.8 dB）
- 最大的一下是 **−3.8 dBFS**，還有 3.8 dB 餘裕，同時好幾個聲音也不會爆
- 別人的戰鬥依距離：2 公尺 −10.4、4 公尺 −16.4、9 公尺（大約是畫面邊緣）−23.4、30 公尺聽不到

### 和畫面對齊

打擊感的關鍵是聲音、凍結、閃白、火花在**同一幀**出現，差幾幀就會覺得軟。所以 `battle_presenter.damage()` 裡
聲音和 `hitstop`、`flash`、`HitSpark` 是同一段連續的程式碼，中間不要插入任何等待或 tween。
聲音的級別用的也是下面算凍結時間用的**同兩個旗標** `crit` 和 `heavy`，不是各自算一次門檻，
這樣聲音的級別和畫面凍結的級別一定一致。動打擊感的人請維持這個順序。

## 5. 對照表

「音高」是基準音高加上隨機幅度。同一段素材調低會變厚重、調高會變輕脆，素材種類不夠就靠它撐開差異，
例如地窟的低頻隆隆聲是重鐘調到 0.28，命中的低頻身體層是厚實的撞擊素材調到 0.28～0.42。
「間隔 / 同時」是同一個事件的最短間隔毫秒和同時最多幾個聲音，規則在 `src/audio/voice_limiter.gd`。

## 8. 對照表以外的規則

- **揮擊看武器**：`src/core/equipment.gd` 的 `weapon_type` 決定，空手、短刀、單手劍、雙手劍、法杖、弓各一種；怪物和其他玩家一律算空手。每次出手都會響，所以壓到 −17 dB 上下，讓命中當主角
- **命中一下只響一個**：打怪是 `hit_light` / `hit_heavy` / `hit_crit`，一下扣掉目標 25% 以上的 HP 算重擊；打到自己是 `hurt_player`
- **怪物看種族**：`data/monsters.json` 的 `art.sound_family` 優先，沒寫時看 `race`，`brute` 算野獸。只影響死亡音
- **屬性看技能**：`data/elements.json` 的九種屬性各一種聲音，對照在 `SoundMap.ELEMENT_EVENTS`

  | 遊戲屬性 | 音效事件 | 聲音是什麼 |
  |---|---|---|
  | 火 fire | `element_fire` | 噪音掃頻壓低，像火的呼聲 |
  | 水 water | `element_water` | 玻璃脆響，當冰晶 |
  | 風 wind | `element_wind` | 金屬脆響，當雷擊 |
  | 土 earth | `element_earth` | 挖掘碎石 |
  | 光 light | `element_holy` | 重鐘調高的明亮鐘聲 |
  | 暗 dark | `element_dark` | 掃頻壓到最低的悶響 |
  | 時間 time | `element_time` | 拉長的掃頻，像速度被扭了一下 |
  | 空間 space | `element_space` | 往內收的聲音，像被吸進去 |
  | 無屬性 neutral | `element_neutral` | 一般輕撞擊 |

  事件名稱講的是聲音的質地不是遊戲的屬性名稱，所以改屬性名只要動這張對照表。屬性名稱這陣子改過好幾輪，用過的舊名稱都留在表裡
- **距離衰減**：聽音點掛在玩家身上而不是鏡頭上。RO 的鏡頭在 24～64 公尺外，15 度長焦，畫面大約只看得到玩家周圍 9 公尺；所以 8 公尺內是原音量，之後反比衰減，30 公尺外聽不到，畫面外的戰鬥自然變小聲
- **匯流排**：世界音效和環境層走 SFX、介面音效走 UI，都接到總音量

## 9. 環境音的實情

**專案裡沒有任何環境錄音。** 沒有風聲、沒有鳥叫、沒有水聲，Kenney 這三包都是單發的音效。

環境層不是循環播放的環境床，而是一個排程器（`src/audio/sfx.gd` 的 `set_ambience`）：每一層有自己的隨機間隔，
時間到就播一個壓低音高、壓小音量的單發音。現在只留有現成合適素材的兩張地圖：

| 基調 | 層 | 做法 | 間隔秒 |
|---|---|---|---|
| 低語森林 forest | `amb_wood_creak` | 木頭吱呀，當樹幹搖動 | 12–26 |
| 灰蝕地窟 cavern | `amb_cave_drip` + `amb_cave_rumble` | `drop` 當水滴、重鐘壓到 0.28 倍當低頻隆隆 | 4–11 / 18–36 |

**萌芽草原、晨曦鎮、碎石谷現在是安靜的。** 本來有一層用噪音掃頻假裝的風，已經拿掉——假的環境音比沒有環境音更糟。
要補的話需要真的素材，見第 11 節。

## 12. 改動這套東西時

- 檔案歸屬：`src/audio/` 全部、`docs/音效對照.md`、`tests/test_audio.gd`
- **加新事件之前先問一次：玩家不聽這個聲音，會漏掉什麼？答不出來就不要加**
- 加一個新事件：在 `sound_map.gd` 的 `EVENTS` 加一列，再在要出聲的地方呼叫 `Sfx.play_at` 或 `Sfx.play_ui`
- 一直發生的事（每次出手、每一步、每個按鈕）要嘛不要有，要嘛壓到 −18 dB 以下，要嘛加 `opt` 讓玩家自己開
- **要重量就加低頻身體層，不要加音量**。加音量只會撞到天花板然後爆掉，反而更弱
- **改衰減參數之前先看第 4 節**。`unit_size` 和 `max_db` 一起決定近距離會不會被放大，改錯會把所有級別壓平
- **聲音和畫面要同一幀**。`battle_presenter.damage()` 裡聲音和 `hitstop`、`flash`、`HitSpark` 是同一段連續的程式碼，
  中間不要插入等待或 tween；級別也用同一組 `crit` 和 `heavy` 旗標，不要各自算一次門檻
- 測試會擋住的事：事件名稱打錯、音檔路徑不存在、音量或音高超出範圍、登記了卻沒人用、預設會響的介面音效超出那四件事、
  音量和其他人差太多、環境層太大聲、砍掉的事件又跑回來（腳步聲那五個也在那張清單裡）
